# Joint model recovery study (#891)

200 simulated fleets per path model (300 pumps each, read monthly for up to two years; Weibull PH hazard with alpha 800 days and beta 2 at a marker of 4; marker effect 0.9), fitted with `marker_reference=4`. `docs/Joint Models.rst` quotes the results ("How well it recovers the truth"), dated 2026-10-16. The page does not re-run the study.

- `study.py <path> [reps]`: runs one path model (`linear`, `exp`, `quad`, `loglink`) and writes `results_<path>.jsonl` and `summary_<path>.json` here.
  - `aft_linear`, `aft_exp`, `aft_quad` and `aft_loglink` are the accelerated model's study: the same pumps and paths, each ageing at the rate `exp(0.45 (marker - 4))` against a Weibull (800 days, 2) of effective age, fitted with `JointAFT` (`marker_reference=4`). Run 2026-11-18; `docs/Joint Models.rst` quotes it.
  - `HOW=two-stage` fits the same fleets by the approximate two-stage estimate (`fit(..., how="two-stage")`), tagged `_two_stage`: run 2026-11-20 for all eight paths; `docs/Joint Models.rst` quotes it beside the joint fits ("How much the two-stage fit loses"). Its path part has no standard errors, so those rows have no coverage.
  - `EVERY=<days>` reads the pumps that often instead of every 30 days, tagged `_every<days>`: `linear` with `EVERY=180` was run both ways (`summary_linear_every180.json`, `summary_linear_every180_two_stage.json`) on 2026-11-20.
  - It resumes a killed run and uses at most 4 processes.
  - `GH=<points>` refits with that many quadrature points per dimension; `N=<pumps>` sets the fleet size. These are the diagnostic runs, tagged `_gh11` and `_n1200`.
  - `cubic` is the study of four varying parameters: fleets of 100 items whose marker is a cubic in the age with every coefficient its own (`simulate(100, seed, q=4)` of `surpyval/tests/univariate/joint/test_joint_integration.py`), fitted with `marker_reference=3.6`. `INTEGRATION=<name>` fits with that integral (`fit(..., integration=...)`), tagged `_<name>`; `PROCESSES=<n>` sets the worker processes.
- `laplace_few_readings.py`: fits fleets with `integration="grid"` and `integration="laplace"` as the readings thin out (the pumps read every 30 to 365 days; a quadratic's fleet read every 0.1 to 1 year) and writes `laplace_few_readings.json`: how far apart the two fits are, in standard errors. Run 2026-11-21 (exploratory); `docs/Joint Models.rst` ("Laplace's approximation") quotes it. `STUDY=confirm` is the second run, whose design and rule (in the script's docstring) were committed before it ran: 20 fleets read every 100 to 160 days, writing `laplace_few_readings_confirm.json`; it set the share of items with three readings or fewer above which a Laplace fit warns (15%, run 2026-11-21).
- `knee_study.py [reps]`: the spline path's study. Fleets whose marker stays flat for a year and then climbs (a knee), each fitted with `JointPH(Weibull, SplinePath(knots=[365], boundary=(0, 730)), varying=("level", "rate"))` and with `LinearPath` on the same data; bias and coverage of each parameter, and the error of each model's dynamic predictions (the marker at 450 days and survival to 540) for pumps still running at 450 days. The design and seeds (1000 to 1199) were fixed before the first run. It resumes a killed run; `PROCS=<n>` sets the processes (default 2). Writes `results_knee.jsonl` and `summary_knee.json`. Run 2026-11-25; `docs/Joint Models.rst` quotes it ("A reading that bends").
- `shape_study.py [reps]`: a spline bend that varies between pumps (sd 1.0 about 3.0; 200 fleets of 150 pumps, seeds 2000 to 2199), each fleet fitted with the bend common and with it varying: bias and coverage, how often `aic()` prefers the varying bend, and how often its spread is warned of as 0. Design fixed before any run; run 2026-11-25, `docs/Joint Models.rst` quotes it ("Items that bend differently"). Writes `results_shape.jsonl` and `summary_shape.json`.
- `table.py`: prints the per-parameter table (`table.txt`) from the summaries.
- `beta_bias.py`: the small-sample bias of a plain Weibull shape estimate at the study's size, for comparison.

Run from the repository root with the package importable (e.g. `pip install -e .`). The raw `results_*.jsonl` files are not kept; the summaries are.
