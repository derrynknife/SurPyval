Datasets
========

Example data sets used throughout the documentation and the docstrings,
each returned as a :class:`pandas.DataFrame` by a ``load_*`` function in
``surpyval.datasets``. Check each loader's description for how its
censoring column is coded: several are already coded as SurPyval's
censoring flag ``c`` (0 observed, 1 right-censored) rather than as an
event indicator.
