Plotting Positions
==================

The empirical estimate of the CDF at each observation that a probability
plot draws, and that the ``MPP`` (probability plotting) fitting method
regresses on. Both the classical rank heuristics (Blom, Median, ...)
and the non-parametric estimators are available, and censored data is
handled by rank adjustment. Import it from
``surpyval.univariate.nonparametric``.
