Kaplan-Meier
============

The product-limit estimator: the survival curve drops by the fraction
of the at-risk units that fail at each event time. It is the
non-parametric maximum likelihood estimate for right-censored and
left-truncated data. ``KaplanMeier`` is an instance of the class below;
``KaplanMeier.fit`` returns a :doc:`NonParametric <non_parametric_class>`
model. Theory: :doc:`../Non-Parametric Estimation`.
