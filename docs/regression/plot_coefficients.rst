Forest Plots of Coefficients
============================

A forest plot of one or more fitted regression models: each coefficient
with its Wald interval, from the model's ``summary()``. Import it as
``surpyval.plot_coefficients``; worked examples are in
:doc:`../Regression Modelling with SurPyval`.

.. autofunction:: surpyval.plot_coefficients

.. autoclass:: surpyval.CoefficientPlot
