Bayesian Fitting

Bayesian fits of the parametric distributions: a prior (surpyval.prior) times the likelihood of the data, by Distribution.fit_bayes and fit_bayes_from_df. The result is a BayesianParametric. Worked examples, in plain words first, are in Bayesian Fitting with SurPyval.

Fitting

ParametricFitter.fit_bayes(x: Any = None, c: Any = None, n: Any = None, t: Any = None, *, priors: Any = None, offset: bool = False, zi: bool = False, lfp: bool = False, tl: Any = None, tr: Any = None, xl: Any = None, xr: Any = None, fixed: dict[str, float] | None = None, method: str = 'auto', points: int | None = None, unit: Any = None, w: Any = None) → Any

Fit the distribution by Bayes’ rule: the prior times the likelihood of the data, which is the likelihood fit uses for every kind of censoring and truncation.

Returns a BayesianParametric, used like any model: its sf, qf, mean and random are those of a new unit’s life with the uncertainty in the parameters averaged in (the posterior predictive), and cri, quantile_cri, mean_cri and param_cri give credible intervals. fit is unchanged; all the work is in surpyval.bayes.

Parameters:

  • x – The data, as for fit; x may be a SurpyvalData.

  • c – The data, as for fit; x may be a SurpyvalData.

  • n – The data, as for fit; x may be a SurpyvalData.

  • t – The data, as for fit; x may be a SurpyvalData.

  • tl – The data, as for fit; x may be a SurpyvalData.

  • tr – The data, as for fit; x may be a SurpyvalData.

  • xl – The data, as for fit; x may be a SurpyvalData.

  • xr – The data, as for fit; x may be a SurpyvalData.

  • priors (dict or prior, optional) – {parameter name: prior} (surpyval.prior.around, between, uniform, flat, fixed or any SurPyval distribution), a joint prior (prior.on_quantities, prior.from_model, prior.from_data), or a list of these. A parameter given none is flat on its unconstrained scale (the log scale for a positive parameter), allowed only where the data alone determine it.

  • offset – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • zi – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • lfp – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • fixed – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • method ({'auto', 'grid', 'conjugate', 'laplace'}, optional) – 'auto' (the default) uses the closed form where one applies, else the self-checking grid (1 to 3 free parameters); 'laplace' a normal approximation, labelled approximate.

  • points (int, optional) – The grid’s starting points per parameter.

  • unit (str, optional) – The unit of the times, as for fit.

  • w (None) – Weights are not taken: a w is refused with a ValueError that says what to use instead (fit with w, or counts n for identical units).

Examples

>>> import numpy as np
>>> import surpyval as sp
>>> x = np.r_[2100, 3400, 4050, np.linspace(1500, 6000, 37)]
>>> c = np.r_[0, 0, 0, np.ones(37)]
>>> model = sp.Weibull.fit_bayes(
...     x, c, priors={"beta": sp.prior.around(2, between=(1.5, 3))})
>>> model.params.round(2)
array([1.441299e+04, 2.090000e+00])

The model

class surpyval.bayes.BayesianParametric(dist: Any, posterior: Posterior, *, data: SurpyvalData | None = None, priors: PriorSpec | None = None, offset: bool = False, lfp: bool = False, zi: bool = False, fixed: dict[str, float] | None = None, method: str = 'draws', log_evidence: float = nan, diagnostics: dict | None = None, exact: dict | None = None)

Bases: DiagnoseMixin, SerialisableMixin

A Bayesian fit of a parametric distribution: the posterior of its parameters, and the posterior predictive distribution of a new unit’s life.

Built by Distribution.fit_bayes (and fit_bayes_from_df), or from another sampler’s draws by from_draws().

The distribution.

Type:

ParametricFitter

params

The posterior medians of the distribution’s parameters (named by parameter_names); gamma, lfp_p and f0 are those of the offset, limited-failure proportion and zero inflation.

Type:

numpy.ndarray

posterior

The posterior itself: draws, to_dataframe, density, marginal.

Type:

Posterior

priors

The priors as given.

Type:

PriorSpec

method

"grid", "conjugate", "laplace" or "draws".

Type:

str

log_evidence

The log marginal likelihood (for Bayes factors), where every prior is proper; nan otherwise.

Type:

float

diagnostics

How the posterior was computed and how accurately.

Type:

dict

predictive_table

Whether a posterior of more than 2,000 points reads its predictive sf, ff, df, hf and Hf from a table built once (within 1e-6 of the full sum over the points in sf, ff and Hf, 1e-5 in hf and df; see “Many points: a table” in the Bayesian fitting guide). True by default; False gives the full sum everywhere.

Type:

bool

Examples

Three of 40 pump seals have failed, and the shape is believed to be about 2, between 1.5 and 3:

>>> import numpy as np
>>> import surpyval as sp
>>> x = np.r_[2100, 3400, 4050, np.linspace(1500, 6000, 37)]
>>> c = np.r_[0, 0, 0, np.ones(37)]
>>> model = sp.Weibull.fit_bayes(
...     x, c, priors={"beta": sp.prior.around(2, between=(1.5, 3))})
>>> model.method
'grid'
>>> bool(model.sf(5000) > 0.5)
True
>>> model.param_cri("beta").round(1)
array([1.4, 3.1])

This posterior as the prior of another fit.

With the data at hand, and the whole posterior wanted (no param, no widen), it is exact: this fit’s priors times its data’s likelihood raised to weight. compare_to(other: Any, on: str = 'sf', p: float = 0.1, x: float | None = None) → Comparison2

The posterior probability that this model’s quantity is greater than the other model’s: for example that this design’s B10 life is longer than the old one’s.

Parameters:

  • other (BayesianParametric or Parametric) – Another Bayesian fit (its posterior is taken as independent of this one’s), or a maximum-likelihood fit with a covariance (its estimate of the quantity is taken as normal on the log scale, or the quantity’s own scale where it can be negative, with its delta-method standard error: the large-sample posterior under a flat prior).

  • on (str, optional) – "sf" (the default) or "ff" at x; "qf", a quantile, with p (on="qf", p=0.10 for the B10 life); "mean"; or a parameter name. "R" and "F" are accepted spellings of "sf" and "ff" (unless the distribution has a parameter of that name).

  • p (float, optional) – The quantile’s probability. Defaults to 0.10.

  • x (float, optional) – The time for on="sf" or "ff".

Returns:

probability, the assumption used and a plain summary.

Return type:

Comparison2

Examples

>>> import surpyval as sp
>>> prior = {"failure_rate": sp.Gamma.from_params([2.0, 500.0])}
>>> new = sp.Exponential.fit_bayes([300, 450, 800], priors=prior)
>>> old = sp.Exponential.fit_bayes([100, 250, 400], priors=prior)
>>> round(new.compare_to(old, on="qf", p=0.10).probability, 2)
0.78

The credible interval on a function of time: the range in which the curve lies with posterior probability 1 - alpha_ci, given the prior and the data (equal-tailed).

Parameters:

diagnose(alpha: float = 0.05, columns: Sequence[str] | None = None, *, n_boot: int | None = None, random_state: Any = None, **options: Any) → Diagnosis

Check the model’s assumptions, fit and influential points, and say what to do about any that fail.

Runs the checks this kind of model calls for (for a Cox model: proportional hazards, the functional form of each continuous covariate, influence and outliers; see Model Diagnostics) and returns a report: d.table, one row per check with its test, statistic, p-value, verdict ("ok", "warn" or "fail") and covariates; d.advice, plain-English remedies that each name the SurPyval feature that applies them; d.plot(), the visual checks (matplotlib is only imported then); d.ok, True if nothing failed; d.raise_if_failed() for pipelines; and d.to_dict().

A test fails when its p-value is below alpha, and warns when it is below 2 * alpha (borderline) or could not be computed. Each row is judged at alpha on its own, so with many rows some fail by chance even when every assumption holds.

Parameters:

  • alpha (float, optional) – The level each test is judged at. Default 0.05.

  • columns (str or list of str, optional) – The covariates to check, named as summary() names them (the DataFrame or formula columns, else coef_0, …); all of them by default. A joint (GLOBAL) test still covers every covariate.

  • n_boot (int, optional) – For the families whose tests resample (a univariate distribution’s bootstrap goodness-of-fit tests): the number of bootstrap refits; None is the family’s default. Other families ignore it.

  • random_state (optional) – The seed of those resamples (SurPyval’s one seed rule: None draws from numpy’s global generator).

  • **options – Options of the model’s family, named in Model Diagnostics: for an accelerated life model, use_stress, the stress the model is to predict at (a number, or one per stress column), whose distance from the tested stresses the report screens. A family refuses an option it does not take.

Returns:

See surpyval.diagnostics.Diagnosis.

Return type:

Diagnosis

Raises:

  • NotImplementedError – For a model whose family’s diagnostics are not built yet, saying what to check it with meanwhile; for an option of the model the checks do not support yet; and for a kind of model the checks do not cover by design (a discrete distribution, a parametric regression with a custom link, …), saying what to use instead.

  • ValueError – For a model the checks cannot be run on (one restored with from_dict, which has no data), saying what to do.

Examples

>>> from surpyval import CoxPH
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> df["censored"] = 1 - df["arrest"]
>>> model = CoxPH.fit_from_df(
...     df, x_col="week", c_col="censored", Z_cols=["fin", "age"]
... )
>>> d = model.diagnose()
>>> d.ok
False
>>> d.table[["check", "transform", "covariates", "verdict"]].head(3)
                  check transform covariates verdict
0  proportional_hazards        km     (fin,)      ok
1  proportional_hazards        km     (age,)    fail
2  proportional_hazards        km (fin, age)    fail

classmethod from_draws(dist: Any, draws: ArrayLike, parameter_names: list[str] | None = None, data: Any = None, priors: Any = None, *, weights: ArrayLike | None = None, diagnostics: dict | None = None) → BayesianParametric

A Bayesian model from posterior draws made elsewhere (another sampler, such as PyMC or Stan).

Every function, credible interval and plot then works as for a fit by fit_bayes; the summaries are computed from the draws.

Parameters:

  • dist (ParametricFitter) – The distribution the draws are for.

  • draws (2-D array like) – One row per draw, one column per parameter.

  • parameter_names (list of str, optional) – The columns’ names: the distribution’s parameters, and gamma, lfp_p or f0 for an offset, limited-failure or zero-inflated model. Defaults to the distribution’s parameter_names.

  • data (SurpyvalData or (x, c, n, t), optional) – The data the draws came from, for plot, compare and update.

  • priors (optional) – The priors used, as for fit_bayes, kept for the summary and for update (which then refits with SurPyval’s own engine).

  • weights (array like, optional) – A weight per draw (importance weights); equal by default.

loo() → Any

Leave-one-out cross-validation: the expected log predictive density of a new observation, as the sum over the data’s units of log p(y_i | y_-i), the density of each unit given the others.

It is computed from the one posterior, without refitting, by p(y_i | y_-i) = 1 / E[1 / p(y_i | theta)]:

  • a conjugate fit in closed form;

  • a grid or Laplace fit by the grid’s quadrature, with edge, each row’s share of its leave-one-out posterior in the grid’s outermost cells (warns above 0.001: it may reach past the grid);

  • a fit from draws (from_draws()) by Pareto-smoothed importance sampling (Vehtari et al. 2024), with each row’s Pareto k (warns, counting the rows, above min(1 - 1/log10(S), 0.7) for S draws). The draws are taken as independent.

Returns:

elpd, se, p (p_loo), ic (-2 elpd), pointwise, and pareto_k or edge. Compare fits with surpyval.bayes.compare().

Return type:

PredictiveCriterion

Examples

>>> import surpyval as sp
>>> x = sp.Weibull.random(40, 1000, 2.5, random_state=1).round()
>>> model = sp.Weibull.fit_bayes(
...     x, priors={"beta": sp.prior.around(2, between=(1, 4))})
>>> res = model.loo()
>>> res.method, round(res.elpd, 2), round(res.se, 2)
('quadrature', -295.03, 3.68)
>>> int(res.flagged.size)
0

surpyval.bayes.prior.check(dist: Any, priors: Any = None, **fit_options: Any) → Any

What a prior says before any data: a table of the B1, B10 and B50 lives, the mean and the median, with their 90% prior intervals.

Run it before fitting, to catch a prior that says something nobody believes (“vague” priors often do: a LogNormal(0, 10) on alpha puts B10 anywhere from nanoseconds to geological time).

PriorCheck

pointwise(params: ArrayLike) → NDArray

Each data row’s own log-likelihood at each parameter point.

Row j (in the order of the data’s x, c, n and t) contributes its censoring kind’s term (density, survival, failure probability or the probability of its interval) less the log probability of its own truncation window, for one unit: the row’s count is not applied. So pointwise(P) @ data.n is the log-likelihood, to rounding.

Parameters:

params (array like) – Parameter points, shape (..., k), as for calling the likelihood.

Returns:

Shape (...) + (rows,); -inf where a row is impossible at a point.

Return type:

numpy.ndarray

Examples

>>> import numpy as np
>>> import surpyval as sp
>>> from surpyval.bayes import LogLikelihood
>>> data = sp.SurpyvalData(x=[1.0, 2.0], c=[0, 1], n=[3, 1])
>>> ll = LogLikelihood(sp.Exponential, data)
>>> ll.pointwise(np.array([0.5])).round(4)
array([-1.1931, -1.    ])
