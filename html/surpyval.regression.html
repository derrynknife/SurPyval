Regression Modelling

Models in which covariates change the survival of an individual unit. The families differ in how a covariate acts: multiplying the hazard, adding to it, scaling time, or shifting the odds.

The univariate regression models are importable directly from surpyval. For the theory see Regression Analysis; for a narrative introduction with worked examples, see Regression Modelling with SurPyval. Tree-based models are under Machine Learning, and regression for recurrent events under Recurrent Event Models. Excess hazard regression, where the covariates act on the hazard beyond a population’s own rates, is documented with net survival in Relative Survival.

Semi-Parametric Models

No assumed baseline distribution: the shape of the baseline is left to the data, and only the covariate effect is parameterised.

  • Cox Proportional Hazards
  • Interval-Censored Cox (Semi-Parametric PH)
  • Semi-Parametric Additive Hazards
  • Non-Parametric Additive Hazards (Aalen)
  • Semi-Parametric Proportional Odds
  • Buckley-James
  • Censored Quantile Regression

Parametric Models

A fitted baseline distribution combined with a covariate function. The page below covers the proportional-hazards, accelerated-failure-time, proportional-odds, parametric additive-hazards and accelerated-life families, the fitted model they all return, and the time-varying covariate paths (step schedules and continuously varying paths) the PH, AFT, AH and PO families can be evaluated along.

  • Parametric Regression Models

Which Family a Model Is

A fitted parametric regression model names its family in model.kind. Compare it with the constants in surpyval.univariate.regression.kinds rather than with a string:

The names of the parametric regression families.

A fitted ParametricRegressionModel says which family it is in its public kind attribute, one of these strings, which to_dict stores. Compare a model’s kind with these names rather than with string literals, so a family is renamed or added in one place:

>>> import surpyval as surv
>>> from surpyval.univariate.regression import kinds
>>> x = [10.0, 14.0, 21.0, 26.0, 35.0, 41.0, 52.0, 60.0]
>>> Z = [[1.0], [0.0], [1.0], [0.0], [1.0], [0.0], [1.0], [0.0]]
>>> model = surv.WeibullAFT.fit(x, Z=Z)
>>> model.kind == kinds.ACCELERATED_FAILURE_TIME
True
>>> model.kind in kinds.TIME_SCALING
True

TIME_SCALING holds the families whose covariates stretch or shrink the time axis; HAZARD_BASED those whose covariates act on the hazard. Proportional odds and distributional regression are in neither.

surpyval.univariate.regression.kinds.ACCELERATED_FAILURE_TIME = 'Accelerated Failure Time'

The covariates rescale time (AFT, WeibullAFT).

surpyval.univariate.regression.kinds.ACCELERATED_LIFE = 'Accelerated Life'

A life model gives a distribution’s life parameter at each stress (AcceleratedLife).

surpyval.univariate.regression.kinds.ADDITIVE_HAZARD = 'Additive Hazard'

The covariates add to the baseline hazard (AH, WeibullAH).

surpyval.univariate.regression.kinds.DISTRIBUTIONAL = 'Distributional'

Every parameter of the distribution has its own linear predictor and link (Distributional).

surpyval.univariate.regression.kinds.HAZARD_BASED = frozenset({'Additive Hazard', 'Proportional Hazard'})

The families whose covariates act on the baseline hazard, by multiplying it or adding to it.

surpyval.univariate.regression.kinds.PROPORTIONAL_HAZARD = 'Proportional Hazard'

The covariates multiply the baseline hazard (PH, WeibullPH).

surpyval.univariate.regression.kinds.PROPORTIONAL_ODDS = 'Proportional Odds'

The covariates scale the baseline odds (PO, WeibullPO; also the semi-parametric ProportionalOdds).

surpyval.univariate.regression.kinds.TIME_SCALING = frozenset({'Accelerated Failure Time', 'Accelerated Life'})

a unit under covariates Z ages along the baseline’s clock run faster or slower.

Type:

The families whose covariates rescale time
