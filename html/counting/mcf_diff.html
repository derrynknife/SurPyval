Comparing Two MCFs

The difference between two groups’ mean cumulative functions, with pointwise confidence bounds from the Lawless-Nadeau robust variance, and the pseudo-score tests of Cook, Lawless and Nadeau (1996) of whether the groups’ event rates differ (constant and linear weights; robust or Poisson variance). Fit a NonParametricCounting to each group and pass both. A worked example is in Recurrent Event Modelling with SurPyval.

surpyval.recurrent.mcf_diff(model_a: NonParametricCounting, model_b: NonParametricCounting, alpha_ci: float = 0.05, test_variance: str = 'robust') → MCFDiffResult

Compare the mean cumulative functions (MCFs) of two groups of items: the difference between them at each time, with a confidence interval, and a test of whether one group has events at a higher rate than the other over the follow-up.

The MCF of a group is the average number of events per item by time \(t\). Fit one NonParametricCounting per group (two fleets of pumps, two maintenance policies, treated and untreated patients) and pass both. The difference \(\hat M_a(t) - \hat M_b(t)\) says how many more events per item group a has had by \(t\); its variance is the sum of the groups’ Lawless-Nadeau robust variances, which do not assume the items share one Poisson process, and its pointwise interval is the difference plus or minus \(z\) standard errors. intervention_test compares the same systems before and after a change; this compares two separate groups.

The tests (Cook, Lawless and Nadeau 1996, the pseudo-score tests of R’s reda::mcfDiff.test) add up, over the times where both groups have items under observation, the differences between the groups’ MCF increments, each weighted by how much information that time carries:

\[U = \sum_j w(t_j) \big(d\hat M_a(t_j) - d\hat M_b(t_j)\big), \qquad w(t) = \frac{r_a(t)\, r_b(t)}{r_a(t) + r_b(t)},\]

with \(r_a, r_b\) the items under observation. The constant weight treats every time alike; the linear weight, \(w(t) (\tau - t)/\tau\) with \(\tau\) the last time both groups are observed, gives early times more say, which compares the average gap between the curves over the follow-up rather than the gap at its end. \(U^2 / \widehat{Var}(U)\) is chi-squared with one degree of freedom when the groups’ rates are the same. The robust variance of \(U\) sums, over the items of both groups, the square of each item’s weighted deviations from its group’s increments; the Poisson variance, \(\sum_j w_j^2 (d\hat M_a/r_a + d\hat M_b/r_b)\), is right only when every item follows the same Poisson process.

Parameters:

  • model_a (NonParametricCounting) – Group a’s MCF, fitted with NonParametricCounting.fit (it keeps the per-item data the robust variance needs).

  • model_b (NonParametricCounting) – Group b’s MCF, fitted the same way.

  • alpha_ci (float, optional) – The significance level of the tests and one minus the confidence level of the pointwise interval. Defaults to 0.05.

  • test_variance (str, optional) – The variance of the test statistics: "robust" (the default) or "poisson".

Returns:

The difference (diff, diff_cb, plot) and the tests (tests, statistic, p_value).

Return type:

MCFDiffResult

Raises:

  • TypeError – If a model is not a fitted NonParametricCounting.

  • ValueError – If a model has no per-item data (built by from_xrd, from_dict or a simulation), test_variance is not one of its values, or the groups are never under observation at the same time.

Examples

Two groups of two systems each, observed to t = 10:

>>> from surpyval.recurrent import NonParametricCounting, mcf_diff
>>> a = NonParametricCounting.fit(
...     [2, 5, 9, 10, 4, 10], i=[1, 1, 1, 1, 2, 2], c=[0, 0, 0, 1, 0, 1]
... )
>>> b = NonParametricCounting.fit(
...     [6, 10, 3, 8, 10], i=[1, 1, 2, 2, 2], c=[0, 1, 0, 0, 1]
... )
>>> result = mcf_diff(a, b)
>>> result.diff([3, 5, 10])
array([0. , 1. , 0.5])
>>> round(result.tests["linear"]["p_value"], 4)
0.294

Notes

The difference is estimated from the later of the two origins to the end of the shorter follow-up; beyond it one MCF is not estimated, and diff is NaN there (R’s reda::mcfDiff carries the shorter group’s MCF at its last value instead). It agrees with reda::mcfDiff and the tests with reda::mcfDiff.test (both variances) to rounding on the times both estimate.

The robust tests rest on large-sample theory. With few items per group they reject a true null somewhat more often than alpha_ci: in a simulation with strongly varying rates (an exponential frailty), 20 items per group rejected 7-8% of the time at a 5% level, and 80 items per group 5%.

References

Lawless, J. F. and Nadeau, C. (1995), “Some simple robust methods for the analysis of recurrent events”, Technometrics 37, 158-168.

Cook, R. J., Lawless, J. F. and Nadeau, C. (1996), “Robust tests for treatment comparisons based on recurrent event responses”, Biometrics 52, 557-571.

diff(x: ArrayLike) → NDArray

The difference of the MCFs, group a minus group b, at x.

Parameters:

x (array like) – The times at which to evaluate the difference.

Returns:

The difference at each x: a step function, 0 before the first observed time, and NaN before the origin and past the end of the shorter follow-up, where one of the MCFs is not estimated.

Return type:

numpy array

diff_cb(x: ArrayLike, bound: str = 'two-sided', *, alpha_ci: float | None = None) → NDArray

Pointwise confidence bounds on the difference of the MCFs at x: the difference plus or minus z standard errors (Wald bounds; a difference can be negative, so there is no log scale).

Parameters:

  • x (array like) – The times at which to compute the bounds.

  • bound (str, optional) – "two-sided" (the default), "upper" or "lower".

  • alpha_ci (float, optional) – The total tail probability of the bound(s): a two-sided 1 - alpha_ci interval, or a one-sided bound exceeded with probability alpha_ci. Defaults to the result’s alpha_ci. Keyword only.

Returns:

Two-sided bounds as one row per query, [lower, upper]; one-sided bounds as a 1-D array. 0 before the first observed time and NaN where diff() is.

Return type:

numpy array

Examples

>>> from surpyval.recurrent import NonParametricCounting, mcf_diff
>>> a = NonParametricCounting.fit(
...     [2, 5, 9, 10, 4, 10], i=[1, 1, 1, 1, 2, 2],
...     c=[0, 0, 0, 1, 0, 1],
... )
>>> b = NonParametricCounting.fit(
...     [6, 10, 3, 8, 10], i=[1, 1, 2, 2, 2], c=[0, 1, 0, 0, 1]
... )
>>> mcf_diff(a, b).diff_cb([5, 10]).round(4)
array([[ 0.02  ,  1.98  ],
       [-1.0495,  2.0495]])

The result as a dict of native Python values, strict JSON: a missing or infinite number is written as None and recorded under "non_finite" (as every SurPyval to_dict does), so that from_dict() restores it.

Examples

>>> import json
>>> from surpyval.recurrent import (
