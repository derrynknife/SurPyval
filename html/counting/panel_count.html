Panel Counts (Events Counted at Inspections)

Recurrent events seen only as counts: each unit is inspected at its own times and the number of events since the previous inspection is recorded, never the event times. PanelCountMCF estimates the mean cumulative function without assuming a process (maximum likelihood or maximum pseudo-likelihood over non-decreasing step functions), and PanelCountRegression fits the proportional means model \(E[N(t) \mid Z] = \Lambda_0(t) e^{\beta' Z}\) with the baseline left unspecified. Bounds and standard errors come from resampling units (the bootstrap). The theory is in Recurrent Event Analysis and worked examples in Recurrent Event Modelling with SurPyval. Each fit returns a fitted instance of its class.

The parametric intensity models (CrowAMSAA, CoxLewis, …) take panel counts as interval-counted rows (c=2, x the [previous, this] inspection times, n the count, 0 allowed).

class surpyval.recurrent.panel_count.PanelCountMCF

Bases: SerialisableMixin

The non-parametric mean cumulative function (MCF) from panel counts: the expected number of events per unit by time \(t\), estimated from counts made at inspections, with no event times.

Each unit \(i\) is inspected at its own times \(t_{i1} < \dots < t_{iJ_i}\), and the count \(n_{ij}\) of events in \((t_{i,j-1}, t_{ij}]\) is recorded (\(t_{i0} = 0\)). The mean function \(\Lambda(t) = E[N(t)]\) is estimated at the distinct inspection times, as a non-decreasing step function, by one of two estimators:

  • how="MLE" (the default), the non-parametric maximum likelihood estimator of Wellner and Zhang (2000): the \(\Lambda\) that maximises the likelihood of the counts as if each were Poisson with mean \(\Lambda(t_{ij}) - \Lambda(t_{i,j-1})\),

    \[\sum_{i,j} n_{ij} \log\big(\Lambda(t_{ij}) - \Lambda(t_{i,j-1})\big) - \sum_i \Lambda(t_{iJ_i}).\]

    It is found by the self-consistency (EM) algorithm, accelerated.

  • how="pseudo", the maximum pseudo-likelihood estimator (Sun and Kalbfleisch, 1995; Wellner and Zhang, 2000): the likelihood of the cumulative counts \(N_{ij} = n_{i1} + \dots + n_{ij}\) taken as independent Poisson counts, whose maximiser is the isotonic (non-decreasing) regression of the \(N_{ij}\) on the times. It is exact and fast; the likelihood estimator is more efficient when the inspection times differ a lot between units.

The Poisson model is a working model: both estimators are consistent for the mean function of any counting process whose inspection times do not depend on its counts. When every unit is inspected at the same times both reduce to the mean count per unit at each inspection.

Bounds (mcf_cb()) are percentile bootstrap bounds from resampling units, which do not assume the Poisson model.

Call PanelCountMCF.fit (or fit_from_df); it returns a fitted instance.

References

Sun, J. and Kalbfleisch, J. D. (1995), “Estimation of the mean function of point processes based on panel count data”, Statistica Sinica, 5(1), 279-289.

Wellner, J. A. and Zhang, Y. (2000), “Two estimators of the mean of a counting process with panel count data”, Annals of Statistics, 28(3), 779-814.

bootstrap(n_boot: int = 1000, random_state: Any = None) → NDArray

The estimate refitted to n_boot resamples of the units (drawn with replacement), at the inspection times x: one row per resample. A time beyond a resample’s last inspection is NaN.

A seed (random_state) caches the resamples, so the bounds at other times or levels reuse them.

converged: bool

Whether the likelihood estimator’s iteration converged.

classmethod fit(x: ArrayLike, n: ArrayLike, i: ArrayLike | None = None, how: str = 'MLE', *, unit=None) → PanelCountMCF

Estimate the mean cumulative function from panel counts.

Parameters:

  • x (array_like) – The inspection times, one row per inspection of a unit, measured from the start of the unit’s observation (all positive).

  • n (array_like) – The number of events found at each inspection: those since the unit’s previous inspection, or since time 0 at its first. 0 where none were found (those rows count: they say no events happened in the interval).

  • i (array_like, optional) – The unit each row belongs to. Defaults to a single unit.

  • how (str, optional) – "MLE" (the default) for the maximum likelihood estimator, or "pseudo" for the maximum pseudo-likelihood (isotonic regression) estimator.

Returns:

The fitted estimate.

Return type:

PanelCountMCF

Examples

Three units, each inspected at its own times:

>>> from surpyval.recurrent import PanelCountMCF
>>> x = [2, 5, 9, 3, 8, 4, 6, 10]
>>> n = [1, 0, 2, 1, 2, 0, 2, 1]
>>> i = [1, 1, 1, 2, 2, 3, 3, 3]
>>> model = PanelCountMCF.fit(x, n, i=i, how="pseudo")
>>> model.mcf([2, 5, 10]).round(4)
array([0.6667, 1.    , 3.    ])

class surpyval.recurrent.panel_count.PanelCountRegression

Bases: SerialisableMixin

The proportional means model for panel counts: the expected number of events by time \(t\) of a unit with covariates \(Z\) is a baseline mean function scaled by the covariates,

\[E[N(t) \mid Z] = \Lambda_0(t)\, e^{\beta' Z},\]

with \(\Lambda_0\) left unspecified (a non-decreasing step function at the inspection times). \(e^{\beta_k}\) is the ratio of the expected counts for a one-unit increase in covariate \(k\), at every time.

The data are panel counts as for PanelCountMCF, with one covariate row per unit. The fit maximises over \(\beta\) the profile of one of two likelihoods (Wellner and Zhang, 2007; Zhang, 2002), both of which treat the counts as Poisson as a working model only:

  • how="pseudo" (the default), the pseudo-likelihood of the cumulative counts, whose baseline for a given \(\beta\) is a weighted isotonic regression (spef’s "MPL" method);

  • how="MLE", the likelihood of the counts in each inspection interval, whose baseline for a given \(\beta\) is found by the self-consistency algorithm.

Both give consistent, asymptotically normal estimates of \(\beta\) when the counting process is not Poisson, as long as the mean model holds and the inspection times do not depend on the counts. Their standard errors and bounds (param_cb(), mcf_cb()) come from refitting to resamples of the units (the bootstrap), as spef gives them for these methods.

Call PanelCountRegression.fit (or fit_from_df); it returns a fitted instance.

References

Wellner, J. A. and Zhang, Y. (2007), “Two likelihood-based semiparametric estimation methods for panel count data with covariates”, Annals of Statistics, 35(5), 2106-2142.

Zhang, Y. (2002), “A semiparametric pseudolikelihood estimation method for panel count data”, Biometrika, 89(1), 39-48.
