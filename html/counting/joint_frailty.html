Joint Frailty Model (Recurrent and Terminal Events)

Recurrent events that stop at a terminal event which depends on them: a machine repaired again and again until it is scrapped, a patient readmitted until death. Each unit has an unobserved frailty that raises both its rate of recurrent events and its hazard of the terminal event, so a unit with many recurrences tends to reach the terminal event sooner. Both baselines are Weibull (the recurrent one is the power-law intensity), on the unit’s age or, for the recurrences, the time since the last event. The theory is on Recurrent Event Regression Analysis, with worked examples on Recurrent Event Regression Modelling with SurPyval.

The fitter

surpyval.recurrent.joint_frailty.JointFrailty

The joint frailty model of recurrent events and a terminal event (Liu, Wolfe and Huang 2004; Rondeau et al. 2007), with Weibull baselines for both. JointFrailty is an instance of this class; its fit returns a JointFrailtyModel.

In plain words: each unit (a machine, a patient) has repeated events until its history is ended by a terminal event (scrapping, death) or by the end of follow-up. Every unit carries an unobserved frailty u that raises its rate of recurrent events by the factor u and its hazard of the terminal event by u ** alpha. theta, the frailty’s variance, measures how much units differ beyond their covariates; alpha measures how the terminal event depends on that difference: positive when the units with many recurrences reach the terminal event sooner. With the terminal event treated as ordinary censoring that dependence biases the recurrent-event rate, which this model corrects.

\[r_i(t \mid u) = u \, r_0(t) \, e^{\beta' Z_i}, \qquad \lambda_i(t \mid u) = u^{\alpha} \lambda_0(t) \, e^{\gamma' Z_i},\]

with \(R_0(t) = (t / \eta_r)^{k_r}\) (the power-law intensity) and \(\Lambda_0(t) = (t / \eta_t)^{k_t}\).

How the data are given. The rows of each unit (named by i) are its recurrent events (c = 0, at the age they happened) and one row that closes its observation (c = 1, at the age it ended). The terminal flag is 1 on that closing row when the terminal event closed it, and 0 when observation simply stopped (the end of the study, a unit lost to follow-up). Covariates Z describe the unit and are the same on all its rows; they enter both parts, with their own coefficients. tl is a unit’s age when its observation began (delayed entry), on the calendar time scale.

From a SurpyvalData. fit(data) takes a SurpyvalData with units i, in which the terminal event is an event row with the terminal flag a = 1: a unit’s rows are its recurrent events (c = 0, a = 0), then its terminal event (c = 0, a = 1) or a row c = 1 at the end of its record without one. They are read as the arrays above (the terminal event becomes the closing row with terminal = 1), so the fit is the same. An event on a unit’s last row with no a is read as its terminal event, and the model’s notes say so: give a = 0 on a last event that was an ordinary one. fit_from_df(..., a_col=...) reads such a table.

Examples

>>> import numpy as np
>>> from surpyval.recurrent import JointFrailty
>>> # Draw 150 units from a joint frailty model and fit it back.
>>> truth = JointFrailty.from_params(
...     recurrent=(10.0, 1.2), terminal=(20.0, 1.5),
...     theta=0.5, alpha=1.0, beta=[0.5], gamma=[0.3],
... )
>>> rows = truth.random(150, end=15.0, Z=np.tile([[0.0], [1.0]], (75, 1)),
...                     random_state=1)
>>> model = JointFrailty.fit(**rows)
>>> model.parameter_names[4:6]
['theta', 'alpha']
>>> round(model.theta, 2), round(model.alpha, 2)
(0.54, 1.68)
JointFrailty.fit(x: ArrayLike, Z: ArrayLike | None = None, i: ArrayLike | None = None, c: ArrayLike | None = None, terminal: Any = None, tl: ArrayLike | None = None, time_scale: str = 'calendar', family: str = 'gamma', init: ArrayLike | None = None, *, unit=None) → JointFrailtyModel

Fit the joint frailty model by maximising the marginal likelihood (the frailty integrated out by adaptive Gauss-Hermite quadrature).

Parameters:

  • x (array_like or SurpyvalData) – The ages of the recurrent events and of the end of each unit’s observation, pooled over the units. Or a SurpyvalData with units i holding the whole of the data, the terminal event marked by a = 1 on its event row (see the class description); the other data arguments are then left out.

  • Z (array_like, optional) – Covariates: one row per row of x (a 1-D array is one covariate), the same on every row of a unit, or a DataFrame whose column names name the coefficients. They enter both the recurrent intensity (beta) and the terminal hazard (gamma). Default: none.

  • i (array_like) – The unit each row belongs to.

  • c (array_like) – 0 on a recurrent event, 1 on the one row per unit that closes its observation.

  • terminal (array_like or dict) – 1 on a unit’s closing row (c = 1) where the terminal event closed its observation, 0 where observation simply stopped; 0 on every event row. Or a dict {unit: 0 or 1}.

  • tl (array_like or float, optional) – Each unit’s age when its observation began (delayed entry): a scalar, one value per row (the same on a unit’s rows) or one per unit in the sorted order of the ids. A unit is seen only if it had not reached the terminal event by then, which the likelihood takes into account. Calendar time scale only.

  • time_scale ({'calendar', 'gap'}, optional) – The clock of the recurrent intensity: 'calendar' (the default), the unit’s age (the Andersen-Gill counting-process form, R frailtypack’s recurrentAG=TRUE), or 'gap', the time since the unit’s last event (each event renews the baseline, recurrentAG=FALSE). The terminal hazard is always on the unit’s age.

  • family ({'gamma', 'lognormal'}, optional) – The frailty distribution: gamma with mean 1 and variance theta (the default), or log-normal with log u ~ N(0, theta).

  • init (array_like, optional) – Starting values of the natural parameters, in the order of parameter_names. The default start (the fits without a frailty) is tried as well, and the better answer kept.

Returns:

The fitted model.

class surpyval.recurrent.joint_frailty.JointFrailtyModel

Bases: ParameterBoundsMixin, SerialisableMixin, LikelihoodInferenceMixin

A fitted joint frailty model of recurrent events and a terminal event (see JointFrailty).

Its predictions are for a unit with covariates Z: either for the population of such units (frailty=None, the frailty averaged over its distribution) or for one unit of known frailty (frailty=u; model.frailties holds each fitted unit’s estimate). Recurrent events: cif() and iif(), the cumulative intensity and the intensity with no terminal event to stop them, and mcf(), the expected number of recurrent events by each age with the terminal event stopping them (the calendar time scale). The terminal event: sf(), ff(), hf(), Hf() and df().

frailty_tests() → Any

Two likelihood-ratio tests of the dependence between the recurrent and the terminal events.

  • theta = 0: no frailty, so the units differ only through their covariates and the two parts are independent. The model without frailty is the two parts fitted separately. Near the null the frailty acts through two variances on the edge of their space, theta in the recurrent part and alpha^2 theta in the terminal part (alpha is not identified under the null), so the p-value is that of a 50:50 mixture of \(\chi^2_1\) and \(\chi^2_2\) (Self and Liang 1987; Stram and Lee 1994), an approximation whose size is checked in the calibration study. (The single-variance reference, half a \(\chi^2_1\), rejected a true null 18% of the time at 5%; this mixture held 5.0% in that study and 4.6% in a second one.)

  • alpha = 0: the frailty acts on the recurrent events only, so the terminal event does not depend on how often a unit has recurrences. The model is refitted with alpha held at 0 (theta free); the statistic is compared with \(\chi^2_1\).

Returns:

One row per test: statistic (twice the difference of the log-likelihoods), df, p and reference (the null distribution).

Return type:

pandas.DataFrame

Examples

>>> from surpyval.recurrent import JointFrailty
>>> truth = JointFrailty.from_params(
...     (10.0, 1.2), (20.0, 1.5), 0.5, 1.0
... )
>>> rows = truth.random(150, end=15.0, random_state=3)
>>> model = JointFrailty.fit(**rows)
>>> model.frailty_tests()["p"].round(5).tolist()
[0.00012, 0.03289]

  • "wald" (the default) – from the covariance, on the log scale for the positive parameters (the baselines’ and theta) and the natural scale for alpha and the coefficients.

  • "lr" – the profile-likelihood interval: the values whose deviance, every other parameter re-fitted, stays below the \(\chi^2_1\) critical value. Where it stays below it down to theta = 0 the lower bound on theta is 0; where it stays below it however far alpha or a coefficient goes (the profile levels off), that end is -inf or inf, with a warning. It needs the data, which a model restored from a dict does not keep.

Parameters:

  • name (str) – One of parameter_names.

  • alpha_ci (float, optional) – Total tail probability. Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are [lower, upper].

  • method ({'wald', 'lr'}, optional) – As above.

Examples

>>> from surpyval.recurrent import JointFrailty
>>> truth = JointFrailty.from_params(
...     (10.0, 1.2), (20.0, 1.5), 0.5, 1.0
... )
>>> rows = truth.random(150, end=15.0, random_state=3)
>>> model = JointFrailty.fit(**rows)
>>> model.param_cb("alpha").round(2)
array([-0.15,  1.82])
>>> model.param_cb("alpha", method="lr").round(2)
array([0.06, 2.57])
property parameter_bounds: list[tuple[float | None, float | None]]

one (low, high) pair per entry of the vector with_params() takes, in the order of covariance_names (None for an end with no bound).

A parameter set drawn inside these ranges is one with_params does not refuse for being out of range, and one just outside a finite end is refused. Draw a parameter bounded on one side on the log scale of its distance from that end, and one bounded on both on the logit scale between them. Whether an end itself is allowed depends on the parameter (a probability may be 0 where a scale may not), so keep draws strictly inside.

A few models also constrain their parameters jointly, which no per-parameter range can say, and with_params refuses a set that breaks the joint constraint, saying so: a mixture’s weights sum to 1; a Uniform’s a is below its b (as a Beta4’s are); a Royston-Parmar spline does not fall; a Binomial’s n is a whole number. The entry of a parameter with_params ignores (held fixed in the fit, or an accelerated life model’s life parameter) gives the parameter’s range all the same. An accelerated life model’s life-model parameters can have ranges that depend on the stresses fitted to; a model loaded from a dict saved without its data gives them as unbounded.

The frailty integral

surpyval.recurrent.joint_frailty.log_frailty_integral(D: Any, A: Any, B: Any, alpha: Any, theta: Any, family: str = 'gamma', n_nodes: int = 64) → Any

The frailty integral of the joint frailty model, elementwise,

\[\log \int_0^\infty u^D e^{-A u - B u^\alpha} \, dG_\theta(u),\]

with G the gamma (mean 1, variance theta) or log-normal (log u ~ N(0, theta)) frailty distribution, by an n_nodes-point trapezoid rule in w = log u over the range where the integrand matters: from its mode (found by Newton’s method; the log-integrand is concave) out to where it has fallen by e^-36 on either side. The mode and the range only place the nodes, so they are not differentiated: autograd’s derivatives are those of the rule with the nodes held, which is a valid quadrature wherever they are. theta <= 0 is the model without frailty, u = 1: -A - B.

Parameters:

  • D (array_like) – Broadcast together: a unit’s count of events (n + alpha delta, its recurrent events and alpha times its terminal flag), its cumulative recurrent intensity at u = 1 and its cumulative terminal hazard at u = 1.

  • A (array_like) – Broadcast together: a unit’s count of events (n + alpha delta, its recurrent events and alpha times its terminal flag), its cumulative recurrent intensity at u = 1 and its cumulative terminal hazard at u = 1.

  • B (array_like) – Broadcast together: a unit’s count of events (n + alpha delta, its recurrent events and alpha times its terminal flag), its cumulative recurrent intensity at u = 1 and its cumulative terminal hazard at u = 1.

  • alpha (float) – The power of the frailty in the terminal hazard.

  • theta (float) – The variance of the frailty (gamma) or of its logarithm (log-normal).

  • family ({'gamma', 'lognormal'}, optional) – The frailty distribution. Default 'gamma'.

  • n_nodes (int, optional) – The least number of nodes. Default 64; more are taken where a unit’s integrand is wide, for steps of at most 0.3 in w.

Returns:

The log-integral, of the broadcast shape.

Return type:

numpy.ndarray

Examples

>>> import numpy as np
>>> from surpyval.recurrent.joint_frailty import log_frailty_integral
>>> # A gamma frailty with alpha = 1 has a closed form:
>>> # log E[u^D e^{-(A + B) u}] for theta = 0.5, D = 2, A + B = 1.5
>>> value = log_frailty_integral(2.0, 1.0, 0.5, 1.0, 0.5)
>>> from scipy.special import gammaln
>>> k = 2.0
>>> exact = (gammaln(k + 2) - gammaln(k) + k * np.log(k)
...          - (k + 2) * np.log(k + 1.5))
>>> bool(abs(value - exact) < 1e-12)
True
