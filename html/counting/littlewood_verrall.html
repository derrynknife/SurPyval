Littlewood-Verrall

The Littlewood-Verrall software reliability model: the time to each failure is exponential with a rate that is itself random (gamma), lower on average after each fix, so a fix may make the software better or worse. Fitted to one test campaign’s times between failures, each of which is then Pareto. It has no number of faults; it gives the distribution of the time to the next failure and of the rate now.

A fit is refused where the gaps are no more scattered than exponential times would be (alpha then has no finite estimate).

surpyval.recurrent.software.littlewood_verrall.LittlewoodVerrall

the time to the i-th failure is exponential with a rate that is itself random, gamma with shape alpha and rate psi(i) = beta0 + beta1 i (or beta0 + beta1 i**2). The rates fall on average as failures are fixed, but a fix can make things worse: the model does not suppose that every fix works, nor that there is a fixed number of faults.

It is fitted by maximum likelihood to one test campaign’s times between failures, each of which is Pareto once the rate is integrated out. Its predictions of the next failure carry the uncertainty about the rate: LittlewoodVerrallModel.next_failure_sf() is a Pareto survival function, with a heavier tail than an exponential’s.

LittlewoodVerrall is an instance of this class; fit and from_params return a LittlewoodVerrallModel.

References

Littlewood, B. and Verrall, J. L. (1973), “A Bayesian reliability growth model for computer software”, Journal of the Royal Statistical Society C 22(3), 332-346.

Examples

>>> import numpy as np
>>> from surpyval.recurrent import LittlewoodVerrall
>>> truth = LittlewoodVerrall.from_params([3.0, 10.0, 2.0])
>>> gaps = truth.random(200, random_state=1)
>>> model = LittlewoodVerrall.fit(gaps, gaps=True)
>>> model.params.round(2)
array([ 4.64, 17.65,  3.19])
>>> model.next_failure_sf([10.0, 100.0]).round(3)
array([0.933, 0.519])
Type:

The Littlewood-Verrall software reliability model

LittlewoodVerrall.fit(x: ArrayLike, c: ArrayLike | None = None, *, gaps: bool = False, psi: str = 'linear', unit=None) → LittlewoodVerrallModel

Fit the model to one test campaign by maximum likelihood.

Parameters:

  • x (array_like) – The failure times, from the start of testing; or, with gaps=True, the times between failures in the order they happened. At least five failures, at different times.

  • c (array_like, optional) – 0 for a failure and 1 for the end of testing (one row, after the last failure; with gaps=True the last value of x is then the time tested since the last failure). Default: every row a failure, the test ending at the last.

  • gaps (bool, optional) – Whether x is the times between failures. Default False. Keyword only.

  • psi ({'linear', 'quadratic'}, optional) – How psi grows with the failure number i: beta0 + beta1 i (default) or beta0 + beta1 i**2. Keyword only.

Returns:

The fitted model.

Return type:

LittlewoodVerrallModel

Raises:

ValueError – Where the gaps are no more scattered than exponential times with a growing mean would be: the likelihood then rises for ever as alpha grows, and there is no estimate. The message says so and what to fit instead.

LittlewoodVerrall.from_params(params: ArrayLike, n: int = 0, psi: str = 'linear', *, unit=None) → LittlewoodVerrallModel

The model at given parameters, without data.

Parameters:

  • n (int, optional) – The failures already seen: the model then answers for the next one, number n + 1. Default 0.

  • psi ({'linear', 'quadratic'}, optional) – The form of psi.

Examples

>>> from surpyval.recurrent import LittlewoodVerrall
>>> truth = LittlewoodVerrall.from_params([3.0, 10.0, 2.0])
>>> gaps = truth.random(200, random_state=1)
>>> model = LittlewoodVerrall.fit(gaps, gaps=True)
>>> round(model.next_failure_qf(0.5), 1)   # the median time to the next
106.3
>>> round(model.current_rate(), 4)
0.007

Bounds: param_cb by the likelihood ratio for alpha (whose likelihood is lopsided, and whose upper bound is inf where the data do not rule out rates with no scatter) and by the delta method (Wald) for all three. The predictions have no confidence bounds: see next_failure_sf().

aic() → float

Akaike’s criterion, 2 * 3 + 2 neg_ll(); comparable with the aic() of the other models fitted to the same failure times.

aic_c() → float

The small-sample AIC, with the failures as the sample size.

bic() → float

The Bayesian criterion, 3 log(n) + 2 neg_ll().

covariance() → ndarray

The covariance of [alpha, beta0, beta1]: the inverse of the observed information (a numerical Hessian of the log-likelihood in the search’s parameters, carried to these by the delta method).

current_rate() → float

The expected failure rate now, alpha / psi(n + 1): the mean of the gamma distribution of the next failure’s rate.

current_rate_qf(p: ArrayLike) → Any

Quantiles of the failure rate now: those of its gamma distribution (shape alpha, rate psi(n + 1)). The model holds that the rate is not known exactly, even with its parameters given; current_rate_qf([0.05, 0.95]) is a 90% interval for it.

Examples

>>> from surpyval.recurrent import LittlewoodVerrall
>>> model = LittlewoodVerrall.from_params([3.0, 10.0, 2.0], n=20)
>>> model.current_rate_qf([0.05, 0.5, 0.95]).round(4)
array([0.0157, 0.0514, 0.1211])

next_failure_mean() → float

The mean time to the next failure, psi(n + 1) / (alpha - 1). It is infinite where alpha <= 1 (the Pareto’s tail is too heavy for a mean), and that is refused: use the median, next_failure_qf(0.5).

next_failure_qf(p: ArrayLike) → Any

The time by which the next failure comes with probability p: psi ((1 - p)**(-1 / alpha) - 1). p = 0.5 is the median time to the next failure, which exists whatever alpha is.

Examples

>>> from surpyval.recurrent import LittlewoodVerrall
>>> model = LittlewoodVerrall.from_params([3.0, 10.0, 2.0], n=20)
>>> round(model.next_failure_qf(0.5), 3)
13.516
next_failure_sf(x: ArrayLike) → ndarray

The chance that the software runs a further x from the last failure without another: (psi / (psi + x))**alpha with psi = psi(n + 1), a Pareto survival function. (The name the other models of failures use.)

It already allows for not knowing the rate: it is the exponential survival averaged over the gamma distribution of the rate, so it has a heavier tail than any one exponential. There are no confidence bounds on it; the uncertainty left out is that of alpha and psi themselves (see param_cb()).

Examples

>>> from surpyval.recurrent import LittlewoodVerrall
>>> model = LittlewoodVerrall.from_params([3.0, 10.0, 2.0], n=20)
>>> model.next_failure_sf([0.0, 26.0, 260.0]).round(4)
array([1.    , 0.2963, 0.0046])
param_cb(name: str, alpha_ci: float = 0.05, bound: str = 'two-sided', method: str | None = None) → Any

Confidence bounds on a parameter.

Parameters:

  • name ({'alpha', 'beta0', 'beta1'}) – The parameter.

  • alpha_ci (float, optional) – The total tail probability of the bound(s). Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are an array [lower, upper].

  • method ({'lr', 'wald'}, optional) –

    "lr": the likelihood ratio, for alpha only (its default): the values of alpha whose profile likelihood is within the chi-squared quantile of the maximum. The upper bound is inf where the model’s limit, rates with no scatter, is inside. For beta0 and beta1 it is refused (not built: use "wald").

    "wald": the delta method, from covariance() (the default for beta0 and beta1): on the log scale for alpha, which is positive. For alpha it is a poor bound where the likelihood is lopsided; compare it with "lr".

Examples

>>> from surpyval.recurrent import LittlewoodVerrall
>>> truth = LittlewoodVerrall.from_params([3.0, 10.0, 2.0])
>>> gaps = truth.random(200, random_state=1)
>>> model = LittlewoodVerrall.fit(gaps, gaps=True)
>>> model.param_cb("alpha").round(2)
array([ 2.38, 17.7 ])
>>> model.param_cb("alpha", method="wald").round(2)
array([ 2.01, 10.73])
