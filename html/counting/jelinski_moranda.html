Jelinski-Moranda

The Jelinski-Moranda software reliability model: a whole number of faults N, each found at the same rate phi, so the failure rate steps down by phi at every failure. It is fitted to one test campaign’s failure times (or the times between them). It is not a Poisson process: for the NHPP growth models see Goel-Okumoto and its neighbours.

The estimate of N is a whole number, and its bounds are likelihood-ratio sets of whole numbers; an upper bound of inf says the data do not limit the number of faults. Data that show no reliability growth have no finite estimate at all, and fit refuses them, saying what was seen and what to fit instead.

surpyval.recurrent.software.jelinski_moranda.JelinskiMoranda

the software holds N faults, a whole number, and each is found at the same rate phi, so the time between failure i - 1 and failure i is exponential with rate phi (N - i + 1). Fitted to one test campaign’s failure times it estimates N and phi, and so the faults left, N - n, and the failure rate now, phi (N - n).

It is not a Poisson process: the rate steps down at each failure, and N is a whole number, estimated as one. Its likelihood is known to have no finite maximum for data that show no growth, and to say little about how large N may be even when it has one, so fit refuses the first case and the bounds (by the likelihood ratio) report an unbounded N as inf.

JelinskiMoranda is an instance of this class; fit and from_params return a JelinskiMorandaModel.

References

Jelinski, Z. and Moranda, P. B. (1972), “Software reliability research”, in Statistical Computer Performance Evaluation (ed. W. Freiberger), Academic Press, 465-484.

Littlewood, B. and Verrall, J. L. (1981), “Likelihood function of a debugging model for computer software reliability”, IEEE Transactions on Reliability R-30(2), 145-148.

Examples

Twelve failures of a program under test, at these days:

>>> from surpyval.recurrent import JelinskiMoranda
>>> x = [3, 8, 12, 20, 25, 33, 41, 47, 58, 70, 81, 99]
>>> model = JelinskiMoranda.fit(x)
>>> model.N, round(model.phi, 5)
(15, 0.01511)
>>> model.remaining_faults()
3
>>> model.remaining_faults_cb(alpha_ci=0.5)
array([1., 8.])
>>> model.remaining_faults_cb(alpha_ci=0.05)
array([ 0., inf])

The Jelinski-Moranda software reliability model

JelinskiMoranda.fit(x: ArrayLike, c: ArrayLike | None = None, *, gaps: bool = False, unit=None) → JelinskiMorandaModel

Fit the model to one test campaign by maximum likelihood.

Parameters:

  • x (array_like) – The failure times, from the start of testing (in any order); or, with gaps=True, the times between failures in the order they happened. At least two failures.

  • c (array_like, optional) – 0 for a failure and 1 for the end of testing: one c=1 row, at or after the last failure (with gaps=True the last value of x, the time tested since the last failure). Without one the test is taken to end at the last failure. Default: every row a failure.

  • gaps (bool, optional) – Whether x is the times between failures. Default False: the failure times. Keyword only.

Returns:

The fitted model.

Return type:

JelinskiMorandaModel

Raises:

ValueError – Where the data show no reliability growth, so that the likelihood rises for ever as N grows and there is no estimate; the message gives the condition and says what to fit instead.

Examples

A campaign as times between failures, with 21 more days of testing after the twelfth failure and none found:

>>> from surpyval.recurrent import JelinskiMoranda
>>> gaps = [3, 5, 4, 8, 5, 8, 8, 6, 11, 12, 11, 18, 21]
>>> model = JelinskiMoranda.fit(gaps, c=[0] * 12 + [1], gaps=True)
>>> model.N, round(model.phi, 5)
(12, 0.02414)

aic() → float

Akaike’s criterion, 2 * 2 + 2 neg_ll(), comparable with the aic() of an NHPP model fitted to the same failure times (the two likelihoods are densities of the same data).

aic_c() → float

The small-sample AIC, with the failures as the sample size: aic() + 12 / (n - 3) (inf with three failures or fewer).

bic() → float

The Bayesian criterion, 2 log(n) + 2 neg_ll(), with the failures as the sample size.

cif(x: ArrayLike) → ndarray

The expected number of failures by the test time x from the start, N (1 - exp(-phi x)) (each fault is found by x with that chance): the same curve as a Goel-Okumoto process with a = N and b = phi.

Examples

>>> from surpyval.recurrent import JelinskiMoranda
>>> JelinskiMoranda.from_params([20, 0.01]).cif([0, 50, 1e6])
array([ 0.        ,  7.86938681, 20.        ])
current_rate() → float

The failure rate now, after the n failures found: phi (N - n) (0 when no fault is left).

current_rate_cb(alpha_ci: float = 0.05, bound: str = 'two-sided', method: str = 'lr') → Any

Likelihood-ratio confidence bounds on the failure rate now, phi (N - n): the rates whose profile likelihood (over the whole numbers of faults left, and their limit, a constant rate) is within the chi-squared quantile of the maximum. The lower bound is 0 where N = n, no fault left, is inside the bounds on N. See param_cb() for the arguments.

Examples

>>> from surpyval.recurrent import JelinskiMoranda
>>> x = [3, 8, 12, 20, 25, 33, 41, 47, 58, 70, 81, 99]
>>> JelinskiMoranda.fit(x).current_rate_cb().round(4)
array([0.    , 0.1709])

param_cb(name: str, alpha_ci: float = 0.05, bound: str = 'two-sided', method: str = 'lr') → Any

Likelihood-ratio confidence bounds on N or phi.

Parameters:

  • name ({'N', 'phi'}) – The parameter.

  • alpha_ci (float, optional) – The total tail probability of the bound(s). Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are an array [lower, upper]; a one-sided bound a number.

  • method ({'lr'}, optional) – Only the likelihood ratio: "wald" and "bootstrap" are refused, saying why.

Returns:

For N whole numbers, the upper one inf where the data do not bound the number of faults; for phi the lower one 0 where they do not bound it away from 0 (the same case).

Return type:

numpy.ndarray or float

Examples

>>> from surpyval.recurrent import JelinskiMoranda
>>> x = [3, 8, 12, 20, 25, 33, 41, 47, 58, 70, 81, 99]
>>> model = JelinskiMoranda.fit(x)
>>> model.param_cb("N")
array([12., inf])
>>> model.param_cb("N", alpha_ci=0.25, bound="upper")
20.0
>>> model.param_cb("phi").round(5)
array([0.     , 0.03788])
