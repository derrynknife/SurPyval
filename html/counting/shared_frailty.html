Shared Frailty (Poisson Processes Whose Units Differ)

A fleet whose units differ by more than their covariates explain: each unit (or cluster of units) has an unobserved frailty that multiplies its intensity, gamma or log-normal, whose variance theta is estimated with the intensity. It is fitted with frailty="gamma" (or "lognormal") and optionally cluster= on CrowAMSAA.fit, Duane.fit, CoxLewis.fit and ProportionalIntensityNHPP.fit; this is the model they return. A worked example is on Recurrent Event Modelling with SurPyval.

The fitted model

class surpyval.recurrent.shared_frailty.SharedFrailtyModel

Bases: SerialisableMixin, LikelihoodInferenceMixin

A fitted shared-frailty Poisson process: the result of fit(..., frailty="gamma") (or "lognormal") of CrowAMSAA, Duane, CoxLewis and ProportionalIntensityNHPP.

Each cluster (a unit by default, or the units cluster= groups) has an unobserved frailty u that multiplies its intensity, u lambda_0(t) exp(beta' Z); theta is the variance of u (of log u for the log-normal frailty), 0 where the clusters differ no more than Poisson counts do.

Predictions are either for the population of clusters (frailty=None: the frailty averaged over its distribution, whose mean is 1 for the gamma and exp(theta / 2) for the log-normal) or for a cluster of known frailty (frailty=u; frailties() gives each fitted cluster’s estimate). cif() and mcf() are the expected number of events by an age (the same function here, where nothing stops the events), iif() its rate.

Uncertainty: cif_cb(), iif_cb() and mcf_cb() are delta-method bounds; param_cb() gives Wald bounds (theta on the log scale) and profile-likelihood ones (method="lr"); frailty_test() is the likelihood-ratio test of theta = 0; forecast() gives the count of failures ahead with intervals that carry the frailty. Not offered: bootstrap bounds and diagnose(); the plain fits’ residual diagnostics assume Poisson counts, which is what this model drops (compare the fits with frailty_test(), aic() and frailties()).

Examples

Six systems watched to 60 hours, with 1 to 11 failures each (far more spread than Poisson counts of one mean would have):

>>> from surpyval.recurrent import CrowAMSAA
>>> import numpy as np
>>> counts = np.array([1, 1, 2, 3, 8, 11])
>>> x = np.concatenate(
...     [np.r_[60 * (np.arange(n) + 0.5) / n, 60] for n in counts]
... )
>>> i = np.repeat(np.arange(1, 7), counts + 1)
>>> c = (x == 60).astype(int)
>>> model = CrowAMSAA.fit(x, i, c, frailty="gamma")
>>> model.parameter_names
['alpha', 'beta', 'theta']
>>> [float(v) for v in model.frailties()["frailty"].round(2)]
[0.46, 0.46, 0.62, 0.78, 1.59, 2.08]
aic() → float

Akaike’s information criterion, \(2k - 2\ln L\), with k the number of fitted parameters. Lower is better. Call it, model.aic(), as on every other fitted model.

Changed in version 0.23: aic is a method, as on every other model (#572); it was a property.

aic_c() → float

The small-sample corrected AIC, aic() + (2k^2 + 2k) / (n - k - 1), with the k of aic() and the n of bic(); nan where n <= k + 1 (corrected_aic), as on every other model (#605).

property aliased: NDArray

The columns of Z whose coefficients the data cannot determine: nan in coeffs, taken as 0 in predictions.

property baseline_params: NDArray

The baseline intensity’s parameters.

bic() → float

The Bayesian information criterion, \(k \ln n - 2\ln L\), with n the number of observed events the model was fitted to: exact, left- and interval-censored, the last two adding the number of events they hold. End-of-observation rows do not add to it, and with no observed event it is the number of rows – the rule of BIC everywhere in SurPyval (see bic_sample_size()). Lower is better. Call it, model.bic(), as on every other fitted model.

Changed in version 0.23: bic is a method, as on every other model (#572); it was a property.

cif(x: ArrayLike, Z: Any = None, frailty: Any = None) → Any

  • Z (array_like, optional) – Covariates, for a model fitted with them: one row for every age, or one per age.

  • frailty (float or array_like, optional) – A cluster’s frailty; default the population average.

Returns:

The cumulative intensity, of the shape of x; nan outside the baseline’s support.

forecast(horizon: ArrayLike, age: ArrayLike | None = None, Z: Any = None, cluster: ArrayLike | None = None, limit: ArrayLike | None = None, alpha_ci: float = 0.05) → Any

Forecast the number of failures over the time ahead, with prediction intervals that carry the frailty: surpyval.forecast() for this model.

With age left out the units are those of the fitted data, each at the end of its observation, and each cluster’s frailty is that given its history (for the gamma frailty its count ahead is negative binomial). With age the units are new ones of the population, each its own cluster unless cluster groups them; a label of a fitted cluster stands for that cluster, with its history. The interval is that of the count at the fitted parameters, wider than a Poisson one by the frailty’s spread. It does not carry the parameters’ uncertainty: for one new unit that hardly matters, but a 95% interval for the fitted fleet’s total held 90% in the calibration study (the Poisson interval of the fit without frailty held 82%).

Parameters:

  • horizon (scalar or array_like) – The time ahead, or several increasing times ahead.

  • age (array_like, optional) – The current age of each unit; by default the fitted data’s units at the ends of their observation.

  • Z (array_like, optional) – Each unit’s covariates, with age, for a model that has them.

  • cluster (array_like, optional) – Each unit’s cluster, with age.

  • limit (scalar or array_like, optional) – An age past which a unit’s failures are not counted.

  • alpha_ci (float, optional) – The prediction intervals’ significance level. Default 0.05.

Returns:

As surpyval.forecast() returns.

Return type:

Forecast

Examples

>>> from surpyval.recurrent import CrowAMSAA
>>> import numpy as np
>>> counts = np.array([1, 1, 2, 3, 8, 11])
>>> x = np.concatenate(
...     [np.r_[60 * (np.arange(n) + 0.5) / n, 60] for n in counts]
... )
>>> i = np.repeat(np.arange(1, 7), counts + 1)
>>> c = (x == 60).astype(int)
>>> model = CrowAMSAA.fit(x, i, c, frailty="gamma")
>>> ahead = model.forecast(30.0)
>>> plain = CrowAMSAA.fit(x, i, c)
>>> import surpyval
>>> poisson = surpyval.forecast(plain, horizon=30.0)
>>> bool(ahead.variance[0] > poisson.variance[0])
True
frailties(alpha_ci: float = 0.05) → Any

Each fitted cluster’s predicted frailty: the mean of its frailty given its history (empirical Bayes), with an equal-tailed interval of that distribution.

For the gamma frailty a cluster with n events and cumulative intensity L (at frailty 1) has a gamma frailty given its history, of mean (n + 1/theta) / (L + 1/theta): its observed over its expected count, shrunk towards 1, and less so the more there is of its history. The interval is that of this distribution at the fitted parameters; it does not carry their uncertainty.

Parameters:

alpha_ci (float, optional) – The interval’s total tail probability. Default 0.05.

Returns:

One row per cluster: events, expected (its cumulative intensity at frailty 1), frailty, and lower <level> and upper <level>.

Return type:

pandas.DataFrame

frailty_test() → Any

The likelihood-ratio test of no frailty, theta = 0: do the clusters differ by more than Poisson counts would?

The statistic is twice the gain in log-likelihood over the model without frailty. theta = 0 is on the edge of its space, so under it the statistic is 0 half the time and \(\chi^2_1\) the other half (Self and Liang 1987): the p-value is half the \(\chi^2_1\) tail, and 1 where the estimate is 0.

Returns:

One row, theta = 0: statistic, p and reference (the null distribution).

Return type:

pandas.DataFrame

Examples

>>> from surpyval.recurrent import CrowAMSAA
>>> import numpy as np
>>> counts = np.array([1, 1, 2, 3, 8, 11])
>>> x = np.concatenate(
...     [np.r_[60 * (np.arange(n) + 0.5) / n, 60] for n in counts]
... )
>>> i = np.repeat(np.arange(1, 7), counts + 1)
>>> c = (x == 60).astype(int)
>>> model = CrowAMSAA.fit(x, i, c, frailty="gamma")
>>> test = model.frailty_test()
>>> round(float(test["p"].iloc[0]), 4)
0.0049

param_cb(name: str, alpha_ci: float = 0.05, bound: str = 'two-sided', method: str | None = 'wald') → NDArray

Confidence bound(s) on a named parameter.

  • "wald" (the default) – from the covariance, on the log scale for the positive parameters (theta among them) and the natural scale for the others. Where theta is estimated at 0 its bounds are nan.

  • "lr" – the profile-likelihood interval: the values whose deviance, every other parameter re-fitted, stays below the \(\chi^2_1\) critical value. Where it stays below it down to theta = 0 the lower bound on theta is 0. It needs the data, which a model restored from a dict does not keep.

Parameters:

  • name (str) – One of parameter_names.

  • alpha_ci (float, optional) – Total tail probability. Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are [lower, upper].

  • method ({'wald', 'lr'}, optional) – As above.

Returns:

The bound(s).

Return type:

numpy.ndarray

The frailty expectation

surpyval.recurrent.shared_frailty.mixed_poisson_log_moment(D: ArrayLike, A: ArrayLike, theta: float, family: str = 'gamma') → NDArray

log E[u^D e^{-A u}] for a frailty u of variance theta, elementwise: what a cluster with D events and cumulative intensity A (at u = 1) contributes to the marginal likelihood beside its events’ intensities.

Gamma (mean 1, variance theta): the closed form sum_{k<D} log(1 + k theta) - (D + 1/theta) log(1 + theta A). Log-normal (log u ~ N(0, theta)): the quadrature of log_frailty_integral(). theta = 0 is no frailty: -A.

Parameters:

  • D (array_like of int) – Counts of events, whole numbers of at least 0.

  • A (array_like) – Cumulative intensities, at least 0; broadcast with D.

  • theta (float) – The frailty variance (of log u for the log-normal).

  • family ({'gamma', 'lognormal'}, optional) – The frailty distribution. Default 'gamma'.

Returns:

The log-expectation, of the broadcast shape.

Return type:

numpy.ndarray

Examples

With no events it is the log of the gamma frailty’s Laplace transform, -log(1 + theta A) / theta:

>>> import numpy as np
>>> from surpyval.recurrent.shared_frailty import (
...     mixed_poisson_log_moment,
... )
>>> value = mixed_poisson_log_moment(0, 3.0, 0.5)
>>> bool(np.isclose(value, -np.log(1 + 0.5 * 3.0) / 0.5))
True
>>> # no frailty: a Poisson count's exp(-A)
>>> float(mixed_poisson_log_moment(2, 3.0, 0.0))
-3.0
