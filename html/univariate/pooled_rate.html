Pooled Rates Across Sources

The two-stage (hierarchical) pooling of event counts from several sources: gamma-Poisson for events in a time at risk, beta-binomial for events out of a number of trials. It gives the population (between-source) distribution, the average across sources, the range for a new source like these, each source’s own and shrunk estimate, and a heterogeneity test. The guide, in plain words and then the maths, is Pooling Rates Across Sources.

surpyval.pooled_rate(events: ArrayLike, exposure: ArrayLike, kind: Literal['rate', 'probability'] = 'rate', *, labels: Any = None, method: Literal['Bayes', 'MLE'] = 'Bayes', alpha_ci: float = 0.05, min_sources: int = 4, n_boot: int = 200, random_state: Any = None) → PooledRate

Pool event counts from several sources that may each have their own true rate: the two-stage (hierarchical) estimate of how the rate varies between sources.

Each source (a site, a hospital, a study, a fleet, a batch) gives the number of events it saw and its exposure: the total time at risk (kind="rate": events per unit of time, distance or person-years), or the number of trials (kind="probability": events per trial, such as failures to start per demand or adverse events per dose). Adding everything into one pot assumes every source has the same rate, and reports a precision nobody has when they differ. This treats the sources as a sample from a population of sources instead, estimates how their true rates are spread, and gives:

  • the population (between-source) distribution: a gamma for rates, a beta for probabilities;

  • the average across sources (the population mean) with its interval: how well the middle of the spread is known;

  • the range for a new source like these (the predictive interval): where the rate of one more source, about which nothing else is known, probably lies. It is wider, and is the one to use as a starting belief for a new source;

  • each source’s own estimate and interval, alone and shrunk (pulled towards the others: a source with little exposure is pulled a long way, one with a lot hardly at all);

  • a heterogeneity test and measures: do the sources differ by more than chance?

Parameters:

  • events (array like) – The number of events at each source (0 is allowed: a source with no events in a long exposure is evidence of a low rate).

  • exposure (array like) – Each source’s exposure: the total time at risk for kind="rate" (any unit; the rates are per that unit), or the number of trials (demands) for kind="probability".

  • kind ({"rate", "probability"}, optional) – "rate" (default): events in a time at risk, Poisson within a source, gamma between sources. "probability": events in a number of trials, binomial within a source, beta between sources.

  • labels (sequence, optional) – A name for each source; default "source 1", "source 2", …

  • method ({"Bayes", "MLE"}, optional) –

    How the population’s two parameters are estimated.

    • "Bayes" (default): their posterior on a grid under a weak prior (flat on the log of the mean rate, or the logit of the mean probability; 1 / (1 + a)^2 on the shape a). Every interval averages over that posterior, so it carries the uncertainty in how spread the sources are. Exact up to the grid, deterministic, and calibrated for small numbers of sources.

    • "MLE": marginal maximum likelihood (the negative binomial or beta-binomial likelihood, the empirical-Bayes estimate). The average’s interval is the profile-likelihood interval; the new source’s interval and the shrunk intervals average over a parametric bootstrap of the population (n_boot refits).

  • alpha_ci (float, optional) – Every interval is two-sided 1 - alpha_ci. Default 0.05 (95%); alpha_ci=0.1 gives the 5th to 95th percentiles usual for generic rate data.

  • min_sources (int, optional) – The fewest sources a population is estimated from. Default 4: with two or three, the spread between sources cannot be told apart from the sources themselves, and the range for a new source is very wide or wrong. With fewer, the result gives the sources side by side (each with its own interval), the one-pot estimate and the heterogeneity test, and no population, with a warning.

  • n_boot (int, optional) – The bootstrap refits for method="MLE". Default 200.

  • random_state (None, int or numpy.random.Generator, optional) – The seed of the bootstrap (method="MLE" only).

Return type:

PooledRate

Notes

For rates, source \(i\) has \(x_i\) events in exposure \(T_i\), \(x_i \sim \text{Poisson}(\lambda_i T_i)\), and the sources’ rates are a sample \(\lambda_i \sim \text{Gamma}(a, b)\) (shape \(a\), rate \(b\), mean \(a / b\)). With \(\lambda_i\) integrated out, \(x_i\) is negative binomial, and the likelihood of \((a, b)\) is the product over the sources. For probabilities, \(x_i \sim \text{Binomial}(n_i, p_i)\), \(p_i \sim \text{Beta}(a, b)\) and \(x_i\) is beta-binomial.

Given the population, a source’s own rate has the conjugate posterior \(\text{Gamma}(a + x_i, b + T_i)\) (or \(\text{Beta}(a + x_i, b + n_i - x_i)\)): the shrunk estimate. The new source’s distribution is the population itself. Under "Bayes" each is averaged over the posterior of \((a, b)\); under "MLE" over the bootstrap refits (the point values are the plug-in ones at the MLE). This is the “two-stage” or hierarchical Bayes treatment of generic data in probabilistic risk assessment (NUREG/CR-6823, chapter 8); its empirical-Bayes form fixes \((a, b)\) at their MLE.

The heterogeneity test is Pearson’s chi-square test that every source has one rate (k - 1 degrees of freedom; NUREG/CR-6823, section 6.2.3); it is approximate when the expected counts are small. \(I^2 = \max(0, (Q - \text{df}) / Q)\) is the share of the variation beyond chance (Higgins and Thompson 2002).

A source’s own interval is the Jeffreys interval (\(\text{Gamma}(x + 1/2, T)\), \(\text{Beta}(x + 1/2, n - x + 1/2)\)), which is defined with no events.

References

Atwood, C. L., LaChance, J. L., Martz, H. F., Anderson, D. J., Englehardt, M., Whitehead, D. and Wheeler, T. (2003), Handbook of Parameter Estimation for Probabilistic Risk Assessment, NUREG/CR-6823, US Nuclear Regulatory Commission, chapters 6 and 8.

Gaver, D. P. and O’Muircheartaigh, I. G. (1987), “Robust empirical Bayes analyses of event rates”, Technometrics 29, 1-15.

Gelfand, A. E. and Smith, A. F. M. (1990), “Sampling-based approaches to calculating marginal densities”, JASA 85, 398-409.

Higgins, J. P. T. and Thompson, S. G. (2002), “Quantifying heterogeneity in a meta-analysis”, Statistics in Medicine 21, 1539-1558.

Examples

Six sources of failures to start, out of a number of demands:

>>> from surpyval import pooled_rate
>>> pooled = pooled_rate(
...     [227, 137, 25, 3, 42, 6],
...     [410593, 49000, 2100, 260, 3700, 2400],
...     kind="probability",
...     alpha_ci=0.1,
... )
>>> p = pooled.predictive
>>> print(round(p["median"], 4), round(p["lower"], 5))
0.0046 0.00017
>>> print(round(p["upper"], 3))
0.026

property population: Any

The population (between-source) distribution, as a SurPyval Gamma (shape, rate) or Beta (a, b); None without a population, or for an MLE with no spread, whose population is the single value population_params["mean"].

Under "MLE" it is the MLE. Under "Bayes" the population averaged over the posterior is not exactly a gamma or beta; this is the gamma or beta with the same median and upper 1 - alpha_ci / 2 quantile as predictive (its upper side, which matters most, is kept). It updates with a new source’s own counts by conjugacy (see update() for the exact update).

property sources: pd.DataFrame

events, exposure, own (events / exposure) with its Jeffreys interval own_lower and own_upper, and shrunk (the posterior mean given the population) with shrunk_lower and shrunk_upper (nan without a population).

Type:

One row per source

to_dict() → dict

The result as a dict of native Python values, strict JSON (a non-finite number is written as None and recorded under "non_finite"). It holds the population’s parameter sets (posterior cells or bootstrap refits), so update() works on the restored result.

Examples

>>> import json
>>> from surpyval import pooled_rate, PooledRate
>>> pooled = pooled_rate([2, 5, 9, 4, 0], [1000, 1200, 900, 1500, 800])
>>> text = json.dumps(pooled.to_dict())
>>> back = PooledRate.from_dict(json.loads(text))
>>> back.predictive == pooled.predictive
True
