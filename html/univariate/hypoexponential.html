Hypoexponential Distribution

The sum of independent Exponential stages (the generalised Erlang): the lifetime of anything that must pass through several memoryless stages in series – a load-sharing group whose rate changes as members fail, a warm or hot standby system. The number of stages is not fixed: from_params takes any number of rates, and the model carries that many parameters, lambda_1 ... lambda_m. Rates may repeat; equal rates are the Erlang case, a Gamma with an integer shape.

fit(x, ..., stages=m) estimates the m rates from data, with every kind of censoring and truncation, an offset, a limited failure population and zero inflation, and reports them slowest stage first. The number of stages is not estimated: compare fits with different numbers by their AIC. A fit with more stages than the data support warns that a rate runs to infinity.

class surpyval.univariate.parametric.distributions.hypoexponential.Hypoexponential_(name: str, m: int = 0)

Bases: OptimisedFitMixin, ParametricFitter

Class used to generate the Hypoexponential class: the sum of independent Exponential stages.

The singleton has no fixed parameter count – from_params takes any number of rates, and fit the number of stages, and the model either returns has that many parameters, named lambda_1 ... lambda_m. The distribution functions take the rates as the parameters: Hypoexponential.sf(x, 0.5, 1.5, 3.0).

Examples

Two stages in series, with mean times 2 and 2/3:

>>> from surpyval import Hypoexponential
>>> model = Hypoexponential.from_params([0.5, 1.5])
>>> model.sf([1, 2, 4]).round(4)
array([0.7982, 0.5269, 0.2018])
>>> round(float(model.mean()), 4)
2.6667

Fitted to data, with the number of stages given:

>>> x = Hypoexponential.random(500, 0.5, 2.0, random_state=3)
>>> Hypoexponential.fit(x, stages=2).params.round(3)
array([0.504, 1.827])

cs(x: NDArray | float, given: NDArray | float, *params: Any) → Any

Conditional survival function: the probability of surviving a further x given survival to given already.

\[R(x, given) = \frac{R(x + given)}{R(given)} = e^{-(H(x + given) - H(given))}\]

It is computed from the cumulative hazard, the second form, so it stays exact where \(R(given)\) underflows to 0 far in the upper tail (the ratio was nan there); it is nan only where \(H(given)\) is itself infinite. This is the definition for every distribution, so it lives here rather than being restated on each one. Exponential overrides it because the exponential is memoryless and \(R(x, given) = R(x)\), which is both cheaper and free of the cancellation the difference suffers in the far tail.

Changed in version 0.24: From the cumulative hazard, so finite where sf(given) underflows (#660).

Changed in version 0.22: The time already survived is given (it was X), the name the regression models’ sf_tvc(..., given=) uses.

Changed in version 0.23: X is removed.

Parameters:

  • x (numpy array or scalar) – The additional time to survive, measured from given

  • given (numpy array or scalar) – The time already survived

  • *params (numpy array like or scalar) – The parameters of the distribution, in the order given by its parameter_names

Returns:

cs – The value(s) of the conditional survival function.

Return type:

scalar or numpy array

Examples

>>> import numpy as np
>>> from surpyval import Weibull
>>> x = np.array([1, 2, 3, 4, 5])
>>> Weibull.cs(x, 5, 3, 4)
array([2.52537548e-04, 3.00394073e-10, 2.45288508e-19, 1.48999440e-32,
       5.42544000e-51])

ff(x: NDArray | float, *rates: NDArray | float | ArrayBox) → NDArray | float | ArrayBox

Failure (CDF or unreliability) function for the Hypoexponential Distribution:

\[F(x) = 1 - \sum_{j=1}^{m} C_j e^{-\lambda_j x} = -\sum_{j=1}^{m} C_j \left(e^{-\lambda_j x} - 1\right)\]

Near the origin (lambda_max x <= 1), where the partial fractions cancel, it is summed as its power series, which keeps its relative precision down to underflow; beyond that it is evaluated in the second form (expm1).

Parameters:

  • x (numpy array or scalar) – The values at which the function will be calculated

  • rates (numpy array or scalars) – The stage rates lambda_1, ..., lambda_m

Returns:

ff – The value(s) of the failure function at x.

scalar or numpy array

fit(x: ArrayLike | None = None, c: ArrayLike | None = None, n: ArrayLike | None = None, t: ArrayLike | None = None, how: str = 'MLE', offset: bool = False, zi: bool = False, lfp: bool = False, tl: ArrayLike | float | None = None, tr: ArrayLike | float | None = None, xl: ArrayLike | None = None, xr: ArrayLike | None = None, fixed: dict[str, float] | None = None, heuristic: str = 'Nelson-Aalen', init: ArrayLike = [], rr: str = 'y', on_d_is_0: bool = False, turnbull_estimator: str = 'Fleming-Harrington', w: ArrayLike | float | None = None, hr: float | None = None, *, stages: int | None = None, unit=None) → Parametric

Fit a hypoexponential with a given number of stages to data.

The stages rates are estimated together, by maximum likelihood by default, with every kind of censoring, truncation, counts, weights, an offset, a limited failure population and zero inflation, as for every other distribution (see Weibull.fit). The rates are exchangeable – the sum of the stages does not depend on their order – and are reported from the slowest stage to the fastest. They may come out equal, an Erlang stretch of the chain. A likelihood that keeps rising as a rate runs to infinity says the data need fewer stages, and the fit warns so. Choose the number of stages by comparing the fits’ AIC.

Probability plotting (how='MPP') is not available: the distribution has no straight-line probability plot.

Fit the distribution by Bayes’ rule: the prior times the likelihood of the data, which is the likelihood fit uses for every kind of censoring and truncation.

Returns a BayesianParametric, used like any model: its sf, qf, mean and random are those of a new unit’s life with the uncertainty in the parameters averaged in (the posterior predictive), and cri, quantile_cri, mean_cri and param_cri give credible intervals. fit is unchanged; all the work is in surpyval.bayes.

  • c – The data, as for fit; x may be a SurpyvalData.

  • n – The data, as for fit; x may be a SurpyvalData.

  • t – The data, as for fit; x may be a SurpyvalData.

  • tl – The data, as for fit; x may be a SurpyvalData.

  • tr – The data, as for fit; x may be a SurpyvalData.

  • offset – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

Fit to data held in the columns of a pandas.DataFrame.

The column names are passed in place of the arrays fit() takes; every other fit() option can be passed as a keyword. The columns are handed to fit() as they are, so the result, and the treatment of a missing value, is that of fit() on the same arrays.

Parameters:

  • x_col (string, optional) – column name for the column in df containing the variable data. If not provided must provide both xl_col and xr_col.

  • c_col (string, optional) – column name for the column in df containing the censor flag of x. If not provided assumes all values of x are observed.

  • n_col (string, optional) – column name in for the column in df containing the counts of x. If not provided assumes each x is one observation.

  • xl_col (string, optional) – column name for the column in df containing the left interval for interval censored data. If left interval is -Inf, assumes left censored. If xl[i] == xr[i] assumes observed.   • tl_col (string or scalar, optional) – If a string, the column of the left truncation of each row. If a number, every row is left truncated at that value (a constant truncation). If not provided, x is not left truncated.

  • tr_col (string or scalar, optional) – If a string, the column of the right truncation of each row. If a number, every row is right truncated at that value. If not provided, x is not right truncated.

  • w_col (string, optional) – column name for the sampling, propensity or censoring weights, passed to fit() as w (for the fitters that take it).

  • fit_options (dict, optional) – Every other option of fit() (how, offset, fixed, dist, …), passed to it unchanged.

Returns:

The model fit() returns.

Return type:

model

Raises:

ValueError – If df is not a DataFrame, a name is not one of its columns, a row has none of x_col, xl_col and xr_col, or a column is given that fit() has no argument for.

fit_from_ecdf(x: ArrayLike, F: ArrayLike) → Parametric

Fit the distribution to points of an empirical CDF by probability plotting.

The points (x, F) are transformed to the distribution’s probability-plot axes and a straight line is fitted through them by least squares (the how='MPP' regression with rr='y', but on the CDF values given rather than on plotting positions computed from data). Points with F equal to 0 or 1 cannot be transformed and are left out. Only distributions that support how='MPP' can be fitted this way.

Parameters:

  • x (array like) – The values at which the CDF is known.

  • F (array like) – The CDF at each x, between 0 and 1, of the same length as x.

Returns:

A model whose method is 'given ecdf'. It holds no data, so it has no likelihood, information criteria or confidence bounds.

Return type:

Parametric

Raises:

ValueError – If x and F differ in length, an F is NaN or outside [0, 1], or F falls as x rises (a survival curve R passed in its place: pass 1 - R).

Examples

>>> from surpyval import Weibull
>>> model = Weibull.fit_from_ecdf([1, 2, 3, 4], [0.1, 0.3, 0.6, 0.9])
>>> model.params
array([2.96150944, 2.1761779 ])

isf(s: NDArray | float, *params: Any) → Any

The inverse survival function: the time at which the survival function is s (scipy’s name), qf(1 - s) without rounding 1 - s.

mrl(x: NDArray | float, *params: Any) → Any

Mean residual life: the expected remaining life of a unit that has survived to x,

\[\mathrm{MRL}(x) = E[T - x \mid T > x] = \frac{1}{R(x)} \int_x^\infty R(u)\, du ,\]

so mrl(0) of a lifetime is its mean, and below the support’s start mrl(x) = mean - x. It is in closed form for the Exponential (1 / failure_rate, memoryless) and the Weibull (an upper incomplete gamma function); otherwise it is the integral of the conditional survival cs(), finite far in the tail where R(x) underflows, or for a discrete distribution the sum over the integers. qf(u: NDArray | float, *rates: NDArray | float | ArrayBox) → NDArray | float | ArrayBox

Quantile function for the Hypoexponential distribution, the inverse of ff. There is no closed form; the failure function is inverted by bisection – on log F against log u below u = 1/2 and on log R against log(1 - u) above it, so a tiny probability keeps its digits – between the bounds

\[\frac{-\ln(1 - u)}{\lambda_{\min}} \le q(u) \le \frac{m}{\lambda_{\min}} \ln \frac{m}{1 - u},\]

the left from the slowest stage alone (the sum exceeds it) and the right from a union bound over the stages. u = 0 gives 0 and u = 1 gives inf.

sf(x: NDArray | float, *rates: NDArray | float | ArrayBox) → NDArray | float | ArrayBox

Survival (or reliability) function for the Hypoexponential Distribution:

\[R(x) = \sum_{j=1}^{m} C_j e^{-\lambda_j x}, \qquad C_j = \prod_{l \neq j} \frac{\lambda_l}{\lambda_l - \lambda_j}\]

Evaluated as 1 - F(x) while F(x) < 1/2 – F is exact at the origin, so R(0) = 1 exactly – and beyond that as the signed sum above with the slowest stage’s exponential factored out, which keeps its relative precision in the tail; the sum is clipped at 0 against the floating-point cancellation of its terms (see _pieces).

Parameters:

  • x (numpy array or scalar) – The values at which the function will be calculated

  • rates (numpy array or scalars) – The stage rates lambda_1, ..., lambda_m

Returns:

sf – The value(s) of the reliability function at x.

Return type:

scalar or numpy array

>>> from surpyval import Hypoexponential
>>> x = np.array([1, 2, 3, 4, 5])
>>> Hypoexponential.sf(x, 0.5, 1.5, 3.0)
