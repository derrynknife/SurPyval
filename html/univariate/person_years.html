Exposure (Person-Years) Tables

The total time at risk, the events and the units in each cell of a cross-classification by fixed factors and by time bands the units move through (attained age, calendar period, time since entry), with each cell’s event rate and its exact bounds, rate ratios between cells, and observed to expected ratios given reference rates. Worked examples are in Non-Parametric SurPyval Modelling.

surpyval.person_years(x: Any, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None, *, factors: Mapping[str, Any] | None = None, timescales: Mapping[str, Any] | None = None, rates: Any = None, per: float = 1.0, alpha_ci: float = 0.05) → PersonYears

The exposure (person-years) table of right censored, possibly late-entry data: in each cell of a cross-classification, the total time the units were followed there, the number of events there and the number of units that spent time there, with the event rate and its exact confidence bounds. As R’s survival::pyears.

The cells are formed by factors, fixed for each unit (a site, a model, a sex), and by time scales cut into bands (attained age, calendar period, time since entry, operating hours since overhaul). A unit moves through the bands of a time scale as it is followed: a pump followed from 3,000 to 7,000 operating hours, with bands every 2,000 hours, spends 1,000 hours in the 2,000-4,000 band, 2,000 in the 4,000-6,000 band and 1,000 in the 6,000-8,000 band; its event (or its censoring) is in the band it is in when it happens. R’s tcut does this; a band read from each unit’s value at the start (cut(age, ...)) would put all its time in one band.

Parameters:

  • x (array like) – The time each unit’s follow-up ends (its event or its censoring), on the time scale of the data: time since each unit’s origin (installation, birth, diagnosis, the start of a study). The rows are matched to the factors and start values by position, so a SurpyvalData (which sorts its rows) is refused; pass the arrays.

  • c (array like, optional) – The censoring flags: 0 an event, 1 right censored (followed to x with no event). Left (-1) and interval (2) censored rows are refused: their exposure ends at an unknown time.

  • n (array like, optional) – The count of each row: n = k is k identical units. Default 1.

  • tl (array like or float, optional) – Each unit’s entry time (late entry, left truncation), on the same scale as x: the unit is followed on (tl, x]. Default 0.

  • factors (dict, optional) – {name: labels}: a fixed classification of the units, one label per row (strings, numbers or a pandas.Categorical, whose category order is kept; otherwise the levels are sorted).

  • timescales (dict, optional) – {name: (start, breaks)} (or {name: {"start": ..., "breaks": ...}}): a time scale that runs with the follow-up. start is each unit’s value on it at time 0 of x (a number, or one per row): its value at time t is start + t. Age at time 0 for attained age; the calendar date at time 0 for calendar period; 0 for the time scale of x itself; -tl for time since entry. breaks are the increasing band edges (the last may be inf); the bands are (b_j, b_{j+1}], so an event exactly on an edge is in the band that ends there, as in R. Time before the first edge or after the last is off the table: counted in PersonYears.offtable, with a warning.

  • rates (DataFrame, dict, float or None, optional) – Reference rates, to give each cell’s expected events and the observed to expected ratio (a standardised incidence or mortality ratio). A single rate for every cell, or a table: a pandas.DataFrame (or a dict of columns) with a column "rate" and one column for each of the factors and time scales it varies by (a subset of them). A time scale’s column holds each band’s lower edge, as the table’s does. Every cell must find one rate. The rates are in the units of the table’s rates: events per per units of time.

  • per (float, optional) – The rates are per per units of the time of x: per=1000 gives failures per 1,000 hours when x is in hours. Default 1. The exposure stays in the units of x.

  • alpha_ci (float, optional) – The bounds are two-sided 1 - alpha_ci intervals. Default 0.05.

Returns:

The table (PersonYears.table), one row per cell, every combination of the levels and bands (cells with no time included), with the columns:

  • one per factor (its label) and one per time scale (its band’s lower edge), followed by <name>_end (the upper edge) for each time scale;

  • units: the units (the sum of n) that spent time in the cell; a unit is counted in each cell it passes through;

  • exposure: the total time at risk in the cell, in the units of x;

  • events: the events in the cell;

  • rate, rate_lower, rate_upper: events / exposure times per, with its exact Garwood bounds (nan with no exposure);

  • with rates: expected (the reference rate times the exposure, divided by per), oe_ratio (events / expected) and its exact bounds oe_lower and oe_upper (the Garwood bounds of the events divided by the expected).

Return type:

PersonYears

Notes

Each unit’s follow-up (tl, x] is cut where any of its time scales crosses a band edge, and each piece is added to the cell it lies in. The event rate of a cell is the maximum likelihood estimate of a constant hazard there, d / T. Its exact bounds treat d as Poisson with mean lambda T (Garwood 1936): with chi2_{k, p} the p quantile of a chi-square on k degrees of freedom,

\[\left[\frac{\chi^2_{2d,\ \alpha/2}}{2T},\ \frac{\chi^2_{2d+2,\ 1-\alpha/2}}{2T}\right].\]

With rates, the expected events of a cell are E = r T, and the observed to expected ratio d / E has the bounds above times T / E (Breslow and Day 1987, section 2.3), E taken as known. The rate table’s resolution is the table’s: a reference rate that changes within a cell is approximated by one value there (R’s pyears integrates a finer rate table along each unit’s path); cut the time scales at the rate table’s edges for the exact expected count, and add up the cells.

References

Garwood, F. (1936), “Fiducial limits for the Poisson distribution”, Biometrika 28, 437-442.

Breslow, N. E. and Day, N. E. (1987), Statistical Methods in Cancer Research, Volume II: The Design and Analysis of Cohort Studies, IARC, chapter 2.

Berry, G. (1983), “The analysis of mortality by the subject-years method”, Biometrics 39, 173-184.

Examples

Four pumps at two sites, followed from installation (hours), with bands of operating age:

>>> import surpyval
>>> x = [1500, 4200, 2500, 6000]
>>> c = [0, 1, 0, 0]
>>> site = ["A", "A", "B", "B"]
>>> py = surpyval.person_years(
...     x, c,
...     factors={"site": site},
...     timescales={"age": (0, [0, 2000, 4000, 8000])},
...     per=1000,
... )
>>> cols = ["site", "age", "units", "exposure", "events", "rate"]
>>> py.table[cols].round(3)
  site     age  units  exposure  events   rate
0    A     0.0      2    3500.0       1  0.286
1    A  2000.0      1    2000.0       0  0.000
2    A  4000.0      1     200.0       0  0.000
3    B     0.0      2    4000.0       0  0.000
4    B  2000.0      2    2500.0       1  0.400
5    B  4000.0      1    2000.0       1  0.500

Site B’s failure rate over site A’s, with its exact bounds:

>>> ratio = py.rate_ratio({"site": "B"}, {"site": "A"})
>>> print(round(ratio["ratio"], 3), round(ratio["upper"], 1))
1.341 79.1

rate_ratio(cells: Mapping[str, Any], reference: Mapping[str, Any]) → dict

The ratio of the event rate in cells to that in reference, with its exact confidence bounds and the exact test of equal rates.

Each of cells and reference picks cells by their labels, {"site": "B"} or {"site": "B", "age": 2000} (a time scale by its band’s lower edge); a dimension left out is added up over. Given the total N = d_1 + d_0 events in the two, d_1 is binomial with probability rho T_1 / (rho T_1 + T_0): the Clopper-Pearson bounds of that probability give the bounds of the ratio rho, and the exact binomial test of T_1 / (T_1 + T_0) gives the p-value, as R’s poisson.test with two counts (the conditional test, Breslow and Day 1987, section 2.4).

Parameters:

  • cells (dict) – The labels picking the two sets of cells; they must not share a cell.

  • reference (dict) – The labels picking the two sets of cells; they must not share a cell.

Returns:

ratio, lower, upper (the 1 - alpha_ci bounds), p_value (two-sided), and each side’s events and exposure. With no events in either, the ratio is nan with bounds [0, inf] and p_value 1.

Return type:

dict

The exact (Garwood) bounds of a single rate:

surpyval.poisson_rate_bounds(events: ArrayLike, exposure: ArrayLike, alpha_ci: float = 0.05) → tuple[NDArray, NDArray]

The exact (Garwood) two-sided confidence bounds of a Poisson rate, events / exposure.

The lower bound is the rate at which seeing events or more has probability alpha_ci / 2, the upper the rate at which seeing events or fewer has that probability:

\[\frac{\chi^2_{2d,\ \alpha/2}}{2T}, \qquad \frac{\chi^2_{2d + 2,\ 1 - \alpha/2}}{2T},\]

with a lower bound of 0 when d = 0 (Garwood 1936; R’s poisson.test). Their coverage is at least 1 - alpha_ci for every true rate.

Parameters:

  • events (array like) – The number of events (whole or not: a count given with weights n that are not whole is used as it is).

  • exposure (array like) – The total time at risk, in any unit; the bounds are per that unit.

  • alpha_ci (float, optional) – The bounds are a two-sided 1 - alpha_ci interval. Default 0.05.

Returns:

lower, upper – The bounds, nan where the exposure is 0.

Return type:

ndarray

Examples

>>> from surpyval import poisson_rate_bounds
>>> lower, upper = poisson_rate_bounds(3, 1000.0)
>>> print(round(float(lower), 6), round(float(upper), 6))
0.000619 0.008767
