Royston-Parmar Flexible Parametric Model

The Royston-Parmar flexible parametric model: a natural cubic spline for the log cumulative hazard (or log odds, or probit) in log time, spanning the space between a fitted distribution and a non-parametric estimate.

class surpyval.univariate.parametric.royston_parmar.RoystonParmar_

Bases: FitterRepr, UnivariateDataFrameMixin

Fitter for RoystonParmarModel. Use the singleton RoystonParmar.

The Royston-Parmar model is a restricted cubic spline in log time on the log cumulative hazard (scale="hazard"), log cumulative odds or probit scale: a smooth parametric survival curve whose flexibility is set by df. df=1 is a Weibull (on the hazard scale).

Examples

>>> import numpy as np
>>> from surpyval import RoystonParmar
>>> rng = np.random.default_rng(0)
>>> x = 10 * rng.weibull(2, 50)
>>> model = RoystonParmar.fit(x, df=3)
>>> model.sf([5, 10]).round(4)
array([0.8029, 0.4131])
fit(x: Any = None, c: Any = None, n: Any = None, t: Any = None, xl: Any = None, xr: Any = None, tl: Any = None, tr: Any = None, df: int = 3, scale: str = 'hazard', knots: Any = None, *, unit=None) → RoystonParmarModel

Fit a Royston-Parmar model by maximum likelihood.

Accepts the full SurpyvalData censoring/truncation surface: observed, right-, left- and interval-censored observations, with left- and/or right-truncation (delayed entry and right-truncated sampling).

Parameters:

  • x (array_like) – Observed times (strictly positive). For interval-censored rows the entry is a 2-element [left, right] pair (see c).

  • c (array_like, optional) – Censoring flags: 0 event, 1 right-censored, -1 left-censored, 2 interval-censored. Default all events.

  • n (array_like, optional) – Observation weights / counts. Default 1.

  • t (array_like, optional) – (m, 2) array of [left, right] truncation bounds per row. Mutually exclusive with tl / tr.

  • xl (array_like, optional) – Left/right interval bounds for interval-censored data, as an alternative to passing 2-element x rows.

  • xr (array_like, optional) – Left/right interval bounds for interval-censored data, as an alternative to passing 2-element x rows.

  • tl (array_like or scalar, optional) – Left- and right-truncation bounds. A scalar truncates every observation at that value.

  • tr (array_like or scalar, optional) – Left- and right-truncation bounds. A scalar truncates every observation at that value.

  • df (int, optional) – Degrees of freedom = number of spline terms beyond the intercept; df - 1 internal knots. df = 1 is a Weibull (scale = hazard) or log-normal (scale = normal). Default 3.

  • scale ({"hazard", "odds", "normal"}, optional) – The link scale (proportional hazards, proportional odds, probit).

  • knots (array_like, optional) – Explicit knot locations on the log-time scale (including the two boundary knots), overriding the quantile-based default. They are sorted (the spline parameters follow the sorted knots) and must be finite and distinct.

classmethod fit_from_df(df: pd.DataFrame, x_col: str | None = None, c_col: str | None = None, n_col: str | None = None, xl_col: str | None = None, xr_col: str | None = None, tl_col: str | float | None = None, tr_col: str | float | None = None, w_col: str | None = None, *, unit=None, **fit_options: Any) → Any

Fit to data held in the columns of a pandas.DataFrame.

The column names are passed in place of the arrays fit() takes; every other fit() option can be passed as a keyword. The columns are handed to fit() as they are, so the result, and the treatment of a missing value, is that of fit() on the same arrays.

Parameters:

  • df (DataFrame) – DataFrame of data to be used to create surpyval model

  • x_col (string, optional) – column name for the column in df containing the variable data. If not provided must provide both xl_col and xr_col.

  • c_col (string, optional) – column name for the column in df containing the censor flag of x. If not provided assumes all values of x are observed.

  • n_col (string, optional) – column name in for the column in df containing the counts of x. If not provided assumes each x is one observation.

  • xl_col (string, optional) – column name for the column in df containing the left interval for interval censored data. If left interval is -Inf, assumes left censored. If xl[i] == xr[i] assumes observed. Provided with xr_col; provided with x_col too, each row is an exact time in x_col or a range in xl_col and xr_col, the other blank (a row giving both is left out, with a warning).

  • xr_col (string, optional) – column name for the column in df containing the right interval for interval censored data. If right interval is Inf, assumes right censored. If xl[i] == xr[i] assumes observed. Provided with xl_col; with x_col, as for xl_col.

  • tl_col (string or scalar, optional) – If a string, the column of the left truncation of each row. If a number, every row is left truncated at that value (a constant truncation). If not provided, x is not left truncated.

  • tr_col (string or scalar, optional) – If a string, the column of the right truncation of each row. If a number, every row is right truncated at that value. If not provided, x is not right truncated.

  • w_col (string, optional) – column name for the sampling, propensity or censoring weights, passed to fit() as w (for the fitters that take it).

  • fit_options (dict, optional) – Every other option of fit() (how, offset, fixed, dist, …), passed to it unchanged.

Returns:

The model fit() returns.

Return type:

model

Raises:

ValueError – If df is not a DataFrame, a name is not one of its columns, a row has none of x_col, xl_col and xr_col, or a column is given that fit() has no argument for.

Notes

Every DataFrame entry point names its columns with a _col suffix (principle 21).

Examples

>>> from surpyval.datasets import load_bofors_steel
>>> df = load_bofors_steel()
>>> model = surv.Weibull.fit_from_df(
...     df, x_col='x', n_col='n', offset=True
... )
>>> print(model)

class surpyval.univariate.parametric.royston_parmar.RoystonParmarModel

Bases: ParameterBoundsMixin, InformationCriteriaMixin, SerialisableMixin

A fitted Royston-Parmar flexible parametric model.

Carries the spline knots, the coefficients params (gamma), the link scale, and (for a maximum-likelihood fit) the coefficient covariance for confidence bounds. Exposes the usual distribution surface: sf(), ff(), hf(), Hf(), df(), qf(), random(), mean(), and cb().

Examples

RoystonParmar.fit returns one. Here with one internal knot (df=2) on the Rossi recidivism data, where arrest is 1 for an arrest (so the censoring flag is 1 - arrest):

>>> from surpyval import RoystonParmar
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> model = RoystonParmar.fit(x, c=c, df=2)
>>> model.params.round(4)
array([-6.9934,  1.5755,  0.0377])
>>> model.sf([20, 52]).round(4)
array([0.9182, 0.7365])
>>> model.cb([20, 52]).round(4)
array([[0.8915, 0.9386],
       [0.6923, 0.7754]])

Notes

The correction \((2k^2 + 2k)/(N - k - 1)\) uses the same sample size \(N\) as bic(): the number of observed failures (exact, left- or interval-censored, weighted by their counts), or the number of units when there is none. Right-censored units do not add to it. The correction only exists for \(N > k + 1\); otherwise the corrected criterion is undefined and nan is returned (the formula gave inf at \(N = k + 1\), and a value below aic() for smaller \(N\), which would have won a comparison).

References

Bayesian Information Criterion for Censored Survival Models.

Notes

The sample size \(d\) in the penalty \(k \ln d\) is the number of observed failures: every unit whose failure was observed, exactly or within a left- or interval-censored window, weighted by its count; right-censored units add nothing. Should that be zero, the number of units is used instead, so the criterion is always finite. Every model in SurPyval that reports a BIC counts \(d\) this way (see “Information criteria” in the Parametric Estimation guide).

cb(x: Any, on: str = 'sf', alpha_ci: float = 0.05, bound: str = 'two-sided') → ndarray

Confidence bound on a function, via the linear predictor.

The bound is formed on the (unbounded) linear predictor eta – whose variance is B Sigma B' from the covariance – and then pushed through the link, so sf / ff bounds stay in (0, 1). S is monotone decreasing in eta on every scale. At and before time 0, and at infinity, there is no spline (it is in log x): both ends of the band are sf there, 1 and 0.

Parameters:

  • x (array like or scalar) – The times at which to bound the function.

  • on ({'sf', 'ff', 'Hf'}, optional) – The function to bound ('R' and 'F' are aliases of 'sf' and 'ff'). Default 'sf'.

  • alpha_ci (float, optional) – The total tail probability of the bound(s). Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are [lower, upper] on the last axis; a one-sided bound at alpha_ci is the matching end of the two-sided bound at 2 * alpha_ci.

covariance() → ndarray

The spline coefficients’ covariance, in the order of params (#605). It was an attribute before v0.23.

Raises a ValueError where the model has none (its information was singular, or it was built from coefficients by with_params()).

property covariance_names: list[str]

hf(x: Any) → ndarray

Hazard rate df(x) / sf(x): 0 at and before time 0, and at infinity its limit along the spline, quietly.

It is taken as one exponential of the logs of its terms, which keeps its value where the density and the survival have both underflowed in the tail (a 0/0 there, nan with a warning). Beyond the last knot the spline is linear in log x, with slope s, so on the hazard scale the hazard there is a Weibull’s of shape s, and its limit is inf for s > 1, 0 for s < 1 and the constant itself for s = 1; on the odds and normal scales it falls to 0, as a LogLogistic’s and a LogNormal’s do. Infinity was 0/0 too (#777).

property parameter_bounds: list[tuple[float | None, float | None]]

one (low, high) pair per entry of the vector with_params() takes, in the order of covariance_names (None for an end with no bound).

A parameter set drawn inside these ranges is one with_params does not refuse for being out of range, and one just outside a finite end is refused. Draw a parameter bounded on one side on the log scale of its distance from that end, and one bounded on both on the logit scale between them. Whether an end itself is allowed depends on the parameter (a probability may be 0 where a scale may not), so keep draws strictly inside.

A few models also constrain their parameters jointly, which no per-parameter range can say, and with_params refuses a set that breaks the joint constraint, saying so: a mixture’s weights sum to 1; a Uniform’s a is below its b (as a Beta4’s are); a Royston-Parmar spline does not fall; a Binomial’s n is a whole number. The entry of a parameter with_params ignores (held fixed in the fit, or an accelerated life model’s life parameter) gives the parameter’s range all the same. An accelerated life model’s life-model parameters can have ranges that depend on the stresses fitted to; a model loaded from a dict saved without its data gives them as unbounded.

Examples

>>> from surpyval import Weibull, WeibullPH
>>> Weibull.from_params([10.0, 2.0]).parameter_bounds
[(0.0, None), (0.0, None)]
>>> model = WeibullPH.fit(
...     x=[1.0, 2, 3, 4, 5, 6, 7, 8], Z=[0.0, 1, 0, 1, 0, 1, 1, 0]
... )
>>> model.covariance_names
['alpha', 'beta', 'coef_0']
>>> model.parameter_bounds
[(0.0, None), (0.0, None), (None, None)]
Type:

The range of each parameter

property parameter_names: list[str]

the spline coefficients gamma_0, gamma_1, …, as the summary prints them.

Type:

qf(p: Any) → ndarray

Quantile function: the time at which ff(x) = p; 0 at p = 0 and inf at p = 1.

Solved for every probability at once on the link scale, where the spline is: the linear predictor that gives ff = p is found in log time, in closed form beyond the boundary knots (where the spline is a straight line) and between them by solve_bracketed, to a relative precision of about 1e-15 in time. A brentq per probability on sf took 1-3 s for 2000 draws (#595), and lost precision for a p near 0, where sf rounds to 1.

random(size: int, *, random_state: Any = None) → ndarray

Draw size random lifetimes (by inverting ff).

random_state (an int or a numpy.random.Generator) gives a draw of its own, which neither depends on nor advances numpy’s global stream; None (the default) draws from the global stream, so np.random.seed reproduces it.

sf(x: Any) → ndarray

Survival function at x: 1 at and before time 0 (the spline is in log x, which does not exist there, so this came back nan) and 0 at infinity, as in the likelihood (see _sf_at).

with_params(params: ArrayLike) → RoystonParmarModel

The same spline – its knots, link scale and unit – with other coefficients: for drawing a fit’s coefficients from its covariance and carrying them into a prediction, say.

The knots are the fit’s (they were placed from its data, so they are part of the model, not of the coefficients). The model returned has no data, covariance or fitted likelihood, since those belong to the fit of the original coefficients: cb, standard_errors, neg_ll, aic and bic are not available on it, while sf, ff, hf, Hf, df, qf, random and mean are. A fit with weights has none either: the model is just the spline at these coefficients.

Parameters:

params (array like) – The spline coefficients, one per knot, in the order of covariance_names (as a draw from covariance() comes).

Returns:

A model built from the coefficients.

Return type:

RoystonParmarModel

Raises:

ValueError – Where params has the wrong length or a value that is not finite, or where the coefficients are not a survival distribution: the spline must not fall anywhere in log time (its slope is the hazard’s shape), and must rise beyond both boundary knots, or the cumulative hazard would decrease somewhere or the survival would not run from 1 to 0. A draw from the covariance of a fit to little data can do that; the message says where. Such a draw is to be left out (and counted); where many are, the spline has more knots than the data support, and a fit with a smaller df is the remedy.

Examples

>>> from surpyval import RoystonParmar
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> model = RoystonParmar.fit(x, c=c, df=2)
>>> same = model.with_params(model._estimates())
>>> bool((same.sf([20, 52]) == model.sf([20, 52])).all())
True
>>> other = model.with_params([-7.0, 1.6, 0.04])
>>> other.sf([20, 52]).round(4)
array([0.9138, 0.7215])
