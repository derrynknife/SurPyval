Degenerate Distributions

The two boundary cases: an event that has already occurred, and an event that never occurs. Useful as components of mixtures and competing-risk structures.

class surpyval.univariate.parametric.distributions.degenerate.InstantlyOccurs

Bases: _PointMass

The event has already occurred: F(x) = 1 everywhere (mass at 0).

Stateless: the class itself is the model, with nothing to fit.

Examples

>>> from surpyval import InstantlyOccurs
>>> InstantlyOccurs.ff([0, 1, 10])
array([1., 1., 1.])
>>> InstantlyOccurs.sf([0, 1, 10])
array([0., 0., 0.])
>>> InstantlyOccurs.mean()
0.0

classmethod rescale_time(factor: float, *, unit: Any = None) → type[Distribution]

The distribution on another clock (see Parametric.rescale_time): itself, as a point mass at 0 or at infinity is there on every clock. factor is checked as there. The class carries no unit, so unit is refused.

Examples

>>> from surpyval import NeverOccurs
>>> NeverOccurs.rescale_time(24) is NeverOccurs
True

class surpyval.univariate.parametric.distributions.degenerate.NeverOccurs

Bases: _PointMass

The event never occurs: R(x) = 1 everywhere (mass at +inf).

Stateless: the class itself is the model, with nothing to fit.

Examples

>>> from surpyval import NeverOccurs
>>> NeverOccurs.sf([1, 10, 100])
array([1., 1., 1.])
>>> NeverOccurs.qf([0.5])
array([inf])
>>> NeverOccurs.mean()
inf
