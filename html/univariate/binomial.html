Binomial Distribution

The Binomial distribution: the number of events in a fixed number of independent trials.

The uncertainty of a fitted p comes from the events and trials of all the rows together: param_cb("p") gives the exact (Clopper-Pearson, the default) or method="jeffreys" interval, and covariance() the variance \(\hat p (1 - \hat p) / N\) (nan with no events or only events), in the order of [n, p] with zeros for the known n. What the intervals mean, why they are preferred to plus or minus two standard errors near 0 or 1, the formulas and a coverage study are on the Bernoulli page.

import surpyval as sp

model = sp.Binomial.fit([2, 3, 1, 4], n_trials=5)
model.param_cb("p")                     # [0.272, 0.728]
model.param_cb("p", method="jeffreys")  # [0.2934, 0.7066]
model.covariance()                      # [[0, 0], [0, 0.0125]]
class surpyval.univariate.parametric.distributions.binomial.Binomial_(name: str)

Bases: DiscreteParametricFitter

The Binomial distribution: the number of events (failures) k in a fixed number n of independent pass/fail trials, each with event probability p.

It is the recurrent (repeated-trials) counterpart of the Bernoulli distribution, which is the special case n = 1. The two agree exactly there, every function included: both follow the package’s discrete rule \(R(k) = P(K > k)\), so Bernoulli.sf([0, 1], 0.3) and Binomial.sf([0, 1], 1, 0.3) are both [0.3, 0], and Bernoulli.sf(x, p) == Binomial.sf(x, 1, p) with no offset (Bernoulli’s survival function was \(P(X \geq x)\) before 0.22, #344).

The distribution is parameterised by n (the number of trials, a positive integer) and p (the per-trial event probability). Because n is an integer structural parameter, the distribution does not use the gradient-based MLE machinery; instead fit uses the closed-form maximum likelihood estimate of p for a known number of trials, in the same spirit as Bernoulli.

Examples

>>> from surpyval import Bernoulli, Binomial
>>> Binomial.sf([0, 1], 1, 0.3)
array([0.3, 0. ])
>>> Bernoulli.sf([0, 1], 0.3)
array([0.3, 0. ])

cs(x: NDArray | float, given: NDArray | float, *params: Any) → Any

Conditional survival function: the probability of surviving a further x given survival to given already.

\[R(x, given) = \frac{R(x + given)}{R(given)} = e^{-(H(x + given) - H(given))}\]

It is computed from the cumulative hazard, the second form, so it stays exact where \(R(given)\) underflows to 0 far in the upper tail (the ratio was nan there); it is nan only where \(H(given)\) is itself infinite. This is the definition for every distribution, so it lives here rather than being restated on each one. Exponential overrides it because the exponential is memoryless and \(R(x, given) = R(x)\), which is both cheaper and free of the cancellation the difference suffers in the far tail.

Changed in version 0.24: From the cumulative hazard, so finite where sf(given) underflows (#660).

Changed in version 0.22: The time already survived is given (it was X), the name the regression models’ sf_tvc(..., given=) uses.

Changed in version 0.23: X is removed.

Parameters:

  • x (numpy array or scalar) – The additional time to survive, measured from given

  • given (numpy array or scalar) – The time already survived

  • *params (numpy array like or scalar) – The parameters of the distribution, in the order given by its parameter_names

Returns:

cs – The value(s) of the conditional survival function.

Return type:

scalar or numpy array

Examples

>>> import numpy as np
>>> from surpyval import Weibull
>>> x = np.array([1, 2, 3, 4, 5])
>>> Weibull.cs(x, 5, 3, 4)
array([2.52537548e-04, 3.00394073e-10, 2.45288508e-19, 1.48999440e-32,
       5.42544000e-51])

Far in the tail, where the survival to given underflows:

>>> Weibull.sf(1000, 100, 3)
np.float64(0.0)
>>> round(float(Weibull.cs(1, 1000, 100, 3)), 6)
0.049638

fit(x: ArrayLike, n_trials: ArrayLike, c: NDArray | None = None, n: NDArray | None = None, *, unit=None) → Parametric

Fit the Binomial distribution for a known number of trials, n_trials, using the closed-form maximum likelihood estimate of the per-trial event probability p.

Parameters:

  • x (array like) – The observed number of events for each experiment. Every value must be an integer in [0, n_trials].

  • n_trials (integer or array like) – The (known) number of trials in each experiment: one number for every row, or one per row (batches of different sizes, #608).

  • c (array like, optional) – Censoring flags. Censoring is not supported for the Binomial distribution and any non-zero flag raises a ValueError.

  • n (array like, optional) – The count (multiplicity) of each observation in x. If None each observation is assumed to have occurred once.

Returns:

model – A parametric model with the fitted [n, p] parameters. Its param_cb("p") bounds p from the events in all the trials, sum(x) in sum(n_trials), exactly (Clopper-Pearson) by default, as Bernoulli does: the events in all the trials are binomial in their total whatever the rows’ sizes, so the exact interval holds for unequal trials too; method="jeffreys" gives the Jeffreys interval. param_cb("n") is the known number of trials. covariance() holds the variance of p from the same totals, and zeros for the known n.

Return type:

Parametric

Notes

With a different number of trials in different rows the model has no single n: params holds nan for it, and the functions of the count of events (sf, df, mean, random, …) raise a ValueError saying so; p, its bounds and the model’s dictionary are as for equal trials. The distribution of the events in m trials is model.with_params([m, p]).

Examples

>>> from surpyval import Binomial
>>> model = Binomial.fit([2, 3, 1, 4], n_trials=5)
>>> model.params
array([5. , 0.5])
>>> model.param_cb("p").round(4)
array([0.272, 0.728])
>>> model.param_cb("p", method="jeffreys").round(4)
array([0.2934, 0.7066])

covariance() is that of [n, p]: the known n has a zero row and column, and p the variance \(\hat p (1 - \hat p) / N\) over all N trials (nan with no events, or only events).

>>> model.covariance()
array([[0.    , 0.    ],
       [0.    , 0.0125]])

Batches of different sizes:

>>> lots = Binomial.fit([1, 0, 3], n_trials=[20, 50, 80])
>>> lots.params.round(4)
array([  nan, 0.0267])
>>> lots.param_cb("p").round(4)
array([0.0073, 0.0669])
fit_bayes(x: Any = None, c: Any = None, n: Any = None, t: Any = None, *, priors: Any = None, offset: bool = False, zi: bool = False, lfp: bool = False, tl: Any = None, tr: Any = None, xl: Any = None, xr: Any = None, fixed: dict[str, float] | None = None, method: str = 'auto', points: int | None = None, unit: Any = None, w: Any = None) → Any

Fit the distribution by Bayes’ rule: the prior times the likelihood of the data, which is the likelihood fit uses for every kind of censoring and truncation.

Returns a BayesianParametric, used like any model: its sf, qf, mean and random are those of a new unit’s life with the uncertainty in the parameters averaged in (the posterior predictive), and cri, quantile_cri, mean_cri and param_cri give credible intervals. fit is unchanged; all the work is in surpyval.bayes.

Parameters:

  • x – The data, as for fit; x may be a SurpyvalData.

  • c – The data, as for fit; x may be a SurpyvalData.

  • n – The data, as for fit; x may be a SurpyvalData.

  • t – The data, as for fit; x may be a SurpyvalData.

  • tl – The data, as for fit; x may be a SurpyvalData.

  • tr – The data, as for fit; x may be a SurpyvalData.

  • xl – The data, as for fit; x may be a SurpyvalData.

  • xr – The data, as for fit; x may be a SurpyvalData.

  • priors (dict or prior, optional) – {parameter name: prior} (surpyval.prior.around, between, uniform, flat, fixed or any SurPyval distribution), a joint prior (prior.on_quantities, prior.from_model, prior.from_data), or a list of these. A parameter given none is flat on its unconstrained scale (the log scale for a positive parameter), allowed only where the data alone determine it.

  • offset – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • zi – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • lfp – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • fixed – As for fit; gamma, f0 and lfp_p then need a prior or are flat.

  • method ({'auto', 'grid', 'conjugate', 'laplace'}, optional) – 'auto' (the default) uses the closed form where one applies, else the self-checking grid (1 to 3 free parameters); 'laplace' a normal approximation, labelled approximate.

  • points (int, optional) – The grid’s starting points per parameter.

  • unit (str, optional) – The unit of the times, as for fit.

  • w (None) – Weights are not taken: a w is refused with a ValueError that says what to use instead (fit with w, or counts n for identical units).

Examples

>>> x = np.r_[2100, 3400, 4050, np.linspace(1500, 6000, 37)]
>>> c = np.r_[0, 0, 0, np.ones(37)]
>>> model = sp.Weibull.fit_bayes(
...     x, c, priors={"beta": sp.prior.around(2, between=(1.5, 3))})
>>> model.params.round(2)
array([1.441299e+04, 2.090000e+00])

isf(s: NDArray | float, *params: Any) → Any

The inverse survival function: the time at which the survival function is s (scipy’s name), qf(1 - s) without rounding 1 - s.

Far in the upper tail qf cannot be asked for the time: 1 - s rounds to 1 once s is below 1.1e-16. isf takes s itself, so isf(sf(t)) gives back t deep in the tail. A distribution with a closed form has its own; the others solve log_sf(x) = log(s) (a discrete one: the smallest point of its support with sf(k) <= s). isf(1) is the start of the support and isf(0) its end.

Examples

>>> from surpyval import Weibull, Gamma
>>> Weibull.isf(1e-300, 10, 2).round(4)
np.float64(262.8261)
>>> t = Gamma.isf(1e-200, 2.5, 0.5)
>>> float(Gamma.sf(t, 2.5, 0.5))
1e-200

mrl(x: NDArray | float, *params: Any) → Any

Mean residual life: the expected remaining life of a unit that has survived to x,

\[\mathrm{MRL}(x) = E[T - x \mid T > x] = \frac{1}{R(x)} \int_x^\infty R(u)\, du ,\]

so mrl(0) of a lifetime is its mean, and below the support’s start mrl(x) = mean - x. It is in closed form for the Exponential (1 / failure_rate, memoryless) and the Weibull (an upper incomplete gamma function); otherwise it is the integral of the conditional survival cs(), finite far in the tail where R(x) underflows, or for a discrete distribution the sum over the integers. Infinite where the mean is; nan at or past a finite end of the support (no unit survives to it) and for a missing x.

Parameters:

  • x (numpy array or scalar) – The ages survived to

  • *params (numpy array like or scalar) – The parameters of the distribution, in the order given by its parameter_names

Returns:

mrl – The mean residual life at each x, shaped as x.

Return type:

scalar or numpy array

Examples

>>> from surpyval import Weibull
>>> Weibull.mrl([0, 5, 10, 20], 10, 2).round(4)
array([8.8623, 5.4564, 3.7894, 2.2634])
>>> Weibull.mean(10, 2).round(4)
np.float64(8.8623)
