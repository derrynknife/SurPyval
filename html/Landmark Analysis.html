Landmark Analysis

A dynamic prediction answers a question asked part way through follow-up: this unit has lasted to time \(s\) and this is what we know about it now; how likely is it to have its event in the next \(w\)? A pump that has run 2 years and whose vibration was last read as high; a patient alive 6 months after treatment whose blood counts have recovered. The answer changes as time passes and as what is known changes, so it is asked again at each landmark time \(s\).

Landmarking (van Houwelingen, 2007; van Houwelingen and Putter, 2011) answers it directly:

  1. at the landmark \(s\), keep the units still at risk – entered by \(s\) and event-free past it;

  2. give each its covariates as they were known at \(s\) – the fixed ones, and the last value at or before \(s\) of anything that changes over time (a time-varying covariate, a measurement);

  3. stop following them at the horizon \(s + w\), censoring any still running then (or failing later);

  4. fit an ordinary model, such as a Cox model, to that data set.

Why it avoids immortal-time bias

A tempting shortcut is to group units by something that happens during follow-up – whether a repair was made, whether a treatment response was seen – and compare the groups from time 0. It is biased: a unit can only join the “it happened” group by surviving until it happens, so that group is credited with event-free time it was guaranteed (immortal time), and looks better than it is. A landmark data set cannot do this: it groups units by what was known at \(s\), and counts only what happens to them after \(s\). Nothing from the future is used.

When a joint model is better

Landmarking takes the last reading as the truth until \(s\). If the covariate is a noisy measurement read at irregular times, a joint model uses every reading, allows for the noise and describes how the measurement moves between readings, and gives the dynamic prediction from the same model at any time. It is the better model when its assumptions about the measurement’s path hold; landmarking asks for no model of the covariate at all, which makes it simpler and robust to a wrong one, at the cost of using only the latest value.

The landmark data

landmark() derives the landmark data from a SurpyvalData of the units’ lifetimes: each unit’s time, censoring, count, entry, id i and covariates. A covariate that changes is given as rows of the unit, (tl, x] stretches with the covariates fixed in each (only the last row ends in the event); readings taken on the units are its measurements m (a Measurements). The result is another SurpyvalData, which any model fits:

import numpy as np
import surpyval as sp

# A unit's covariate z2 switches from 0 to 1 at some time (a recovery,
# a change of duty); z1 is fixed. A unit that switches has two rows.
rng = np.random.default_rng(1)
i, x, c, tl, Z = [], [], [], [], []
for unit in range(300):
    switch = rng.exponential(3.0)
    z1 = float(rng.uniform() < 0.5)
    t = rng.exponential(1 / (0.15 * np.exp(0.5 * z1)))
    if t > switch:  # the hazard doubles after the switch
        t = switch + rng.exponential(1 / (0.3 * np.exp(0.5 * z1)))
    end = rng.uniform(4, 10)
    stop, event = min(t, end), int(t <= end)
    if switch < stop:
        i += [unit, unit]; x += [switch, stop]; c += [1, 1 - event]
        tl += [-np.inf, switch]; Z += [[z1, 0.0], [z1, 1.0]]
    else:
        i.append(unit); x.append(stop); c.append(1 - event)
        tl.append(-np.inf); Z.append([z1, 0.0])
life = sp.SurpyvalData(x=x, c=c, tl=tl, i=i, Z=Z,
                       covariate_names=["z1", "z2"])

data = sp.landmark(life, at=2, horizon=3)
data.covariate_names     # ['z1', 'z2'], as known at 2
data.tl[:3], data.x[:3]  # entered at 2, followed at most to 5

At one landmark the rows are the units at risk then, entered at the landmark (tl = s), each with its covariates as known then, the unit’s id its i. With several landmarks, at=[0, 1, 2, 3], the landmark data sets are stacked into one, the super landmark data set: a unit appears once for each landmark it is at risk at, the landmark is a covariate column L, and interactions=True adds each covariate times L. A unit’s rows there overlap in time (each runs from its own landmark), which SurpyvalData does not allow for one unit’s rows, so each row’s unit and landmark are in its attributes ("i" and "L"). Each measurement in m becomes a covariate named after it, its last reading at or before the landmark; a unit with no reading of it by then is left out of that landmark, with a warning that counts them: nothing is known about it there.

Landmark models

LandmarkCox fits a Cox model to the landmark data and predicts from it. With one landmark it is the Cox model of that landmark data set. With several it is a supermodel: the effect of each covariate may change smoothly with the landmark,

\[h(t \mid Z(s), s) = h_0(t \mid s)\,\exp\big(\beta(s)' Z(s)\big), \qquad s \le t \le s + w, \qquad \beta(s) = \beta_0 + \beta_1 u + \dots + \beta_d u^d,\]

with \(u = (s - s_1) / (s_L - s_1)\) running from 0 at the first landmark to 1 at the last (degree=d; or any basis of \(s\) you give, a spline for example, as basis=; varying= names the covariates whose effect changes). The baseline hazard is either

  • stratified (baseline="stratified", the default): a baseline of its own at each landmark, which predicts at the landmarks fitted; or

  • pooled (baseline="pooled"): one baseline \(h_0(t) e^{\theta(s)}\), \(\theta(s) = \theta_1 u + \dots + \theta_d u^d\) (the “proportional baselines” model), which predicts at any \(s\) between the first and last landmark.

model = sp.LandmarkCox.fit(life, at=[0, 1, 2, 3, 4], horizon=3)
model.summary()                  # coefficients, robust standard errors
model.beta([0, 2, 4])            # each covariate's effect at s
model.predict(2, [[0, 0], [1, 1]])   # P(T <= 5 | T > 2, Z(2))
model.table([[0, 0], [0, 1], [1, 0], [1, 1]])  # landmarks x profiles

predict(s, Z) is the dynamic prediction \(P(T \le s + w \mid T > s, Z(s))\); sf, ff and Hf(x, Z, s=...) give it for any time \(x\) from \(s\) to \(s + w\). table lays out the dynamic prediction table, a row for each landmark and covariate profile with the probability and its bounds.

Standard errors and bounds

In the stacked data a unit appears several times, so its rows are not independent and the model-based standard errors of the Cox fit are too small. The standard errors are therefore the robust (sandwich) ones, clustered on the unit, as R’s coxph(... + cluster(id)) reports; covariance(robust=False) gives the model-based one for comparison. The bounds on a prediction (cb, and the table) carry the same robust variance to the prediction: each unit’s influence on the baseline over \((s, x]\) and on the coefficients is added up over its rows, and the influences are squared and summed over the units (the infinitesimal jackknife). The bound is normal on the log cumulative hazard by default (bound_type="log-log"), which keeps it inside (0, 1). In simulations of a correctly specified model with four landmarks per unit, the 95% robust intervals covered the coefficients 93%-96% of the time and a window probability 95%.

Only these Wald bounds are offered: the stacked rows have no likelihood of their own for a likelihood-ratio bound, and no bootstrap is built (resample the units, refit, and take quantiles, for one).

Survival from a landmark by group

The simplest landmark analysis needs no model: landmark_kaplan_meier() gives the Kaplan-Meier estimate of survival from the landmark, \(P(T > x \mid T > s)\), for each group of units by their covariates known at \(s\), with its usual bounds (each unit counted once):

km = sp.landmark_kaplan_meier(life, at=2, horizon=3, by="z2")
km[1.0].sf([3, 4, 5])      # switched by time 2
km[0.0].sf([3, 4, 5])      # not yet switched at 2

Checked against R

The landmark data sets match dynpred’s cutLM (0.1.2) row for row; the Cox model at one landmark and the stratified and pooled supermodels match survival’s coxph(... + cluster(id)) (3.8.12): coefficients, robust and model-based standard errors, and the window probabilities from survfit, to about 1e-10, with Efron’s and Breslow’s ties.

One convention differs from cutLM’s long format, whose default (right = TRUE) does not use a change of covariate recorded exactly at the landmark: here a value recorded at \(s\) is known at \(s\) (cutLM’s right = FALSE, and its wide format).

API reference

Import everything from surpyval (or surpyval.univariate.landmark).

surpyval.univariate.landmark.landmark(life: Any, at: ArrayLike | float, horizon: float, interactions: bool = False) → Any

The landmark data of life at the landmark time(s) at, as a SurpyvalData (R dynpred’s cutLM).

At a landmark L, keep the units still at risk (entered by L and followed event-free past it), enter them at L (tl = L), cut their follow-up at L + horizon (an event after that, or a unit still running then, is right censored at L + horizon), and give them their covariates as known at L: the fixed ones, and the last value at or before L of the time-varying ones and of each measurement read on the units (life.m). Because only units at risk at L and only what was known at L are used, a model of this data never borrows from the future: it has no immortal-time bias.

With several landmarks the landmark data sets are stacked into one (the “super landmark data set” of van Houwelingen, 2007), in which a unit appears once for each landmark it is at risk at. The landmark is then a covariate column, L, and with interactions=True so is each covariate times L ("z*L"): fit a Cox model to it (CoxPH.fit(data), stratified by L or not) for a supermodel, with standard errors clustered on the unit, as each unit has several rows; LandmarkCox does this and predicts from it.

Parameters:

  • life (SurpyvalData) – The units’ lifetimes: time x, c (0 the event, 1 still running), counts n, entry tl, unit ids i and covariates Z. A covariate that changes is given as rows of the unit, (tl, x] stretches with Z fixed in each, only the last ending in the event (or as a StepSchedule or CovariatePath per unit, from from_items); a gap between a unit’s rows, or an event before its last row, is refused. Readings taken on the units are its measurements m. The last reading of each measurement at or before L becomes a covariate named after it; a unit at risk with no reading of one by L is left out of that landmark, with a warning that counts them.

  • at (float or array_like) – The landmark time(s) L.

  • horizon (float) – The window w: follow-up is cut at L + w.

  • interactions (bool, optional) – With several landmarks, add each covariate times L as a column ("z*L").

Returns:

One row per unit at risk at each landmark, ordered by landmark, with x, c, n, tl (the landmark) and Z (named by covariate_names). Each row’s attributes hold its unit ("i") and landmark ("L"); with one landmark the units are also its i. (Stacked, a unit’s rows overlap in time, each running from its landmark, which SurpyvalData does not allow for one unit’s rows, so there the unit is in the attributes only.)

Return type:

SurpyvalData

Examples

Three units with a fixed covariate; at the landmark 2 the first has failed already, and the follow-up of the others is cut at 2 + 3:

>>> from surpyval import SurpyvalData, landmark
>>> life = SurpyvalData(x=[1.5, 6, 4], c=[0, 0, 1], Z=[[1], [0], [1]],
...                     i=["a", "b", "c"])
>>> data = landmark(life, at=2, horizon=3)
>>> data.i, data.x, data.c, data.tl
(['b', 'c'], array([5., 4.]), array([1, 1]), array([2., 2.]))

Stacked over two landmarks, the landmark becomes a covariate:

>>> data = landmark(life, at=[0, 2], horizon=3)
>>> data.covariate_names
['Z0', 'L']
>>> data.Z
array([[1., 0.],
       [0., 0.],
       [1., 0.],
       [0., 2.],
       [1., 2.]])
surpyval.univariate.landmark.landmark_kaplan_meier(life: Any, at: float, horizon: float, by: str | list[str] | None = None) → dict

The Kaplan-Meier estimate of survival from the landmark at, for each group of units by the value(s) of their covariates by as known at at (the simple landmark analysis of van Houwelingen and Putter, 2011).

Each estimate is of \(P(T > x \mid T > L, \text{group at } L)\) for x from L to L + horizon: the units at risk at L, entered at L, grouped by what was known about them at L. Its bounds are the Kaplan-Meier estimate’s own (cb), as each unit is counted once.

Parameters:

  • life (SurpyvalData) – The units’ lifetimes and covariates, as landmark() takes them.

  • at (float) – The landmark time L.

  • horizon (float) – The window w: follow-up is cut at L + w.

  • by (str or list of str, optional) – The covariates to group by (names, as the landmark data’s covariate_names). Default: one estimate of every unit at risk.

Returns:

{group: NonParametric}: the group is the covariate’s value (a tuple of values for several), or None without by.

Return type:

dict

Examples

>>> from surpyval import SurpyvalData, landmark_kaplan_meier
>>> life = SurpyvalData(x=[1, 3, 4, 5, 6, 8], c=[0, 0, 1, 0, 0, 1],
...                     Z=[[0], [1], [0], [1], [0], [1]],
...                     covariate_names=["z"])
>>> km = landmark_kaplan_meier(life, at=2, horizon=4, by="z")
>>> sorted(km)
[0.0, 1.0]
>>> km[1.0].sf([3, 5, 6]).round(3)
array([0.667, 0.333, 0.333])
class surpyval.univariate.landmark.LandmarkCox

Bases: SerialisableMixin

Landmark Cox models and the dynamic predictions they give (van Houwelingen, 2007; van Houwelingen and Putter, 2011).

A dynamic prediction is the chance that a unit still event-free at time s has its event within the next w, given what is known about it at s: \(P(T \le s + w \mid T > s, Z(s))\). Landmarking answers it directly. At a landmark time s, take the units still at risk, their covariates as known at s, and their follow-up cut at s + w (landmark()), and fit a Cox model to them. Because only units still at risk at s are used, and only what was known about them at s, the prediction never uses the future, so it has no immortal-time bias.

With one landmark the model is that Cox model. With several, the landmark data sets are stacked and fitted together as a supermodel: the effect of each covariate may change smoothly with the landmark,

\[h(t \mid Z(s), s) = h_0(t \mid s) \exp\big(\beta(s)' Z(s)\big), \qquad s \le t \le s + w, \qquad \beta(s) = \beta_0 + \beta_1 u + \dots + \beta_d u^d,\]

with \(u = (s - s_1) / (s_L - s_1)\) (0 at the first landmark, 1 at the last), or any basis of s given as basis. The baseline hazard is either a separate one at each landmark (baseline="stratified") or one shared baseline \(h_0(t) \exp(\theta(s))\) with \(\theta(s) = \theta_1 u + \dots + \theta_d u^d\) (baseline="pooled"), which predicts at any s between the first and last landmark. A unit appears once for each landmark it is at risk at, so its rows are correlated; the standard errors are therefore the robust (sandwich) ones, clustered on the unit (R’s coxph(... + cluster(id))), and so are the bounds on the predictions.

Fit with fit() or fit_from_df().

Type:

numpy.ndarray

Type:

beta_cb(s: ArrayLike, alpha_ci: float = 0.05, bound: str = 'two-sided') → NDArray

Robust Wald bounds on beta() at s: shape np.shape(s) + (p, 2) two-sided, np.shape(s) + (p,) one-sided (bound='lower' or 'upper').

cb(x: ArrayLike, Z: Any, s: float, on: str = 'sf', alpha_ci: float = 0.05, bound: str = 'two-sided', bound_type: str = 'log-log') → NDArray

Robust pointwise confidence bounds on the dynamic survival (sf(), the default, as for every model), the dynamic prediction (ff(), on="ff") or Hf(), from the landmark s to x.

The standard error of \(\log \hat H(x \mid s, Z)\) is the infinitesimal jackknife: each stacked row’s influence on the baseline hazard over \((s, x]\) and on the coefficients, summed over the rows of each unit (a unit appears at several landmarks), and squared and added over the units. It is the robust variance that the coefficients’ standard errors use, carried to the prediction; at tied times it takes Breslow’s form of the baseline. The bound is normal on the scale of bound_type: "log-log" (the default, \(H e^{\pm z\,\mathrm{se}}\)), "log" or "plain", as for CoxPH()’s cb. Only these Wald bounds are offered: the stacked rows have no likelihood of their own for a likelihood-ratio bound, and no bootstrap is built (resample the units, refit, and take quantiles, for one).

Returns [lower, upper] on a last axis of 2 for two-sided bounds, one value per x otherwise.

covariance(robust: bool = True) → NDArray

The coefficients’ covariance: the robust one, clustered on the unit (the default), or, with robust=False, the model-based one, which treats a unit’s rows at different landmarks as independent and is too small for a supermodel.

ff(x: ArrayLike, Z: Any, s: float) → NDArray

The dynamic failure probability \(P(T \le x \mid T > s, Z(s))\) (see sf()).

standard_errors(robust: bool = True) → NDArray

The coefficients’ standard errors (robust by default; see covariance()).

summary(alpha_ci: float = 0.05, robust: bool = True) → Any

The coefficients’ table: estimate, standard error (robust, clustered on the unit, by default), z, p-value and the Wald bounds of the coefficient and of the hazard ratio exp(coef), with the columns of every regression model’s summary.

table(Z: Any, landmarks: ArrayLike | None = None, window: float | None = None, alpha_ci: float = 0.05, bound_type: str = 'log-log') → Any

The dynamic prediction table: for each landmark (default: those fitted) and covariate profile (the rows of Z; a DataFrame’s index labels the profiles), the chance of the event within window (default the fitted w) and its robust bounds.

Returns a DataFrame with the columns landmark, profile, probability, lower and upper.

to_dict() → dict

Serialise the model to a plain, JSON-serialisable dict. The data (life, by its own to_dict) and the options are stored and the model is refitted on loading, so it predicts and bounds exactly as the original. A model with a basis of its own (basis=) cannot be saved.

to_json(fp: str | PathLike | None = None, with_data: bool = False) → str | None

Write to_dict() to fp as strict JSON, or return it.

Parameters:

  • fp (str or os.PathLike, optional) – The file to write. Without it the JSON is returned as a string (as pandas.DataFrame.to_json does), which from_json also reads.

  • with_data (bool, optional) – Write to_dict(with_data=True), which also stores the fitted data, for the models whose to_dict takes with_data (the univariate Parametric and NonParametric); a TypeError for any other model. Defaults to False.

unit: str | None = None

a label, set by unit= on fit, fit_from_df and from_params, shown in the repr and on plots and saved by to_dict. None is unknown. See surpyval.utils.units. (Not units, which names the items measured: a degradation model’s unit ids.)

Type:

The unit of the data the model describes (#845)
