Competing Risks SurPyval Modelling

This page shows how to use SurPyval’s competing risks classes. For the theoretical background see Competing Risks Analysis; for the complete list of arguments and methods see the Competing Risks API reference.

Note

Every example on this page is executed when the documentation is built, so the outputs shown are produced by the installed version of surpyval.

SurPyval’s competing-risks tools, and the question each one answers:

Tool

Answers

CompetingRisks

Non-parametric cumulative incidence of each cause: Aalen-Johansen for exact times, and the non-parametric maximum-likelihood estimate when failures are found at inspections (interval-censored), or their cause was not recorded.

ParametricCompetingRisks

One distribution per cause; smooth CIFs, extrapolation, simulation.

gray_test

Does the cumulative incidence of a cause differ between groups? Also for failures found at inspections.

FineGray

How do covariates change the cumulative incidence of one cause?

CompetingRisksProportionalHazards

How do covariates change each cause-specific hazard (model="Cox"), or the incidence of every cause (model="Fine-Gray")?

ParametricCompetingRisksRegression

A parametric regression per cause; smooth CIFs at any covariates, beyond the last observation.

The classes live in surpyval.univariate.competing_risks; gray_test is also available at the top level as surpyval.gray_test. All of them accept right-censored data; CompetingRisks, ParametricCompetingRisks and gray_test also take failures found at inspections (left- and interval-censored rows). For repeated events with several failure modes see the cause-specific MCF and NHPP models in Recurrent Event Modelling with SurPyval.

Standard imports used throughout this page:

import surpyval as surv
import numpy as np
from matplotlib import pyplot as plt

Fitting a Competing Risks Model

The CompetingRisks class estimates a non-parametric cumulative incidence function (CIF) for each failure cause with the Aalen-Johansen estimator. Pass the observed times, a cause indicator, and optional censoring flags.

Competing-risks data format

Every competing-risks fit takes the same core arrays:

  • x – the observed time of each row (failure or censoring time);

  • e – the cause of each row. Any hashable labels work (integers, strings, …). A censored row has no cause: use None (or NaN, or a blank cell in a DataFrame);

  • c – optional censoring flags, 0 observed and 1 right-censored (and, for ParametricCompetingRisks, -1 left- and 2 interval-censored). When c is omitted it is derived from e: a missing cause means censored. If you do pass c, every row with c == 1 must have a missing cause and every other row must have one, otherwise a ValueError explains the mismatch;

  • n – optional counts, when each row stands for several identical units;

  • tl – for CompetingRisks, ParametricCompetingRisks and the cause-specific CompetingRisksProportionalHazards, the optional age at which each row came under observation (left truncation, or delayed entry; see Delayed entry, Assembling a model from separately fitted causes and Delayed entry in the cause-specific model).

Left- and interval-censored rows (c of -1 or 2) are taken by ParametricCompetingRisks (see Failures found at inspections), CompetingRisks (The non-parametric estimate for inspection data), gray_test and the cause-specific CoxPH; the other regressions (FineGray, CompetingRisksProportionalHazards, ParametricCompetingRisksRegression) and pseudo_cif refuse them, saying which of those to use.

lifelines, scikit-survival and R’s cmprsk code the causes as one integer column with 0 for a censored row. Here 0 is a cause like any other (you may number causes from 0), so convert such data with e = np.where(np.asarray(e) == 0, None, e). Because the two codings cannot be told apart, a fit whose labels are numbers including 0, with none missing and no c, warns and says so; passing c (np.zeros(len(e)) when nothing is censored) silences it.

The smallest possible example is the six-unit data set worked by hand on the Competing Risks Analysis page. The fourth unit is censored:

from surpyval.univariate.competing_risks import CompetingRisks

x = [1, 2, 3, 4, 5, 6]
e = ["A", "B", "A", None, "B", "A"]

small = CompetingRisks.fit(x, e)
print("CIF of A at t=6:", small.cif(6, "A"), "(7/12 = %.4f)" % (7 / 12))
print("CIF of B at t=6:", small.cif(6, "B"), "(5/12 = %.4f)" % (5 / 12))

CIF of B at t=6: 0.4166666666666667 (5/12 = 0.4167)

and “one minus Kaplan-Meier with the other cause censored” gives the misleading answers discussed on the theory page – 1 for A and 0.6 for B, a total “probability” of 1.6:

for k in ["A", "B"]:
    c_k = [0 if ei == k else 1 for ei in e]   # other cause -> censored
    naive = surv.KaplanMeier.fit(x, c=c_k)
    print(k, "naive 1 - KM at t=6:", naive.ff(6))

A naive 1 - KM at t=6: 1.0
B naive 1 - KM at t=6: 0.6

When each row stands for several identical units, give the counts in n rather than repeating rows. Doubling every row of the six-unit data gives the same CIFs, because the estimator only uses the proportions \(d_{k,j}/r_j\). The iif method returns the individual increments \(\hat{S}(x_{j-1})\,d_{k,j}/r_j\), here the three terms \(\tfrac{1}{6}, \tfrac{1}{6}, \tfrac{1}{4}\) of the hand calculation on the theory page:

doubled = CompetingRisks.fit(x, e, n=[2] * 6)
print("CIF of A at t=3, 6     :", doubled.cif([3, 6], "A"))
print("increments at t=1, 3, 6:", doubled.iif([1, 3, 6], "A"))

CIF of A at t=3, 6     : [0.33333333 0.58333333]
increments at t=1, 3, 6: [0.16666667 0.16666667 0.25      ]

Non-parametric cumulative incidence

A more realistic example: components fail either by wear-out (a Weibull latent life) or by random shocks (an exponential latent life), whichever comes first, and some are removed from test (censored) before failing. Because we simulate the data we know the true CIFs and can check the estimates:

rng = np.random.default_rng(0)
N = 300
t_wear = 100 * rng.weibull(3.0, N)       # Weibull(alpha=100, beta=3)
t_shock = rng.exponential(150, N)        # Exponential, mean 150
t_cens = rng.uniform(0, 200, N)          # removal from test

x = np.minimum.reduce([t_wear, t_shock, t_cens])
e = np.where(x == t_cens, None,
             np.where(t_wear < t_shock, "wear", "shock")).astype(object)

model = CompetingRisks.fit(x, e)         # c is derived from e
print(model)
print("event index map:", model.event_idx_map)

Competing Risk model with events:
['shock', 'wear']

event index map: {'shock': 0, 'wear': 1}

Causes are sorted and mapped to internal indices (event_idx_map); you always refer to a cause by its own label. Once fitted, you can query the CIF for each cause:

t_plot = np.linspace(0, 200, 400)
for k in ["wear", "shock"]:
    plt.step(t_plot, model.cif(t_plot, event=k), where="post", label=k)
plt.xlabel('Time')
plt.ylabel('Cumulative Incidence')
plt.legend()
plt.title('Competing Risks CIF by Cause')

Text(0.5, 1.0, 'Competing Risks CIF by Cause')

The CIFs of all causes add up to the all-cause failure probability. The Aalen-Johansen increments are weighted with the Kaplan-Meier all-cause survival, so the sum equals one minus the ordinary Kaplan-Meier curve of the data with every cause treated as a failure – exactly, not approximately:

t = np.array([25.0, 50.0, 100.0, 150.0])
total = model.cif(t, "wear") + model.cif(t, "shock")
all_cause_km = surv.KaplanMeier.fit(x, c=(e == None).astype(int))
print("sum of CIFs   :", np.round(total, 4))
print("1 - KM (all)  :", np.round(all_cause_km.ff(t), 4))

sum of CIFs   : [0.1485 0.3722 0.7605 0.9567]
1 - KM (all)  : [0.1485 0.3722 0.7605 0.9567]

The model’s own all-cause ff is a different estimate unless you ask for this one. sf, ff and Hf use the estimator given by how, and the default is Nelson-Aalen, ff = 1 - exp(-H). That is never above the sum of the CIFs, and is below it from the first event on; the gap is small while few units have failed and grows as the risk sets shrink. Fit with how="Kaplan-Meier" when ff should match the CIFs:

km_fit = CompetingRisks.fit(x, e, how="Kaplan-Meier")
print("ff, Nelson-Aalen :", np.round(model.ff(t), 4))
print("ff, Kaplan-Meier :", np.round(km_fit.ff(t), 4))

ff, Nelson-Aalen : [0.1483 0.3714 0.7583 0.9503]
ff, Kaplan-Meier : [0.1485 0.3722 0.7605 0.9567]

Now compare the CIF of wear-out with the naive “1 - Kaplan-Meier with shocks censored” curve, and with the truth. For this simulation the true CIF of wear is \(\int_0^t f_{\text{wear}}(u)\, S_{\text{shock}}(u)\, du\):

from scipy.integrate import quad

def true_cif_wear(t):
    dens = lambda u: surv.Weibull.df(u, 100, 3.0) * np.exp(-u / 150)
    return quad(dens, 0, t)[0]

naive_wear = surv.KaplanMeier.fit(x, c=(e != "wear").astype(int))

plt.step(t_plot, model.cif(t_plot, "wear"), where="post",
         label="Aalen-Johansen CIF")
plt.step(t_plot, naive_wear.ff(t_plot), where="post",
         label="naive 1 - KM (shocks censored)")
plt.plot(t_plot, [true_cif_wear(ti) for ti in t_plot], "k--",
         label="true CIF")
plt.xlabel("Time")
plt.ylabel("Probability of wear-out failure")
plt.legend()

The naive curve climbs towards one because it pretends that a component destroyed by a shock could still have worn out later. The Aalen-Johansen estimate tracks the true incidence, which levels off at the probability that wear-out, rather than a shock, is what ends a component’s life.

Delayed entry

Often a unit comes under observation only some time after it started: a patient joins a study at diagnosis but the clock is their age, or a component enters the records when they began, long after it was installed. A unit that failed before it would have entered is never seen, so the units you do see are the ones that survived to their entry. Pass each unit’s entry time as tl: the unit then counts as at risk only between its entry and its exit (tl < t <= x), and the estimates are those of the units still running at each time. They are conditional on surviving to the earliest entry, as a KaplanMeier fit with tl is. Here half the components were watched from new and the rest only came under observation at a random age; the fit with the entry ages comes close to the fit of every component from new (the model above), while the fit that ignores them counts too many at risk early on and understates the shocks:

rng_entry = np.random.default_rng(1)
entry = np.where(rng_entry.uniform(size=N) < 0.5, 0.0,
                 rng_entry.uniform(0, 80, N))
seen = x > entry                         # failed before entry: never seen
late = CompetingRisks.fit(x[seen], e[seen], tl=entry[seen])
ignored = CompetingRisks.fit(x[seen], e[seen])
print("with entry     :", np.round(late.cif(t, "shock"), 4))
print("ignoring entry :", np.round(ignored.cif(t, "shock"), 4))
print("all from new   :", np.round(model.cif(t, "shock"), 4))

with entry     : [0.1424 0.3004 0.4401 0.4676]
ignoring entry : [0.0985 0.2361 0.3863 0.418 ]
all from new   : [0.1306 0.293  0.4267 0.4549]

fit_from_df takes the column as tl_col, and fit(data) passes a SurpyvalData’s entry times through. The bounds (cb) work as before: the variance is a function of the numbers at risk and of failures at each time, which already count only the units that have entered. This is R’s survfit(Surv(entry, x, factor(e)) ~ 1); right truncation is not supported.

What the fitted model returns

All methods take the query times first and a cause label as event. The CIF methods need a cause; the others treat event=None (the default) as “all causes combined”. Every function is a step function that is zero (or one, for sf) before the first observed time.

Method

Returns

cif(x, event)

Aalen-Johansen cumulative incidence \(\hat{F}_k(x)\) – the real-world probability of having failed from event by x.

iif(x, event)

The CIF jump at the most recent observed time at or before x (zero if no failure from event happened at that time).

hf(x, event=None)

The Nelson-Aalen hazard increment \(d_{k,j}/r_j\) at the most recent observed time at or before x (a jump size, not a rate).

Hf(x, event=None)

Cumulative (cause-specific) hazard \(\hat{H}_k(x)\).

sf(x, event=None) / ff(x, event=None)

The survival and 1 - sf, by the method the model was fitted with: \(e^{-\hat{H}_k(x)}\) (Nelson-Aalen, the default) or the product limit \(\prod (1 - d_{k,j}/r_j)\) (Kaplan-Meier). With an event these are the net quantities (the cause acting alone); with event=None they are all-cause.

df(x, event=None)

hf * sf.

print("all-cause sf     :", np.round(model.sf(t), 4))

Warning

ff(x, event=k) is the net failure probability: “one minus Kaplan-Meier with the other causes censored” (exactly that with method="Kaplan-Meier", its Nelson-Aalen version by default). It answers “what if cause k were the only cause?”, which is only meaningful if the causes act independently. For “how likely is a failure from cause k?” always use cif.

The method argument ("Nelson-Aalen", the default, or "Kaplan-Meier") selects the survival estimator that sf, ff and Hf report (Hf is -log sf, so the three stay consistent); the all-cause estimate is also stored as model.S at the distinct observed times model.x. It does not change cif: the Aalen-Johansen weights are always the product-limit (Kaplan-Meier) survival, the only one for which the CIFs sum to the all-cause failure probability.

km_model = CompetingRisks.fit(x, e, how="Kaplan-Meier")
print("same CIFs          :", np.allclose(km_model.cif(t, "wear"), model.cif(t, "wear")))
print("sf (Kaplan-Meier)  :", np.round(km_model.sf(t), 4))
print("sf (Nelson-Aalen)  :", np.round(model.sf(t), 4))
print("CIFs sum to 1 - KM :", np.allclose(
    km_model.cif(t, "wear") + km_model.cif(t, "shock"), km_model.ff(t)))

same CIFs          : True
sf (Kaplan-Meier)  : [0.8515 0.6278 0.2395 0.0433]
sf (Nelson-Aalen)  : [0.8517 0.6286 0.2417 0.0497]

Like the single-cause step estimates, every function starts at its initial value before the first observed time (sf 1, the others 0) and holds its last value after the last one, however far from the data. To give the estimate an explicit range instead, call set_support(lower, upper): the functions keep that convention only within [lower, upper] and are nan outside it. The bounds must contain the observed times; lower may be negative and either bound infinite. set_support returns the model, and to_dict saves the bounds with it.

bounded = CompetingRisks.fit(x, e).set_support(0, 2 * x.max())
q = [-1, 0, 1.5 * x.max(), 3 * x.max()]
print("bounded CIF wear :", np.round(bounded.cif(q, "wear"), 4))
print("CIF wear         :", np.round(model.cif(q, "wear"), 4))

bounded CIF wear : [   nan 0.     0.5451    nan]
CIF wear         : [0.     0.     0.5451 0.5451]

Confidence bounds

cb(x, event) gives pointwise confidence bounds on a cause’s cumulative incidence: two-sided [lower, upper] rows by default, or one side with bound="lower" or "upper", at the level alpha_ci (0.05, a 95% interval). The variance is Aalen’s, the var that R’s cmprsk::cuminc reports, and the interval is formed on the log(-log) scale so that it stays in [0, 1] (bound_type="normal" gives the plain estimate \(\pm\) z standard errors); see Competing Risks Analysis for the formula. With on="sf", "ff" or "Hf" it bounds the all-cause functions (event=None) or a cause’s net ones instead, as KaplanMeier or NelsonAalen (by how) would for the same data.

t = np.array([25.0, 50.0, 100.0, 150.0])
bounds = model.cb(t, "wear")
for ti, f, (lo, hi) in zip(t, model.cif(t, "wear"), bounds):
    print(f"CIF wear at {ti:5.0f}: {f:.3f}  95% CI [{lo:.3f}, {hi:.3f}]")
print("all-cause sf bounds at 100:", np.round(model.cb(100.0, on="sf"), 3))

plt.xlabel("Time")
plt.ylabel("Cumulative incidence")
plt.legend()

Parametric cumulative incidence

ParametricCompetingRisks fits one parametric distribution to each cause (the fit separates by cause, as explained on the theory page). The default is a Weibull for every cause; pass a {cause: distribution} dict to choose per cause. Here we use the distributions the data were simulated from:

from surpyval.univariate.competing_risks import ParametricCompetingRisks

pmodel = ParametricCompetingRisks.fit(
    x, e, dist={"wear": surv.Weibull, "shock": surv.Exponential}
)
print(pmodel)
for k in pmodel.causes:
    print(k, pmodel.models[k].params)

Unlike the step function, the parametric model can be evaluated beyond the last observation. probability_of_cause gives \(F_k(\infty)\), the long-run share of failures from each cause (these sum to one unless a cause has a cure fraction):

for k in pmodel.causes:
    print(k, "eventual probability: %.3f" % pmodel.probability_of_cause(k))

shock eventual probability: 0.465
wear eventual probability: 0.535

The other methods follow the same conventions as CompetingRisks: hf/Hf take an optional event (cause-specific) and otherwise sum over causes; sf and ff are the all-cause survival and failure probability, and with event=k the net survival and failure probability of cause k alone (its own model, as if the other causes were removed); iif(x, event) is the sub-distribution density; and cif(x) without an event is the all-cause incidence 1 - sf. cif returns a float for a scalar time:

print("CIF wear at 100    :", pmodel.cif(100.0, "wear"))
print("all-cause ff at 100:", pmodel.ff(100.0))
print("hazard of shock    :", pmodel.hf(100.0, event="shock"))

CIF wear at 100    : 0.3248846815193291
all-cause ff at 100: 0.744788997447001
hazard of shock    : 0.006529558412992116

Because the joint likelihood is the product of the per-cause likelihoods, neg_ll and aic are sums over causes. bic is the joint criterion 2 neg_ll + K ln(n), with K the parameters of every cause and n the observed failures of any cause (here 189: 83 wear and 106 shock), not the sum of the causes’ own BICs. Either can be used to compare candidate distributions – for example, whether the shock mode needs a Weibull rather than an exponential:

all_weibull = ParametricCompetingRisks.fit(x, e)   # Weibull for both causes

Lifetime of the whole unit: MTTF and B-lives

A unit’s life ends at its first failure from any cause, so the questions “how long does a unit last on average?” (the mean time to failure, MTTF) and “by when have 10% failed?” (the B10 life) are about the all-cause lifetime. The fitted model answers them with mean() and qf(p), and df(x) gives the density of that lifetime.

In formulas: the all-cause survival is the product of the causes’ survivals, \(S(t) = \prod_k S_k(t)\), its density is \(f(t) = S(t)\sum_k h_k(t)\), and

\[\mathrm{MTTF} = \int_0^\infty S(t)\,dt, \qquad B_{10} = F^{-1}(0.1) = H^{-1}\!\left(-\log 0.9\right),\]

with \(H = \sum_k H_k\). Neither has a closed form in general, so the mean is integrated numerically and the quantile found by root finding on the cumulative hazard (which keeps its precision far into the upper tail).

print("MTTF          : %.2f" % pmodel.mean())
print("B10 life      : %.2f" % pmodel.qf(0.1))
print("median life   : %.2f" % pmodel.qf(0.5))
print("net B10, wear : %.2f" % pmodel.qf(0.1, event="wear"))

MTTF          : 71.16
B10 life      : 15.63
median life   : 68.96
net B10, wear : 51.69

The net B10 of wear-out alone, qf(0.1, event="wear"), is much later: it is the B10 a unit would have if shocks could not happen. The all-cause figures are the ones that describe the units actually in service.

If a cause has a cure (limited-failure) fraction, some units never fail, so the MTTF is infinite and a quantile above the share that ever fails is infinite too; mean(defective=True) gives \(\int t\,dF(t)\) over the units that fail, as Parametric.mean does.

Eliminating a failure mode

“If a design change removed the shocks, how long would the units last?” eliminate(cause) returns the model of the causes left, each with its fitted distribution, so its sf, mean, qf, cif and cb answer for the units with that failure mode designed out. The data cannot check that, so it is an assumption to state with the answer.

Assembling a model from separately fitted causes

ParametricCompetingRisks.from_fitted combines already-fitted single-cause models – a {cause: model} dict, or a list whose causes become 0, 1, ... – into one competing-risks model. Each model can use any SurPyval option (a different family, an offset, a limited-failure or zero-inflated fit, …). The one rule: fit each model to the cause-specific view of the data, with that cause’s failures observed and every other row right-censored.

Delayed entry (left truncation). Suppose the components were only put under observation at a random age entry (when the maintenance records start, say), so that units which failed before entering were never seen. Ignoring the entry ages biases the fit; ParametricCompetingRisks.fit takes them as tl (and fit_from_df as tl_col), which is the exact maximum-likelihood fit: the truncated likelihood factorises by cause too, so it is the same as fitting each cause with tl=entry and assembling the result with from_fitted. (Right truncation does not factorise by cause, and fit does not take it; interval censoring does not either, and fit takes it by fitting the causes together, below.)

truth = ParametricCompetingRisks.from_fitted({
    "wear": surv.Weibull.from_params([100.0, 3.0]),
    "shock": surv.Exponential.from_params([1 / 150]),

Failures found at inspections

Often a failure is not seen when it happens but found at the next inspection: the unit was working at one inspection and found failed, with its cause, at the next. Its failure time is known only to lie between the two (interval censored, c = 2, with x the row [xl, xr]); one found failed at the first inspection is left censored (c = -1, x the inspection time). ParametricCompetingRisks.fit takes such rows. A row like that counts the chance that the unit failed from its cause between the two inspections, and that chance depends on every cause – the unit had to survive all of them until it failed – so the causes can no longer be fitted one at a time: with any such row, fit fits them together, by maximum likelihood over all of their parameters at once. Without such rows nothing changes.

Because the causes are fitted together, their estimates are correlated: covariance() is the inverse of the joint Hessian, with terms between causes, and every bound (cb on cif, sf, ff and Hf, standard_errors) uses it. Each cause’s model in models carries its parameters and its block of that covariance, so its own Wald bounds hold; it has no data of its own, so its likelihood-ratio and bootstrap bounds, neg_ll and aic are the model’s, not the cause’s. A cause’s net sf, ff and Hf take method="lr" and method="bootstrap" on the model, over the joint likelihood: the likelihood-ratio bound profiles every cause’s parameters (with one cause it is the univariate fit’s bound), and the bootstrap is by cases – the units resampled with their windows, the causes fitted together again – since a parametric resample would need the inspection schedule. In formulas: a unit that entered at \(t_l\) and was found failed from cause \(k\) in \((x_l, x_r]\) contributes

\[\frac{\mathrm{CIF}_k(x_r) - \mathrm{CIF}_k(x_l)}{S(t_l)} = \frac{1}{S(t_l)} \int_{x_l}^{x_r} f_k(u) \prod_{j \neq k} S_j(u)\,du,\]

a left-censored one the same from \(t_l\) (or the start) to \(x\). The integral is taken by Gauss-Legendre quadrature on the cause’s own probability scale, refined until it holds to about \(10^{-12}\).

The non-parametric estimate for inspection data

The Aalen-Johansen estimate needs each failure’s time. Given windows (any left- or interval-censored row), CompetingRisks.fit takes the same rows as ParametricCompetingRisks and estimates each cause’s cumulative incidence without assuming any distribution, by the non-parametric maximum-likelihood estimate (NPMLE); the fitted model’s estimator says which estimate it holds ("Aalen-Johansen" or "NPMLE"). In plain words: it shares out each unit’s failure among the stretches of time its window could have held it, with each cause’s share put where the other units’ windows overlap most, and picks the shares that make the data most likely. With exact times this is the Aalen-Johansen estimate; with one cause it is Turnbull’s.

The estimate is a step function, and the data cannot say where inside a window the failures happened: each cause’s curve is flat across an interval and steps up at its end, as Turnbull’s survival curve does. innermost_intervals(cause) lists those intervals and the probability on each; beyond is the share of units not failed by the end of follow-up. The bounds are by the case bootstrap (the units resampled and the estimate refitted), and are approximate: an estimate from inspection data settles more slowly than one from exact times.

Two more things it takes. A failure whose cause was not recorded counts, with masked="include", as a failure from some cause in its window (this assumes that whether a cause was recorded does not depend on which cause it was). And the curves can be drawn with plot(), as for exact times.

What needs each failure’s time is refused with a message saying what to use instead: a cause’s net survival (sf(x, event)), the hazard and density (hf, df, iif), the restricted mean time lost (rmtl, which depends on where inside each window the failures happened), set_support, the stacked plot, weights and delayed entry.

In formulas (Hudgens, Satten and Longini 2001): with \(p_{kj}\) the probability of cause \(k\) on interval \(j\), the estimate maximises

\[\prod_i \Big(\sum_{(k, j) \subseteq \text{row } i} p_{kj}\Big)^{n_i},\]

a row found failed from cause \(k\) in \((x_l, x_r]\) covering cause \(k\)’s intervals inside its window, a row whose cause was not recorded every cause’s, and a right-censored row every cause’s after \(x_l\) and the probability left after follow-up. Cause \(k\)’s intervals are the innermost intervals (Turnbull’s maximal intersections) of the windows of the rows that can hold it. The maximum is found by the EM algorithm, accelerated by SQUAREM, until its Karush-Kuhn-Tucker conditions hold to tol.

Comparing incidence across groups: Gray’s test

Having estimated a cumulative incidence function for each group, surpyval.gray_test tests whether the CIFs differ for a chosen cause. It is the competing-risks analogue of the log-rank test, but with an important distinction: where a cause-specific log-rank compares the instantaneous hazards of a cause, Gray’s test compares the incidence — the CIFs directly. It does this by keeping competing-cause failures in the subdistribution risk set, rather than removing them, with each group’s risk set estimated from that group’s own data (and so its own censoring distribution). Reach for it when the clinical or engineering question is “how many fail of this cause”, not “how fast”.

Pass the observed times x, the per-observation cause label e, the group label, and the cause of interest as event; optional n gives row counts. Censored rows follow the same rules as for the model classes (see Competing-risks data format): a missing cause (None or NaN) marks a censored row, and an optional c must agree with it.

Here two groups have genuinely different cause-1 incidence:

from surpyval import gray_test

rng = np.random.default_rng(7)

def simulate(n, p_cause1):
    is1 = rng.random(n) < p_cause1
    t = rng.exponential(6.0, n)
    return t, np.where(is1, 1, 2)         # causes labelled 1 and 2

x_a, e_a = simulate(300, 0.35)
x_b, e_b = simulate(300, 0.60)            # higher cause-1 incidence
x = np.concatenate([x_a, x_b])
e = np.concatenate([e_a, e_b])
group = np.array([0] * 300 + [1] * 300)

result = gray_test(x, e, group, event=1)
print('statistic = %.2f   df = %d   p = %.3g'
      % (result.statistic, result.df, result.p_value))

statistic = 47.93   df = 1   p = 4.41e-12

The tiny p-value correctly flags the difference in cause-1 incidence. The result is a named tuple (statistic, df, p_value, cause, groups); df is the number of groups minus one, so more than two groups are compared in one test. The statistic is Gray’s (1988): an observed-minus-expected count of cause-1 failures on the subdistribution risk sets, with Gray’s asymptotic variance (the Competing Risks Analysis page gives the formulas).

Calibration

On data where the groups share the same incidence the test is calibrated, returning p-values spread over [0, 1] — including under censoring, and when the groups are censored differently. A quick check: simulate many pairs of groups with identical cause-specific hazards and independent censoring, and count how often p < 0.05. The second pair of groups is censored very differently, exponentially with means 2 and 50:

rng = np.random.default_rng(3)

def simulate_cr(n, h1, h2, cens_mean):
    t1 = rng.exponential(1 / h1, n)       # latent cause-1 time
    t2 = rng.exponential(1 / h2, n)       # latent cause-2 time
    cz = rng.exponential(cens_mean, n)    # censoring time
    x = np.minimum.reduce([t1, t2, cz])
    e = np.where(x == cz, None, np.where(t1 < t2, 1, 2)).astype(object)
    return x, e

def rejection_rate(cens_mean_0, cens_mean_1, n=100, reps=200):
    p_values = []
    for _ in range(reps):
        x0, e0 = simulate_cr(n, 0.1, 0.2, cens_mean_0)
        x1, e1 = simulate_cr(n, 0.1, 0.2, cens_mean_1)
        res = gray_test(np.concatenate([x0, x1]),
                        np.concatenate([e0, e1]),
                        np.repeat([0, 1], n), event=1)
        p_values.append(res.p_value)
    return np.mean(np.array(p_values) < 0.05)

same = rejection_rate(10.0, 10.0)
different = rejection_rate(2.0, 50.0)
print("same censoring:      rejection rate at 5%%: %.3f" % same)
print("different censoring: rejection rate at 5%%: %.3f" % different)

same censoring:      rejection rate at 5%: 0.065
different censoring: rejection rate at 5%: 0.035

Both rejection rates are close to the nominal 5%, as they should be when the null hypothesis is true.

Gray’s test for failures found at inspections

Gray’s test needs each failure’s time. Given windows, gray_test gives each failure in a window a plausible exact time (and cause, if not recorded), drawn from the non-parametric estimate of all the groups together, runs Gray’s test on the completed data, and repeats this to average out the guesswork (multiple imputation). Each repeat first refits the estimate to a resample of the units, so the spread between repeats includes the estimate’s own uncertainty, and the combined test accounts for it. With no windows nothing is imputed and it is Gray’s test exactly, as always.

from surpyval import gray_test

rng = np.random.default_rng(11)
n = 300

The result is the same named tuple as for exact times, (statistic, df, p_value, cause, groups), with the imputation’s details as attributes. Imputing from the pooled estimate is imputing as if the null hypothesis held, as the score tests of interval-censored survival data do (interval_logrank): it keeps the test’s size when the groups are inspected on different schedules, at some cost in power. In the calibration study (surpyval/tests/calibration/test_size_interval_gray.py: two groups of 100 with the same incidences, one inspected every time unit and the other every 3, follow-up ending uniformly between 10 and 25, 300 replicates of 10 imputations), it rejected at the 5% level in 3.3% of replicates and at the 10% level in 8.3%: a little conservative. The test assumes the inspection times do not depend on the failures.

Gray’s test versus a cause-specific log-rank

The difference between “how fast” and “how many” is easiest to see in an example. Give two groups the same cause-1 hazard, but a much higher cause-2 hazard in group B. Cause 1 strikes at the same rate among the survivors in both groups, but in group B most units are removed by cause 2 before cause 1 has a chance, so far fewer of them ever fail from cause 1. A cause-specific log-rank (surpyval.logrank with cause 2 treated as censored) compares the rates and finds nothing; Gray’s test compares the incidence and finds the difference:

from surpyval import logrank

x_a, e_a = simulate_cr(300, 0.1, 0.05, 20.0)    # group A
x_b, e_b = simulate_cr(300, 0.1, 0.30, 20.0)    # group B: more cause 2

Time lost to a cause: the restricted mean time lost

The cumulative incidence answers “what fraction has failed from this cause by time t”. A single number that summarises the whole curve up to a horizon is the restricted mean time lost (RMTL): of the first \(\tau\) units of time, how much, on average, a unit loses to that cause. A unit that fails from the cause at time \(t < \tau\) loses \(\tau - t\); a unit that survives to \(\tau\), or fails from another cause, loses nothing to it. It is the area under the cause’s cumulative incidence,

\[\text{RMTL}_k(\tau) = \int_0^\tau F_k(t)\,dt,\]

so it is in units of time and needs no model for how the causes act (Andersen, 2013). The times lost to all the causes add up to \(\tau\) less the restricted mean survival time (rmst), so with one cause the time lost is just \(\tau - \text{RMST}\).

rmtl(event, tau) gives it with a standard error and a 95% interval; tau defaults to the largest observed time:

import numpy as np
import surpyval as sp

rng = np.random.default_rng(3)

def simulate(n, shock_mean):
    wear = 100.0 * rng.weibull(3.0, n)
    shock = rng.exponential(shock_mean, n)
    censor = rng.uniform(0.0, 250.0, n)
    x = np.minimum.reduce([wear, shock, censor])
    e = np.where(x == censor, None, np.where(wear < shock, "wear", "shock"))
    return x, e.astype(object)

old = sp.CompetingRisks.fit(*simulate(200, 150.0))
new = sp.CompetingRisks.fit(*simulate(200, 600.0))
res = old.rmtl("shock", tau=100)
print("time lost to shocks in the first 100 hours: %.1f (%.1f to %.1f)"
      % (res["rmtl"], res["lower"], res["upper"]))

time lost to shocks in the first 100 hours: 23.8 (18.8 to 28.8)

surpyval.rmtl_diff compares the time lost to a cause between two groups, as rmst_diff compares survival: the difference with its interval and a z-test of no difference, and the ratio with its interval. Here a design change that makes shocks four times rarer saves many hours in the first 100:

ratio 4.37 (2.54 to 7.53)

The standard error is the delta method’s on the hazard increments at each event time (a multinomial at each time, as Greenwood’s formula takes a binomial); with one cause it is exactly the Greenwood-based standard error of KaplanMeier.rmst. It is the standard error of R’s GFDrmtl package, and within 1% of R survival’s summary(fit, rmean = tau) (an infinitesimal-jackknife standard error) on the data checked. The interval is rmtl +- 1.96 se; in simulation (n = 200) it covers the true time lost about 95% of the time, and rmtl_diff’s test rejects about 5% of the time when the groups do not differ. A tau past the last observed time is refused while some units are still event-free there, as for rmst. A model fitted with weights refuses rmtl: its robust variance is not built.

ParametricCompetingRisks.rmtl gives the same quantity from the fitted distributions, by numerical integration of the cumulative incidence, with a delta-method standard error over every cause’s parameters and an interval on the logit of rmtl / tau (so within 0 and tau); a tau past the data is allowed, the fit extrapolating. rmtl_diff accepts either kind of model in either position.

Fine-Gray Sub-distribution Hazards

The Fine-Gray model estimates the effect of covariates directly on the cumulative incidence function of a chosen cause, using an inverse-probability-of-censoring-weighted subdistribution risk set. e is the per-observation cause label (None for a censored row) and event selects the cause of interest. Z is the covariate matrix, one row per observation.

The baseline, and so phi(Z), is that of a unit with every covariate at 0, unless the model is fitted with center=True, which puts it at the covariate means (model.center). With a covariate such as a temperature in °C, phi at 50 is the multiplier relative to 0 °C: fit with center=True, or compare two units as phi(Z1) / phi(Z0). standard_errors(robust=...), covariance(...) and phi(Z) are methods, called for their values, where beta and coefficients are arrays.

Here we simulate two-cause data whose cause-1 incidence follows a Fine-Gray model with coefficients \((0.7, -0.4)\), apply right-censoring, and recover the coefficients. (This is the simulation design of Fine and Gray’s paper: the true CIF of cause 1 is \(F_1(t \mid Z) = 1 - \{1 - p(1 - e^{-t})\}^{\exp(Z\beta)}\) with \(p = 0.5\).)

from surpyval.univariate.competing_risks import FineGray

rng = np.random.default_rng(1)
N, beta, p = 800, np.array([0.7, -0.4]), 0.5
Z = rng.uniform(-1, 1, size=(N, 2))
phi = np.exp(Z @ beta)
p1 = 1 - (1 - p) ** phi                    # P(cause = 1 | Z)
is1 = rng.uniform(size=N) < p1

x = np.empty(N)
e = np.empty(N, dtype=object)
v = rng.uniform(size=N)
w = 1 - (1 - v * p1) ** (1 / phi)          # invert the cause-1 CIF
x[is1] = (-np.log(np.clip(1 - w / p, 1e-12, 1.0)))[is1]
e[is1] = 1
x[~is1] = rng.exponential(1.0, size=N)[~is1]   # cause 2 mops up the rest
e[~is1] = 2

cens = rng.exponential(3.0, size=N)        # independent right-censoring
c = (x > cens).astype(int)
x = np.minimum(x, cens)
e[c == 1] = None

model = FineGray.fit(x, Z, e, c=c, event=1)

Things to watch:

  • event must be given when the data contain more than one cause, and it must be one that is observed; with a single cause it may be omitted.

  • With fewer than ten events of the cause per coefficient the fit warns, with the counts: the coefficients, p-values and bounds then rest on few events (Peduzzi et al.’s rule of ten events per variable).

  • The Fine-Gray model is fitted for one cause at a time. To model every cause, use CompetingRisksProportionalHazards with model="Fine-Gray" (below); the separate fits are not constrained to be mutually consistent.

  • For many covariates, or correlated ones, FineGray.fit_penalised adds a ridge, lasso or elastic-net penalty (the objective of R’s fastcmprsk::fastCrrp; see the penalised regression section of Regression Modelling with SurPyval). The penalised model predicts the incidence, but has no standard errors.

  • Censoring times tied with event times (common when times are recorded in whole days or months) follow R’s cmprsk::crr: the event is taken to come first. A unit that failed from a competing cause at \(x_i\) keeps the weight \(\hat{G}(t^-)/\hat{G}(x_i^-)\) at a later event time \(t\), with \(\hat{G}\) the Kaplan-Meier estimate of the censoring survival taken just before each time, so censorings at \(t\) or at \(x_i\) do not count against the events there. These are crr’s weights; without such ties the left limits are just \(\hat{G}(t)\) and \(\hat{G}(x_i)\). See Competing Risks Analysis for the details.

Strata and clusters

Two common departures from the plain model have their own options.

Strata. When the units come from a few groups (sites, centres, production lines) whose cause-1 incidence has a different shape over time, or whose censoring differs, strata= gives each group its own baseline subdistribution hazard and its own censoring distribution, while the covariates’ effects are shared (Zhou, Latouche, Rocha and Fine, 2011; R’s crrSC::crrs). This is the competing-risks counterpart of a stratified Cox model: use it for a factor you need to allow for but do not need an effect for. Predictions then name the stratum:

site = np.where(np.arange(N) % 3 == 0, "east", "west")
by_site = FineGray.fit(x, Z, e, c=c, event=1, strata=site)
print(by_site.beta.round(3), by_site.standard_errors().round(3))
print(by_site.cif([0.5, 1.0], Z=[1.0, 0.0], stratum="east").round(3))

[ 0.768 -0.416] [0.102 0.096]
[0.378 0.527]

With many small strata (a stratum per centre with a handful of units each) a censoring distribution per stratum is poorly estimated; then strata_censoring="common" estimates one for all the strata, each still with its own baseline (crrs’s ctype = 2).

Clusters. When units are not independent of each other within a group (the two eyes or kidneys of a patient, the pumps of one station, the components of one machine), cluster= keeps the estimates and makes the standard errors allow for the dependence: the robust covariance adds up the influence of a cluster’s units before squaring it (Zhou, Fine, Latouche and Labopin, 2012; R’s crrSC::crrc). Without it, a covariate shared by the units of a cluster has standard errors that are too small.

pair = np.arange(N) // 2
paired = FineGray.fit(x, Z, e, c=c, event=1, cluster=pair)
print(paired.beta.round(3), paired.standard_errors().round(3))

[ 0.77  -0.416] [0.104 0.094]

Both combine with each other and with weights w, and fit_from_df takes them as strata_col and cluster_col. SurPyval treats each unit as independent unless cluster= says otherwise. R’s crrs with ctype = 2 also treats each stratum as a cluster, which widens the standard errors (on the test data, by 1.5 to 1.7 times); to get R’s numbers, fit with strata_censoring="common", cluster=<the strata>. With only a few strata, a cluster per stratum makes the standard errors themselves unreliable, which is why it is not the default. The model-based covariance (covariance(robust=False)) ignores the clusters, and the diagnostics (diagnose(), the proportionality tests and the residuals) refuse a fit with strata or clusters, as their tests take one baseline and independent units: check proportionality on the fit without them, or within each stratum.

With model="Cox" the model has the usual functions, each taking the times, one covariate vector Z and an optional event:

  • cif(x, Z, event) – the cumulative incidence of event at Z: over each step \(x_j\) the unit, event-free with probability \(\hat{S}(x_{j-1} \mid Z) = e^{-H}\), fails with probability \(1 - e^{-\Delta H}\), and cause \(k\) takes the share \(\Delta H_k / \Delta H\) of it (the matrix-exponential form R’s survival uses for a multi-state coxph);

  • Hf/hf – the cause-specific cumulative hazard and its increment at the most recent event time; with event=None they are summed over causes, each cause with its own coefficients;

Delayed entry in the cause-specific model

Records often start after the units did: patients enter a registry at diagnosis, machines enter the maintenance system when it goes live. A unit that failed before it entered is never seen, and a unit that entered at age 3 was not at risk, as far as the data know, before age 3. Pass each row’s entry age as tl (tl_col for fit_from_df) and the cause-specific model counts a unit in a risk set only once it has entered, tl < t <= x, as CoxPH does; every cause’s coefficients and baseline, and so the incidences, use those risk sets. Here the units come under observation at a uniform age between 0 and 4, and only those still working then are seen:

rng = np.random.default_rng(11)

Ignoring the entry ages counts the late entrants at risk from age 0, when they could not have been seen to fail, so the baseline hazards come out far too low and the incidence of wear by age 2 is about half the truth. With tl it is recovered. The estimates are conditional on being event-free at the earliest entry, as for KaplanMeier with tl.

The Fine-Gray model (model="Fine-Gray", FineGray) and Gray’s test refuse tl where an entry is after the first time, with a message naming the cause-specific model and the Aalen-Johansen estimate: their subdistribution risk set keeps the units that already failed from another cause, and with late entry it needs truncation weights, which SurPyval does not build (see Competing Risks Analysis).

Fitting from a DataFrame

fit_from_df takes the time and cause column names, and the covariates either as Z_cols (a column name or list of names) or as a formula; c_col, n_col, model and tie_method (default "efron", passed to each cause’s Cox fit) are optional. Parametric Competing-Risks Regression

The cause-specific Cox model above tells you how a covariate changes each cause’s hazard, but its cumulative incidences are step functions that stop at the last event: it cannot say what happens after the study ends. ParametricCompetingRisksRegression answers the same question with a parametric model for every cause, so each cause’s cumulative incidence is a smooth curve, at any covariate values, that carries on past the data:

  • an engineer with two years of field returns asks what share of pumps running hot will have had a seal failure by the end of a five-year warranty, when bearings fail too;

  • a clinician asks for a patient’s ten-year probability of dying of the disease, given age and stage, from a study with six years of follow-up, when patients also die of other causes.

Each cause gets its own regression of its hazard on the covariates: a Weibull proportional hazards model by default (model=WeibullPH), or any of the parametric regressions (ExponentialPH, WeibullAFT, LogNormalAFT, LogLogisticPO and the rest), the same for every cause or one per cause in a dict. Each cause is fitted with the failures of the other causes treated as censored; that is the maximum-likelihood fit of the whole model, and it does not assume the causes are independent (the theory page, Competing Risks Analysis, explains why).

Here 600 pumps run at a temperature between 40 and 80 degrees. Seals wear out, faster when hot; bearings fail at a rate that temperature does not change. The test stops at 8 (thousand hours), so the data end there:

from surpyval import (
    ExponentialPH,
    ParametricCompetingRisksRegression,
    WeibullPH,
)

pump_e[pump_first > 8.0] = None            # still running at the end

Scoring predictions of one cause: Brier score and AUC

Once a model predicts each subject’s cumulative incidence of a cause, two questions follow: are the predicted probabilities close to what happened (the Brier score: lower is better), and do the subjects who went on to have that cause by a time get higher predictions than those who did not (the time-dependent AUC: 0.5 is chance, 1 is perfect)? The prediction metrics of surpyval.metrics answer both for one cause at a time: pass the event types as e and the cause scored as cause, and the predicted cumulative incidences F_k(t | Z) of that cause in place of predicted survival.

Censored subjects are handled as for the ordinary metrics, by weighting the others by the inverse of the probability of being still under observation (IPCW, with the Kaplan-Meier estimate of the censoring of every cause). What is new is the subject whose first event is of another cause: they can never have the scored cause, so

  • in the Brier score they count, with their weight, as subjects whose outcome is “no event of this cause”, and

  • in the AUC they count as controls, alongside the subjects still free of every event (controls="cause_free", the default, as R’s riskRegression::Score and timeROC’s AUC_2); controls="event_free" leaves them out and compares the cases with the event-free subjects only (timeROC’s AUC_1).

Here two cause-specific Cox models are fitted to the first 500 subjects of the Fine-Gray simulation above, one with both covariates and one with \(Z_2\) only, and scored for cause 1 on the other 300. brier_score(), integrated_brier_score() and auc_td() take the same e and cause and return the bare estimates. A cause that is not among the event types is refused, as is cause without e.

In formulas, with \(\hat G\) the censoring Kaplan-Meier, \(\delta_i\) the event indicator and \(\epsilon_i\) the cause of subject \(i\)’s event, the Brier score of cause \(k\) at \(t\) is

\[BS_k(t) = \frac1n \sum_i \Big[ \frac{(I(\epsilon_i = k) - F_k(t\mid Z_i))^2\, I(x_i \le t,\ \delta_i=1)}{\hat G(x_i-)} + \frac{F_k(t\mid Z_i)^2\, I(x_i > t)}{\hat G(t)} \Big],\]

and the AUC is the weighted proportion of (case, control) pairs the predictions order correctly, ties counting half, with the cases (\(x_i \le t\), \(\epsilon_i = k\)) weighted by \(1/\hat G(x_i-)\), the event-free controls by \(1/\hat G(t)\) and the competing-event controls by \(1/\hat G(x_j-)\) (Blanche, Dartigues and Jacqmin-Gadda 2013). The standard errors come from the same influence functions as for one cause, and agree with riskRegression::Score(cause = k, se.fit = TRUE) to rounding: Brier score, AUC, the integrated Brier score and the comparisons, with and without tied times. For a cause other than the first one, Score (version 2026.3.11) gives AUC standard errors that change when the causes are relabelled; SurPyval’s match those it gives with the cause coded 1, which also agree with timeROC.
