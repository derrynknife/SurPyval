Glossary

Survival analysis grew up separately in several fields, and each named the same ideas in its own words. An engineer’s failure is a clinician’s event; a suspension is a right censored observation; reliability is survival. SurPyval is for anyone with time-to-event data, so these pages use the words together where a method is general and keep a field’s own word where the method belongs to that field (reliability growth, test planning, B-lives).

The API has one name for each thing, whatever the field: the censoring flag is always c, the survival function is always sf. This page maps the vocabularies to each other and to those names. It changes nothing in the API.

The censoring flag

SurPyval’s flag c says where the event lies relative to the recorded value: 0 at it (the event was observed), 1 to its right (right censored), -1 to its left (left censored) and 2 between two values (interval censored). Clinical data sets, and some other software, more often carry an event indicator or status column in which 1 means the event happened and 0 means censored, which is the reverse for the two commonest codes. Convert such a column before fitting:

import numpy as np
import surpyval as surv

weeks = [6, 13, 21, 30, 31, 37, 38, 47, 49, 50]
event = np.array([1, 1, 1, 1, 0, 1, 0, 1, 0, 0])  # 1 = relapsed

c = 1 - event           # SurPyval: 0 = event, 1 = right censored
model = surv.KaplanMeier.fit(weeks, c)
print(model.sf(26))

0.7

For a table, SurpyvalData.from_dataframe does the conversion itself when the status column is named with event_col in place of c_col (see Data Wrangling Examples). Conventions defines the flags, and every other input, exactly.

Words that belong to one field

Some terms have no everyday counterpart elsewhere, because the method was developed for one field’s problem. They are used as they are:

  • Reliability growth, Crow-AMSAA, Duane: models of how the rate of failures of a repairable system changes as a design is developed. See Recurrent Event Analysis.

  • Demonstration test, success-run test, accelerated life test plan: planning how many units to test, and for how long, before a test is run. See Test Planning with SurPyval.

  • Accelerated life, life-stress relationship (Arrhenius, Eyring, inverse power law): regression in which a physical stress shortens life by a known law. See Regression Analysis.

  • Probability plot (Weibull plot): axes scaled so that a chosen distribution is a straight line. See Parametric Estimation.

  • Log-rank test, hazard ratio, cumulative incidence, subdistribution hazard: at home in medical statistics, and used with the same names for any kind of unit. See Non-Parametric Estimation, Regression Analysis and Competing Risks Analysis.

New to all of it? Survival Analysis from Scratch introduces these ideas one at a time.
