Semi-Parametric Proportional Odds

The proportional odds model with the baseline left to the data: the covariates multiply the survival odds, \(S(x \mid Z) / F(x \mid Z) = e^{\beta' Z} S_0(x) / F_0(x)\), and the baseline failure odds \(G_0 = F_0 / S_0\) are a step function that jumps at the event times, estimated with \(\beta\) by nonparametric maximum likelihood (Murphy, Rossini and van der Vaart, 1997). A positive coefficient means a longer life, as in the parametric PO family in Parametric Regression Models. ProportionalOdds is an instance of the fitter class below. Supports observed and right-censored data, with left truncation. ProportionalOdds.fit_penalised adds a ridge, lasso or elastic-net penalty to the profile likelihood (see the penalised regression section of Regression Modelling with SurPyval).

class surpyval.univariate.regression.proportional_odds.proportional_odds.ProportionalOdds_

Bases: FitterRepr

The semi-parametric proportional odds model: the covariates multiply the survival odds of a baseline left to the data,

\[\frac{S(x \mid Z)}{F(x \mid Z)} = e^{\beta' Z}\, \frac{S_0(x)}{F_0(x)},\]

the proportional-odds counterpart of CoxPH, fitted by nonparametric maximum likelihood (Murphy, Rossini and van der Vaart 1997). A positive coefficient raises the odds of survival, as in the parametric proportional odds models (LogisticPO, PO(...)); R’s timereg::prop.odds and mets::logitSurv model the odds of failure, so their coefficients have the opposite sign. ProportionalOdds is an instance of this class; its fit returns a ProportionalOddsModel.

fit(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None, tol: float = 1e-09, center: bool = False, *, unit=None) → ProportionalOddsModel

Fit the semi-parametric proportional odds model.

The coefficients maximise the profile likelihood, the likelihood maximised over the baseline odds at each beta (see the module notes), and their standard errors are the profile likelihood’s (the inverse of its negative Hessian at the maximum), as Murphy, Rossini and van der Vaart (1997) justify. The rows are fitted sorted by every column (time, censoring, entry time, covariates, count), so the fit is the same to the last digit whatever order they are given in.

Parameters:

  • x (array_like) – The observed times. Only their order matters. Tied event times share one jump of the baseline, each event contributing its full term (Breslow’s convention for Cox, which R’s coxph with ties = "breslow" and a unit gamma frailty matches); under heavy ties the coefficients are attenuated a little towards 0, as Breslow’s are (by about 5% with 100 events on 30 distinct times).

  • Z (array_like) – The covariates, one row per observation (a 1-D array is one covariate). Rows with a missing or infinite covariate are dropped, with a warning. A constant column (the baseline odds absorb it) or a linear combination of the others is aliased, as in CoxPH: its coefficient is nan and one warning names it.

  • c (array_like, optional) – The censoring flags: 0 observed, 1 right censored. Defaults to all observed. Left (-1) and interval (2) censored rows raise a ValueError; fit those with a parametric proportional odds model (PO(LogLogistic), WeibullPO, …).

  • n (array_like, optional) – The count of each row. Defaults to 1.

  • tl (array_like, optional) – Left-truncation (delayed entry) times: a row is in the risk sets only after its entry time, and its likelihood is conditional on surviving to it.

  • tol (float, optional) – The convergence tolerance: Newton-Raphson on the profile likelihood stops once a step is at most tol standard errors long (measured by the profile information).

  • center (bool, optional) – False (the default) reports the baseline (g0, G0) at Z = 0; True reports it at the covariate means, stored as model.center. The fit runs on centred covariates either way, so the coefficients and predictions are the same; the default refuses, with a ValueError, covariates so far from 0 that the baseline there over- or underflows.

Returns:

The fitted model. If a covariate separates the events from the survivors (a level with no events, say) the likelihood has no finite maximum: the fit warns “No finite maximum” and that coefficient is meaningless.

Return type:

ProportionalOddsModel

Examples

>>> from surpyval import ProportionalOdds
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> Z = df[["fin", "age", "prio"]].values
>>> model = ProportionalOdds.fit(x, Z, c=c)
>>> model.beta.round(4)
array([ 0.391 ,  0.0701, -0.1116])
>>> model.standard_errors().round(4)
array([0.2206, 0.0227, 0.0331])

fit_penalised(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None, penalizer: float | ArrayLike = 0.1, l1_ratio: float = 0.0, standardise: bool = True, tol: float = 1e-09, center: bool = False, w: ArrayLike | float | None = None, *, unit=None) → ProportionalOddsModel

Fit the semi-parametric proportional odds model with a ridge, lasso or elastic-net penalty on the coefficients: for many covariates, or correlated ones.

The fit minimises the negative profile log-likelihood of fit(), \(-p\ell(\beta) = -\max_g \ell(\beta, g)\) (the baseline odds maximised out at each beta), divided by the number of units N (the sum of n), plus

\[\sum_j \lambda_j \left( \frac{1 - a}{2} b_j^2 + a |b_j| \right),\]

with \(\lambda_j\) the penalizer, \(a\) the l1_ratio and \(b_j\) the coefficient of covariate j divided by its standard deviation (standardise=True), as every penalised fit in SurPyval (see CoxPH.fit_penalised). The profile’s gradient and Hessian are exact (the gradient at the solved baseline, and the Schur complement of the observed information), so the solver’s Newton polish and its check of the optimality conditions are those of the other penalised fits. The baseline is the one that maximises the likelihood at the penalised coefficients. With no penalty it is the fit of fit().

The model predicts as the fit’s does, but has no covariance, standard errors, bounds or p-values: penalised estimates are biased towards 0 by design, and intervals from them would not have their stated coverage; those calls raise an error that says so (summary() shows them as nan). Its aic and bic count the effective degrees of freedom.

Parameters:

  • x – As for fit().

  • Z – As for fit().

  • c – As for fit().

  • n – As for fit().

  • tl – As for fit().

  • center – As for fit().

  • penalizer (float or array_like, optional) – \(\lambda\): one value, or one per column of Z (0 leaves a coefficient unpenalised). Default 0.1.

  • l1_ratio (float, optional) – \(a\), from 0 (ridge, the default) to 1 (lasso).

  • standardise (bool, optional) – True (the default) penalises the coefficients of the covariates divided by their standard deviations (count- weighted, divisor N, as glmnet), so the penalty does not depend on their units; the coefficients are reported on the covariates’ own scale either way.

  • tol (float, optional) – The optimality tolerance on the gradient of the objective.

  • w (None) – Weights are refused: fit() takes none either.

Returns:

The fitted model, with penalty (the penalizer per column, l1_ratio, standardise, the columns’ scale and the effective degrees of freedom).

Return type:

ProportionalOddsModel

class surpyval.univariate.regression.proportional_odds.proportional_odds.ProportionalOddsModel

Bases: ParameterBoundsMixin, PenalisedModelMixin, AtCovariatesMixin, ConditionalSurvivalMixin, InformationCriteriaMixin, LinearPredictorMixin, ConcordanceMixin, DiagnoseMixin, SerialisableMixin

A fitted semi-parametric proportional odds model, returned by ProportionalOdds.fit and fit_from_df.

The covariates multiply the survival odds of a baseline whose failure odds \(G_0 = F_0 / S_0\) is a step function:

\[S(x \mid Z) = \frac{1}{1 + G_0(x)\, e^{-\beta' (Z - \text{center})}},\]

so exp(beta) are survival odds ratios, as in the parametric LogisticPO / WeibullPO models (a positive coefficient means a longer life). x are the distinct observed times, g0 the baseline’s jumps there (0 at a time with no event) and G0 its cumulative value, the baseline failure odds; the baseline is that of a unit at center, Z = 0 unless fitted with center=True. Before the first time the survival is 1 and after the last it holds its last value, as for CoxPH.

Examples

On the Rossi recidivism data (arrest is 1 for an arrest, so c = 1 - arrest), financial aid raises the odds of staying out of prison by about 48 %, and each prior conviction lowers them by about 11 %:

>>> from surpyval import ProportionalOdds
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> model = ProportionalOdds.fit(x, df[["fin", "age", "prio"]].values, c=c)
>>> model.beta.round(4)
array([ 0.391 ,  0.0701, -0.1116])
>>> model.sf([20, 52], [1, 25, 3]).round(4)
array([0.9351, 0.7938])

Notes

The correction \((2k^2 + 2k)/(N - k - 1)\) uses the same sample size \(N\) as bic(): the number of observed failures (exact, left- or interval-censored, weighted by their counts), or the number of units when there is none. Right-censored units do not add to it. The correction only exists for \(N > k + 1\); otherwise the corrected criterion is undefined and nan is returned (the formula gave inf at \(N = k + 1\), and a value below aic() for smaller \(N\), which would have won a comparison).

concordance(x: ArrayLike | None = None, c: ArrayLike | None = None, Z: Any = None, tie_tol: float = 1e-08, ties: str = 'therneau', *, weighting: str = 'harrell', tau: float | None = None, alpha_ci: float = 0.05, ci_method: str = 'normal') → ConcordanceResult | float

Harrell’s (or Uno’s) concordance index (C) of the model’s risk scores, with its standard error and confidence interval.

The proportion of usable pairs of subjects – the one with the earlier time had the event – in which the model gives that subject the higher risk: 1 ranks every pair correctly, 0.5 is chance. With no arguments it scores the data the model was fitted to (each row counted n times); pass x, c and Z together to score other data, such as a test set. Two events at the same time are not a pair (ties="therneau", as R’s concordance and lifelines) unless ties="harrell"; see surpyval.metrics.concordance_index() for the treatment of tied times and scores.

The risk score, higher meaning an earlier event, is for each family:

  • CoxPH, the frailty models and AdditiveHazards (Lin-Ying): the linear predictor \(\beta'Z\) (the log hazard ratio, or the covariates’ additive hazard), as R’s concordance and lifelines use;

  • the parametric families (PH, AFT, PO, AH and the accelerated life models): the cumulative hazard \(H(t^* \mid Z)\) at \(t^*\), the median of the times scored. For every family whose covariates act through a linear predictor this ranks the rows exactly as the linear predictor does, with the sign that means a higher risk (\(\beta'Z\) for PH, AFT and AH, \(-\beta'Z\) for PO), and \(t^*\) does not matter; it can only matter for an accelerated life model whose life model sets a shape parameter;

  • BuckleyJames: \(-\beta'Z\), since the model is linear in the log time;

  • ProportionalOdds: \(-\beta'Z\), the log of the odds of failure relative to the baseline’s.

Parameters:

  • x (array_like, optional) – Observed times.

  • c (array_like, optional) – Censoring flags, 0 an event and 1 right censored.

  • Z (array_like or DataFrame, optional) – Covariates, one row per time (a DataFrame for a model fitted with fit_from_df).

  • tie_tol (float, optional) – Scores within this of each other are tied. Default 1e-8.

  • ties ({"therneau", "harrell"}, optional) – "therneau" (the default, as R’s survival::concordance and lifelines): two events at the same time are not a usable pair. "harrell" (Harrell’s original definition): they are, counting 1 if their scores are tied, else 0.5.

  • weighting ({"harrell", "uno"}, optional) – "harrell" (default): every usable pair weighs 1. "uno": Uno’s inverse-probability-of-censoring weighted C, each pair weighted by 1 / G(t-)^2 (see surpyval.metrics.concordance_index()).

  • tau (float, optional) – Count only the pairs whose earlier time is at most tau. Default None, every pair.

  • alpha_ci (float, optional) – Keyword only: the significance level of the interval. Default 0.05.

  • ci_method ({"normal", "logit"}, optional) – Keyword only: the scale of the interval. Default "normal".

Returns:

The concordance index, a float that carries its infinitesimal-jackknife standard error se and interval ci (surpyval.metrics.concordance_index()). With no data it scores the data the model was fitted to, each row repeated n times as its own subject (as R does with the rows repeated); the standard error treats the scores as fixed, as R’s does. A plain nan where a covariate is missing.

Return type:

ConcordanceResult

Raises:

ValueError – If only some of x, c and Z are given, or none are and the model does not keep its training data (a model restored with from_dict, or one fitted with time-varying covariates, whose rows are intervals of a subject’s history).

Examples

>>> import surpyval as sp
>>> from surpyval.datasets import load_lung
>>> lung = load_lung().dropna(subset=["ph.ecog"])
>>> lung["censored"] = 1 - lung["status"]  # status 1 is a death
>>> model = sp.CoxPH.fit_from_df(
...     lung, x_col="time", c_col="censored",
...     Z_cols=["age", "sex", "ph.ecog"],
... )
>>> round(model.concordance(), 4)
0.6371
>>> round(model.concordance(ties="harrell"), 4)
0.6369

cs(x: ArrayLike, given: ArrayLike, Z: Any, *args: Any, **kwargs: Any) → Any

Conditional survival: the probability that a unit with covariates Z that has survived to given survives a further x,

\[R(x \mid given, Z) = \frac{R(given + x \mid Z)}{R(given \mid Z)} = e^{-(H(given + x \mid Z) - H(given \mid Z))},\]

the univariate models’ cs(x, given) with the covariates of sf() (#581).

Parameters:

  • x (array like or scalar) – The further durations.

  • given (array like or scalar) – The ages already survived, broadcast against x (one age per unit and one x for all, say).

  • Z (array like or DataFrame) – The covariates, paired with the times as sf() pairs them: one row per element of x / given, or a single row for all of them.

  • *args – Any further arguments of this model’s Hf() (grid=True for every time for every row; a Cox model’s stratum; a frailty model’s group or frailty).

  • **kwargs – Any further arguments of this model’s Hf() (grid=True for every time for every row; a Cox model’s stratum; a frailty model’s group or frailty).

Returns:

cs – The conditional survival probabilities.

Return type:

scalar or numpy array

Notes

The ratio is taken from the model’s cumulative hazard, which keeps it exact where \(R(given)\) underflows (a unit far into the tail). Where \(R(given \mid Z) = 0\) the conditional survival is undefined and nan is returned, as for the univariate models. A fleet’s expected failures over a horizon, built on this, are surpyval.forecast().

Examples

>>> import numpy as np
>>> from surpyval import Weibull, WeibullPH
>>> np.random.seed(1)
>>> Z = np.random.binomial(1, 0.5, 100).reshape(-1, 1)
>>> x = Weibull.random(100, 10, 2) * np.exp(-0.5 * Z[:, 0])
>>> model = WeibullPH.fit(x, Z)

Two units, aged 2 and 8, surviving one more unit of time:

>>> model.cs(1.0, [2.0, 8.0], [[0], [1]]).round(4)
array([0.9362, 0.6843])
>>> s = model.sf([3.0, 9.0], [[0], [1]])
>>> (s / model.sf([2.0, 8.0], [[0], [1]])).round(4)
array([0.9362, 0.6843])

diagnose(alpha: float = 0.05, columns: Sequence[str] | None = None, *, n_boot: int | None = None, random_state: Any = None, **options: Any) → Diagnosis

Check the model’s assumptions, fit and influential points, and say what to do about any that fail.

Runs the checks this kind of model calls for (for a Cox model: proportional hazards, the functional form of each continuous covariate, influence and outliers; see Model Diagnostics) and returns a report: d.table, one row per check with its test, statistic, p-value, verdict ("ok", "warn" or "fail") and covariates; d.advice, plain-English remedies that each name the SurPyval feature that applies them; d.plot(), the visual checks (matplotlib is only imported then); d.ok, True if nothing failed; d.raise_if_failed() for pipelines; and d.to_dict().

A test fails when its p-value is below alpha, and warns when it is below 2 * alpha (borderline) or could not be computed. Each row is judged at alpha on its own, so with many rows some fail by chance even when every assumption holds.

Parameters:

  • alpha (float, optional) – The level each test is judged at. Default 0.05.

  • columns (str or list of str, optional) – The covariates to check, named as summary() names them (the DataFrame or formula columns, else coef_0, …); all of them by default. A joint (GLOBAL) test still covers every covariate.

  • n_boot (int, optional) – For the families whose tests resample (a univariate distribution’s bootstrap goodness-of-fit tests): the number of bootstrap refits; None is the family’s default. Other families ignore it.

  • random_state (optional) – The seed of those resamples (SurPyval’s one seed rule: None draws from numpy’s global generator).

  • **options – Options of the model’s family, named in Model Diagnostics: for an accelerated life model, use_stress, the stress the model is to predict at (a number, or one per stress column), whose distance from the tested stresses the report screens. A family refuses an option it does not take.

Returns:

See surpyval.diagnostics.Diagnosis.

Return type:

Diagnosis

Raises:

  • NotImplementedError – For a model whose family’s diagnostics are not built yet, saying what to check it with meanwhile; for an option of the model the checks do not support yet; and for a kind of model the checks do not cover by design (a discrete distribution, a parametric regression with a custom link, …), saying what to use instead.

  • ValueError – For a model the checks cannot be run on (one restored with from_dict, which has no data), saying what to do.

param_cb(name: str, alpha_ci: float = 0.05, bound: str = 'two-sided', method: str = 'wald') → NDArray

Confidence bound(s) on a coefficient.

Two methods, as for the parametric regression models; "wald" is the default:

  • "wald" – from the profile likelihood’s information (see covariance()).

  • "lr" – the profile-likelihood interval (#617): the values of the coefficient whose deviance of the profile likelihood \(p\ell(\beta) = \max_g \ell(\beta, g)\), the other coefficients re-fitted, stays below the \(\chi^2_1\) critical value (aliases "likelihood", "likelihood-ratio", "profile"). The profile likelihood ratio is asymptotically \(\chi^2\) in this model, the baseline being profiled out (Murphy and van der Vaart 2000). A side that cannot be found is nan, with a warning. It needs the data the model was fitted to, which a model restored from a dict does not keep.

Parameters:

  • name (str) – The coefficient, one of parameter_names.

  • alpha_ci (float, optional) – Total tail probability of the bound(s). Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are returned as [lower, upper].

  • method ({'wald', 'lr'}, optional) – As above. Default 'wald'.

>>> model.param_cb("coef_0").round(4)
array([-0.0017,  0.8567])
>>> model.param_cb("coef_1").round(4)
array([-0.1853, -0.0559])
>>> model.param_cb("coef_1", method="lr").round(4)

property parameter_bounds: list[tuple[float | None, float | None]]

one (low, high) pair per entry of the vector with_params() takes, in the order of covariance_names (None for an end with no bound).

A parameter set drawn inside these ranges is one with_params does not refuse for being out of range, and one just outside a finite end is refused. Draw a parameter bounded on one side on the log scale of its distance from that end, and one bounded on both on the logit scale between them. Whether an end itself is allowed depends on the parameter (a probability may be 0 where a scale may not), so keep draws strictly inside.

A few models also constrain their parameters jointly, which no per-parameter range can say, and with_params refuses a set that breaks the joint constraint, saying so: a mixture’s weights sum to 1; a Uniform’s a is below its b (as a Beta4’s are); a Royston-Parmar spline does not fall; a Binomial’s n is a whole number. The entry of a parameter with_params ignores (held fixed in the fit, or an accelerated life model’s life parameter) gives the parameter’s range all the same. An accelerated life model’s life-model parameters can have ranges that depend on the stresses fitted to; a model loaded from a dict saved without its data gives them as unbounded.

Examples

>>> Weibull.from_params([10.0, 2.0]).parameter_bounds

>>> model = WeibullPH.fit(
...     x=[1.0, 2, 3, 4, 5, 6, 7, 8], Z=[0.0, 1, 0, 1, 0, 1, 1, 0]
... )
>>> model.covariance_names
['alpha', 'beta', 'coef_0']
>>> model.parameter_bounds
[(0.0, None), (0.0, None), (None, None)]
Type:

The range of each parameter

qf(p: npt.ArrayLike, Z: npt.ArrayLike | pd.DataFrame, *, grid: bool = False) → npt.NDArray

The quantile function: the first baseline time at which the predicted failure probability ff(x, Z) reaches p (#662), nan where it never does – the curve stops at the last observed time, above 1 - p where the data end censored – as the non-parametric estimates’ qf gives it. The median life of a unit with covariates Z is qf(0.5, Z) (R’s quantile(survfit(fit, newdata)), lifelines’ predict_median), its B10 life qf(0.1, Z).

Z is paired with p as sf() pairs it with x: one row for every p, or one p for every row; grid=True gives every p for every row, with shape (len(Z),) + p.shape. A predicted curve within 1e-9 of p counts as reaching it (round-off would otherwise put the quantile a step late), and qf(0, Z) is the first time the curve rises above 0. A probability outside [0, 1] gives nan, with a warning, as every model’s qf.

Examples

>>> from surpyval import ProportionalOdds
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> model = ProportionalOdds.fit(x, df[["fin", "prio"]].values, c=c)
>>> model.qf(0.1, [[0, 0], [1, 0], [0, 10]])
array([26., 37., 12.])
random(size: int, Z: npt.ArrayLike | pd.DataFrame, random_state: Any = None) → tuple[npt.NDArray, npt.NDArray]

Draw size lifetimes for each covariate row of Z, by inverting qf() on the step survival curve: a uniform U, the survival the draw is to have, gives qf(1 - U, Z), as every regression’s random draws. The curve stops at the last observed time; a draw it never reaches is inf (the unit outlives the data), as often as sf at the last time says. random_state seeds the draw: None (the default) draws from numpy’s global generator; an int or a numpy.random.Generator gives a stream of its own.

Returns the draws and a 2-D array of the covariate row each was drawn at, row by row.
