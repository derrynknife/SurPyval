Pseudo-Observations

Jackknife pseudo-values of the Kaplan-Meier survival, the restricted mean survival time and a cause’s cumulative incidence, and the regression on them (estimating equations with robust standard errors). Importable directly from surpyval; the guide, with worked examples and the sign of the coefficients, is Pseudo-Observations.

surpyval.pseudo_survival(x: ArrayLike, t: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None) → NDArray

Jackknife pseudo-values of the Kaplan-Meier survival at times t.

Each unit’s pseudo-value is N S(t) - (N - 1) S_(-i)(t), with S the Kaplan-Meier estimate of all N units and S_(-i) the estimate with unit i left out. A unit that failed before t gets a value near 0, one known to survive past t a value near 1, and one censored before t a value in between (it can fall a little outside [0, 1]). Their mean is S(t). They are R’s pseudo::pseudosurv.

Parameters:

  • x (array_like) – The failure or censoring time of each row.

  • t (float or array_like) – The time(s) at which to take the survival; none past the largest time in x.

  • c (array_like, optional) – Censoring flags: 0 an event (a failure, a death), 1 right-censored (the default is every row an event). Left and interval censoring are refused.

  • n (array_like, optional) – Counts: a row with n = 3 is three identical units, each with the row’s pseudo-value.

  • tl (array_like, optional) – Delayed entry is refused (named only so that the refusal can say what to use instead).

Returns:

One value per row of x: shape (rows,) for a scalar t, (rows, len(t)) otherwise.

Return type:

numpy.ndarray

Examples

>>> import numpy as np
>>> from surpyval import pseudo_survival
>>> x = [1, 2, 3, 4, 5]
>>> c = [0, 1, 0, 0, 1]
>>> pseudo_survival(x, 3, c).round(4)
array([ 0.    ,  0.6667, -0.3333,  1.1667,  1.1667])
>>> round(float(np.mean(pseudo_survival(x, 3, c))), 4)  # S(3)
0.5333
surpyval.pseudo_rmst(x: ArrayLike, tau: float, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None) → NDArray

Jackknife pseudo-values of the restricted mean survival time to tau.

The restricted mean survival time (RMST) is the average time lived up to tau: the area under the Kaplan-Meier curve from 0 to tau. Each unit’s pseudo-value is N m - (N - 1) m_(-i), m the RMST of all N units and m_(-i) that with unit i left out; for a unit followed to tau or to its failure it is close to min(x, tau). Their mean is m. They are R’s pseudo::pseudomean.

Parameters:

  • x (array_like) – The failure or censoring time of each row.

  • tau (float) – The end of the window; not past the largest time in x.

  • c (array_like, optional) – Censoring flags: 0 an event, 1 right-censored.

  • n (array_like, optional) – Counts of identical units.

  • tl (array_like, optional) – Delayed entry is refused.

Returns:

One value per row of x.

Return type:

numpy.ndarray

Examples

>>> from surpyval import pseudo_rmst
>>> pseudo_rmst([1, 2, 3, 4, 5], 4, [0, 1, 0, 0, 1]).round(4)
array([1.    , 3.6667, 2.6667, 4.1667, 4.1667])
surpyval.pseudo_cif(x: ArrayLike, e: ArrayLike, t: ArrayLike, cause: Any, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None) → NDArray

Jackknife pseudo-values of a cause’s cumulative incidence at times t.

With competing causes of failure, the cumulative incidence of a cause is the chance of failing from it by t: the Aalen-Johansen estimate, as CompetingRisks gives it. Each unit’s pseudo-value is N F_k(t) - (N - 1) F_k,(-i)(t). A unit that failed from the cause by t gets a value near 1, one that failed from another cause or survived past t a value near 0. They are R’s pseudo::pseudoci.

Parameters:

  • x (array_like) – The failure or censoring time of each row.

  • e (array_like) – The cause of each failure (any labels); a missing value (None, NaN) marks a right-censored row.

  • t (float or array_like) – The time(s) at which to take the incidence; none past the largest time in x.

  • cause (label) – The cause whose incidence is wanted; one of the labels in e.

  • c (array_like, optional) – Censoring flags (0 an event with a cause, 1 right-censored); derived from e if not given.

  • n (array_like, optional) – Counts of identical units.

  • tl (array_like, optional) – Delayed entry is refused.

Returns:

One value per row: shape (rows,) for a scalar t, (rows, len(t)) otherwise.

Return type:

numpy.ndarray

Examples

>>> from surpyval import pseudo_cif
>>> x = [1, 2, 3, 4, 5, 6]
>>> e = ["a", "b", None, "a", "b", None]
>>> pseudo_cif(x, e, 4, "a").round(4)
array([ 1.    ,  0.    ,  0.3333,  1.3333, -0.1667, -0.1667])
surpyval.pseudo_regression(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, quantity: str = 'survival', t: ArrayLike | None = None, tau: float | None = None, e: ArrayLike | None = None, cause: Any = None, link: str | None = None, names: list[str] | None = None, alpha_ci: float = 0.05, tl: ArrayLike | None = None) → PseudoRegressionResult

Regression on the survival probability, the restricted mean survival time or a cause’s cumulative incidence, through pseudo-observations.

Each unit’s censored time is replaced by its jackknife pseudo-value of the quantity (pseudo_survival(), pseudo_rmst(), pseudo_cif()), and a generalised linear model is fitted to the pseudo-values by estimating equations, g(E[y]) = a(t) + s b'Z, with an independence working model and robust (sandwich) standard errors. With several times t each time has its own intercept and the covariates’ effects are shared. This is the analysis of Andersen, Klein and Rosthoj (2003) and Klein et al. (2008), what R’s geepack::geeglm(..., id = id, corstr = "independence") fitted to pseudo::pseudosurv, pseudomean or pseudoci gives.

The sign: a positive coefficient means a shorter life. The survival regressions model the event probability F(t) = 1 - S(t) (with the default complementary log-log link, log(-log S(t)) = a(t) + b'Z, a proportional-hazards-like model at the chosen times); the incidence regressions model the cause’s incidence; the RMST regression is g(RMST) = a - b'Z, so with the identity link a covariate’s RMST difference is -b.

Parameters:

  • x (array_like) – The failure or censoring time of each row.

  • Z (array_like) – The covariates, one row per row of x (a 1-D array is one covariate). Rows with a missing or infinite covariate are dropped before the pseudo-values are computed, with a warning.

  • c (array_like, optional) – Censoring flags: 0 an event, 1 right-censored.

  • n (array_like, optional) – Counts of identical units (each its own unit in the sandwich).

  • quantity (str, optional) – “survival” (the default), “rmst” or “cif”.

  • t (float or array_like, optional) – The time(s) of a “survival” or “cif” model (needed for them).

  • tau (float, optional) – The end of the window of an “rmst” model (needed for it).

  • e (array_like, optional) – The cause of each failure, for “cif” (None censored).

  • cause (label, optional) – The cause of a “cif” model.

  • link (str, optional) – “cloglog” (the default) or “logit” for “survival” and “cif”; “identity” (the default) or “log” for “rmst”.

  • names (list of str, optional) – The covariates’ names (by default Z’s DataFrame columns, or x0, x1, …).

  • alpha_ci (float, optional) – One minus the level of the intervals ci.

  • tl (array_like, optional) – Delayed entry is refused.

Returns:

The coefficients, their robust standard errors, intervals and p-values, summary(), predict, predict_cb and to_dict().

Return type:

PseudoRegressionResult

Examples

>>> import numpy as np
>>> from surpyval import pseudo_regression
>>> rng = np.random.default_rng(0)
>>> z = rng.normal(size=400)
>>> x = rng.weibull(1.5, 400) * 10 * np.exp(-0.5 * z)
>>> c = (x > 15).astype(int)
>>> x = np.minimum(x, 15)
>>> res = pseudo_regression(x, z, c, quantity="survival", t=[5, 10])
>>> res.names
['Intercept (t=5)', 'Intercept (t=10)', 'x0']
>>> bool(res.coef[2] > 0)  # higher z, shorter life
True
surpyval.pseudo_regression_from_df(df: DataFrame, x_col: str, Z_cols: str | list[str] | None = None, formula: str | None = None, c_col: str | None = None, n_col: str | None = None, e_col: str | None = None, **kwargs: Any) → PseudoRegressionResult

pseudo_regression() from the columns of a DataFrame.

Parameters:

  • df (pandas.DataFrame) – The data.

  • x_col (str) – The column of times.

  • Z_cols (str or list of str, optional) – The covariate columns (or give formula).

  • formula (str, optional) – A formulaic formula for the covariates ("age + C(sex)").

  • c_col (str, optional) – The column of censoring flags.

  • n_col (str, optional) – The column of counts.

  • e_col (str, optional) – The column of causes, for quantity="cif".

  • **kwargs – The other arguments of pseudo_regression() (quantity, t, tau, cause, link, alpha_ci).

Returns:

As pseudo_regression(), with the covariates named.

Return type:

PseudoRegressionResult

Examples

>>> import numpy as np
>>> import pandas as pd
>>> from surpyval import pseudo_regression_from_df
>>> rng = np.random.default_rng(2)
>>> df = pd.DataFrame({"z": rng.integers(0, 2, 200)})
>>> df["x"] = rng.exponential(5 * np.exp(-0.5 * df["z"]))
>>> res = pseudo_regression_from_df(df, "x", "z", quantity="rmst", tau=5)
>>> res.names
['Intercept', 'z']
class surpyval.univariate.regression.PseudoRegressionResult(quantity: str, link: str, times: NDArray, cause: Any, names: list[str], coef: NDArray, cov: NDArray, alpha_ci: float, n_units: float, iterations: int, n_covariates: int, sign: float)

Bases: object

A regression fitted to pseudo-observations, from pseudo_regression().

The coefficients follow SurPyval’s sign: a positive coefficient means a shorter life. For the survival regressions the response is the chance of the event by t, F(t) = 1 - S(t) (with the complementary log-log link, log(-log S(t)) = a(t) + b'Z, so exp(b) is a ratio of cumulative hazards at t, close to a Cox hazard ratio); for the cumulative incidence the response is the incidence of the cause (a positive coefficient, more failures from it). For the restricted mean the response is the RMST and the covariates enter with a minus sign, g(RMST) = a - b'Z: with the identity link -b is the difference in RMST per unit of the covariate (b = 20 means 20 time units less of the first tau), with the log link exp(-b) the ratio of RMSTs.
