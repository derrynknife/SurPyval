Distributional Regression

Every parameter of the distribution has its own covariates and link: \(g_k(\theta_k(z)) = g_k(\theta_k) + s_k x_k(z)' b_k\), with SurPyval’s sign \(s_k\) (a positive coefficient means a shorter life, as in the AFT models: \(s_k = -1\) on a scale or a location). The guide, with a worked example and the rule for each kind of parameter, is Distributional Regression.

Pre-built instances: WeibullDistributional, ExponentialDistributional, GammaDistributional, LogNormalDistributional, LogLogisticDistributional, NormalDistributional, GumbelDistributional and LogisticDistributional.

fit_penalised(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, t: ArrayLike | None = None, penalizer: Any = 0.1, l1_ratio: float = 0.0, standardise: bool = True, tl: ArrayLike | None = None, tr: ArrayLike | None = None, tol: float = 1e-10, w: ArrayLike | float | None = None, covariates: Mapping[str, Any] | None = None, links: Mapping[str, str] | None = None, *, unit=None) → Any

Fit with a ridge, lasso or elastic-net penalty on the covariate coefficients of every parameter (the intercepts, the distribution’s parameters at Z = 0, are not penalised).

The objective is WeibullPH.fit_penalised’s: the negative log-likelihood over N (the sum of n) plus \(\sum_j \lambda_j ((1 - a) b_j^2 / 2 + a |b_j|)\) over the coefficients of the covariates divided by their standard deviations (standardise=True). With covariates on the scale alone and its log link, a Weibull’s fit is WeibullAFT’s penalised fit, coefficient for coefficient (the scale’s coefficients take the AFT sign, model.coefficient_signs). The model has no covariance, standard errors, bounds or tests (they raise an error that says why).

  • Z – As for fit().

  • c – As for fit().

  • n – As for fit().

  • t – As for fit().

  • tl – As for fit().

  • tr – As for fit().

  • covariates – As for fit().

  • links – As for fit().

  • penalizer (float, array_like or dict, optional) – One value for every coefficient; one per column of Z (that column’s coefficient on every parameter); or one per parameter, a dict {"beta": 0.5} whose values are one value or one per column that parameter takes. A parameter the dict does not name is not penalised. Default 0.1.

  • l1_ratio (float, optional) – From 0 (ridge, the default) to 1 (lasso).

  • standardise (bool, optional) – Penalise the coefficients of the standardised covariates (default True).

  • tol (float, optional) – The optimality tolerance on the gradient of the objective.

class surpyval.univariate.regression.distributional.model.DistributionalRegressionModel

Bases: ParametricRegressionModel

A fitted distributional regression (Distributional()): every parameter of the distribution has its own linear predictor and link,

\[g_k\bigl(\theta_k(z)\bigr) = g_k(\theta_k) + s_k\, x_k(z)' b_k,\]

so each row of covariates has its own distribution, here the distribution’s functions at that row’s parameters.

params are the distribution’s parameters at Z = 0 (at center for a fit with center=True), then each parameter’s coefficients on its link scale, named <parameter>_<column>, with SurPyval’s sign s_k (coefficient_signs), that of the AFT models: a positive coefficient means a shorter life.

  • A scale (a Weibull’s alpha): alpha(z) = alpha e^{-b'z}, the AFT model’s coefficient; alpha_load = 0.5 divides the scale by e^0.5 per unit of load.

  • A rate (an Exponential’s failure_rate, a Gamma’s beta): lambda(z) = lambda e^{b'z}, again the AFT model’s.

  • A location (mu of a LogNormal, Normal, Gumbel or Logistic): mu(z) = mu - b'z (mu e^{-b'z} with a log link).

  • A shape that orders lives (a Gamma’s alpha, an ExpoWeibull’s mu, a Beta’s alpha): e^{-b'z}, a positive coefficient lowering it and so shortening lives (a Beta’s beta, which shortens lives as it rises, takes e^{b'z}).

  • A shape or spread that moves some quantiles earlier and others later (a Weibull’s beta, sigma): the link’s own sign, beta(z) = beta e^{b'z}; beta_load = 0.2 multiplies the shape by e^0.2 per unit of load.

covariate_positions holds each parameter’s columns of Z and links its link.

Examples

>>> import numpy as np
>>> from surpyval import WeibullDistributional
>>> rng = np.random.default_rng(3)
>>> load = rng.uniform(0, 1, 300)
>>> x = 10 * np.exp(-0.5 * load) * rng.weibull(1.2 * np.exp(load))

>>> model.parameters_at([[0.0], [1.0]]).round(2)

Hf_tvc(x: ArrayLike, Z: ArrayLike | Any, xl: ArrayLike | None = None) → NDArray

Cumulative hazard for a covariate following a path Z(t): a step schedule, or a continuously varying path.

For the proportional-hazards, additive-hazards and proportional-odds families the hazard at time \(t\) depends only on \(t\) and the covariate value at \(t\), so along a piecewise constant path the cumulative hazard is exactly the sum of the per-segment increments of the constant-covariate cumulative hazard

\[H\bigl(x \mid Z(\cdot)\bigr) = \sum_{\text{seg } (a, b]} \bigl[\,H(b, z) - H(a, z)\,\bigr] .\]

For proportional odds, with \(\phi = e^{\beta' z}\) multiplying the survival odds, the hazard is \(h(t \mid z) = h_0(t) / (F_0(t) + \phi S_0(t))\) and its integral at constant \(z\) is \(H(t, z) = H_0(t) - \ln\phi + \ln(F_0(t) + \phi S_0(t)) = -\ln S(t \mid z)\), so each segment contributes \(\ln[S(a \mid z) / S(b \mid z)]\). On entering a segment the hazard switches to the new covariate’s PO hazard; the survival does not jump to the new covariate’s PO curve. The first segment is held back to the bottom of the baseline’s support (for a baseline defined below zero, such as Logistic, the value in force at time zero is taken to apply before it too), so the result is the unconditional survival.

For accelerated failure time the covariate rescales time, so the path accumulates an accelerated age \(\psi(x) = \sum_{\text{seg}} e^{\beta' z}\,(b - a)\) and the cumulative hazard is the baseline evaluated there, \(H(x \mid Z(\cdot)) = H_0(\psi(x))\). An accelerated life model whose life parameter scales time (Weibull alpha, the Exponential and Gamma rates, LogNormal’s exp(mu)) does the same with the rate \(1 / L(z)\) and the distribution at unit life, Nelson’s cumulative exposure; one whose life parameter is a location (Normal, Gumbel, Logistic) raises NotImplementedError. Either way a single constant segment reduces exactly to Hf(x, Z).

Along a CovariatePath, a covariate that changes continuously, the same hazards are integrated: \(H(x) = \int_0^x h(u \mid Z(u))\, du\), and for accelerated failure time \(\psi(x) = \int_0^x e^{\beta' Z(u)}\, du\) (Nelson’s cumulative exposure). For proportional odds the hazard is that of the current covariate, \(h_0(t) / (F_0(t) + \phi(Z(t)) S_0(t))\): the limit of the step sum above, and the model fit_tvc fits. The integral is by adaptive Gauss-Kronrod quadrature to a relative error of about 1e-10; where that is not reached, one RuntimeWarning says at how many query times. The type of Z picks the method: a StepSchedule is always summed exactly.

The path is measured from time zero: a schedule or path starting after zero is refused (nothing says what the covariate was before it), and the part of one before zero is ignored (the value in force at zero applies from there). Any time is a valid query, zero and below included: a constant path gives Hf(x, Z) there too.

Parameters:

  • x (array_like) – Times at which to evaluate the cumulative hazard.

  • Z (StepSchedule, CovariatePath or array_like) – The covariate path – a StepSchedule, a CovariatePath, or an array of per-segment covariate rows (with xl giving the segment start times).

  • xl (array_like, optional) – Segment start times, required only when Z is an array.

Returns:

The cumulative hazard at each x.

Return type:

ndarray

Examples

An exponential proportional hazards model along a stress ramp Z(t) = 0.1 t, whose cumulative hazard is \(\lambda (e^{0.1 \beta t} - 1) / (0.1 \beta)\):

>>> import numpy as np
>>> from surpyval import CovariatePath, ExponentialPH
>>> rng = np.random.default_rng(0)
>>> Z = rng.uniform(0, 2, (300, 1))
>>> x = rng.exponential(10 * np.exp(-0.7 * Z[:, 0]))
>>> model = ExponentialPH.fit(x, Z)
>>> lam, beta = model.params
>>> ramp = CovariatePath.from_points([0, 10], [0.0, 1.0])
>>> t = np.array([2.0, 5.0, 10.0])
>>> H = model.Hf_tvc(t, ramp)
>>> exact = lam * np.expm1(0.1 * beta * t) / (0.1 * beta)
>>> bool(np.allclose(H, exact, rtol=1e-12, atol=0))
True

Notes

cb(x: npt.ArrayLike, Z: npt.ArrayLike | pd.DataFrame, on: str = 'sf', alpha_ci: float = 0.05, bound: str = 'two-sided', method: str = 'wald', n_boot: int = 200, random_state: Any = None, robust: bool = False, cluster: npt.ArrayLike | None = None) → npt.NDArray

Confidence bounds on a predicted function at covariate vector Z.

With method="wald" (the default) the bounds propagate the fitted parameter covariance through the requested function by the delta method. sf/ff/Hf are derived from one bound on the baseline family’s probability-plot scale, as for the univariate models: log H for a Weibull, Exponential, Rayleigh or Gumbel baseline, the normal quantile of F for a Normal or LogNormal one, the logit of F for the rest (#504; every band was on the logit before v0.22). Each keeps sf in (0, 1), and is formed from the cumulative hazard so the Hf bound has no ceiling where sf underflows. hf/df use a log-scale bound (so they stay positive).

method="lr" gives the likelihood-ratio bound instead, as for the univariate models’ cb(method="lr"): at each x and row of Z the bound is the extreme of the function over the likelihood region of all the parameters, {theta : 2[nll(theta) - nll_hat] <= chi2_1}, which is where the function’s profile deviance reaches the critical value; the sf, ff and Hf bounds are one bound, so they agree exactly. It does not rest on the function being near linear in the parameters, and is invariant to their parameterisation, but takes a search of the likelihood: about a second a bound, where the Wald bound takes milliseconds (the region’s boundary is traced once per model and level, and kept). It needs the data the model was fitted to; where a bound cannot be found it is nan, with a warning. Both are large-sample bounds, and neither is exact with few failures: on an accelerated life test of 72 units extrapolated 40 °C below its coolest cell (#583), the 90% bounds on the five-year reliability at the use condition covered 0.897 (Wald) and 0.893 (likelihood ratio) with 46 failures on average (1000 repetitions), and 0.877 and 0.866 with 11 (900).

method="bootstrap" gives a parametric bootstrap bound: the model is refitted to n_boot data sets simulated from it, each unit at its own covariates and within its own truncation window, and censored as it was – a censored unit at its censoring time, a failed one at a time drawn from the censoring distribution past its failure (Davison & Hinkley’s conditional bootstrap), so a test stopped at a common time censors every unit there. The bound is the BCa interval of the refits’ values (Efron 1987: their percentiles, corrected for bias and for skewness, the acceleration taken from each resample’s score at the estimate); sf, ff and Hf are one interval. On the test above with 46 failures it covered 0.903, against 0.880 (Wald), 0.875 (likelihood ratio) and 0.866 for the plain percentile interval (1000 repetitions of 1000 refits, #617). With 11 failures it covered 0.71 (Wald 0.87, likelihood ratio 0.85): in 28% of those data sets the likelihood has no finite maximum, and a bootstrap from such a fit closes onto its estimate (it warns so); where the estimate exists it covered 0.979. A refit that reaches no verified maximum (a resample with no failures at some stresses can leave an effect without one) is kept at the estimate it reached, and one that raises is left out; both are counted, with one warning when more than 2% of the refits are. It needs the data, and is not available for left- or interval-censored data or a time-varying-covariate fit. It costs n_boot refits: about 60 s for 1000 on that test with WeibullAFT. With an integer random_state the refits are kept, and shared by every bound with the same n_boot and seed.

The likelihood-ratio test that the distribution’s shape is the same at every stress level, as an accelerated life model assumes.

At each distinct stress (each distinct row of Z) the baseline distribution is fitted on its own, its life and shape free; and all levels together with one shape and a life of their own each. Harrell’s (or Uno’s) concordance index (C) of the model’s risk scores, with its standard error and confidence interval.

The proportion of usable pairs of subjects – the one with the earlier time had the event – in which the model gives that subject the higher risk: 1 ranks every pair correctly, 0.5 is chance. With no arguments it scores the data the model was fitted to (each row counted n times); pass x, c and Z together to score other data, such as a test set. Two events at the same time are not a pair (ties="therneau", as R’s concordance and lifelines) unless ties="harrell"; see surpyval.metrics.concordance_index() for the treatment of tied times and scores.

The risk score, higher meaning an earlier event, is for each family:

  • CoxPH, the frailty models and AdditiveHazards (Lin-Ying): the linear predictor \(\beta'Z\) (the log hazard ratio, or the covariates’ additive hazard), as R’s concordance and lifelines use;

  • the parametric families (PH, AFT, PO, AH and the accelerated life models): the cumulative hazard \(H(t^* \mid Z)\) at \(t^*\), the median of the times scored. For every family whose covariates act through a linear predictor this ranks the rows exactly as the linear predictor does, with the sign that means a higher risk (\(\beta'Z\) for PH, AFT and AH, \(-\beta'Z\) for PO), and \(t^*\) does not matter; it can only matter for an accelerated life model whose life model sets a shape parameter;

  • BuckleyJames: \(-\beta'Z\), since the model is linear in the log time;

  • ProportionalOdds: \(-\beta'Z\), the log of the odds of failure relative to the baseline’s.

mean_tvc(Z: ArrayLike | Any, xl: ArrayLike | None = None, given: float | None = None) → float

The mean life along a covariate path Z(t) (a step schedule or a continuously varying path, as for sf_tvc()), or, with given, the mean residual life of a unit that has survived to that age along it.

\[\text{mean} = \int_0^\infty S(t)\, dt, \qquad \text{mrl}(g) = \int_g^\infty S(t \mid g)\, dt .\]

The outer integral is adaptive Gauss-Kronrod on panels graded geometrically from the start, and its nodes are simply more query times of sf_tvc(): each round of refinement is one pass along the path, not an integral per node. A step schedule is integrated as the matching piecewise-constant path, whose survival is its step sum to rounding. For a baseline defined below zero (Normal, Gumbel, Logistic) the mean without given also takes off \(\int_{-\infty}^0 F(t)\, dt\), which depends on the covariate back to -inf: it needs a schedule or path from -inf (#952, #957), for additive hazards a StepSchedule with one value before 0.

A path can stop units from failing: a hazard that dies away (a stress driven to a level with no failures, an additive hazard driven to 0) leaves the survival levelling off above 0. A fraction of units then never fails and the mean is infinite: inf is returned, with a warning that gives the survival where the integration stopped, as a univariate model’s mean() returns inf for a limited-failure population. An additive hazard can also turn negative, and survival rise above 1 (#376): the mean is then infinite as well, or undefined (nan, with a warning) where the failure probability before time 0 grows without limit.

Parameters:

  • Z (StepSchedule, CovariatePath or array_like) – The covariate path, as for sf_tvc().

  • xl (array_like, optional) – Segment start times, required only when Z is an array.

  • given (float, optional) – An age survived to: the mean remaining life from it. Z need only start by then, as for sf_tvc(). A nan given gives nan.

Returns:

The mean (residual) life along the path.

Return type:

param_cb(name: str, alpha_ci: float = 0.05, bound: str = 'two-sided', method: str = 'wald', n_boot: int = 200, random_state: Any = None, robust: bool = False, cluster: ArrayLike | None = None) → NDArray

Confidence bound(s) on a single fitted parameter.

Three methods; "wald" is the default:

  • "wald" – bounds from the observed information, computed on a scale chosen from the parameter’s support so the result stays inside it: log for a one-sided-bounded distribution or life-model parameter (e.g. a positive scale, or Arrhenius’s b and Power’s a, #655), the natural scale for the unbounded covariate coefficients.

  • "lr" – the profile-likelihood (likelihood-ratio) interval: the values whose profile deviance, every other parameter re-fitted, stays below the \(\chi^2_1\) critical value (aliases "likelihood", "likelihood-ratio", "profile"). It respects the parameter’s space (a life model’s positive constant stays positive) and need not be symmetric about the estimate; where the deviance stays below the critical value to the edge of the space, the bound is that edge, and a side that cannot be found is nan, with a warning. It needs the data the model was fitted to.

  • "bootstrap" – the parametric bootstrap BCa interval (Efron 1987) over n_boot refits of the model to data simulated from it, as cb() describes: the parameter’s percentiles over the refits, corrected for bias (the share of refits below the estimate) and for skewness (the acceleration, from each resample’s score at the estimate; 0, which leaves the bias-corrected percentile interval, where the covariance is not finite). A parameter held at fit time has its value as its interval. It needs the data.

Parameters:

  • name (str) – The parameter to bound; one of parameter_names.

  • alpha_ci (float, optional) – Total tail probability of the bound(s). Default 0.05.

  • bound ({'two-sided', 'lower', 'upper'}, optional) – Two-sided bounds are returned as [lower, upper].

  • method ({'wald', 'lr', 'bootstrap'} or None, optional) – As above. Default 'wald'; None means the default too, as for the univariate models (#655).

  • n_boot (int, optional) – The number of bootstrap refits (method='bootstrap' only). Default 200.

one (low, high) pair per entry of the vector with_params() takes, in the order of covariance_names (None for an end with no bound).

A parameter set drawn inside these ranges is one with_params does not refuse for being out of range, and one just outside a finite end is refused. Draw a parameter bounded on one side on the log scale of its distance from that end, and one bounded on both on the logit scale between them. Whether an end itself is allowed depends on the parameter (a probability may be 0 where a scale may not), so keep draws strictly inside.

A few models also constrain their parameters jointly, which no per-parameter range can say, and with_params refuses a set that breaks the joint constraint, saying so: a mixture’s weights sum to 1; a Uniform’s a is below its b (as a Beta4’s are); a Royston-Parmar spline does not fall; a Binomial’s n is a whole number. This is exact along a step path for the proportional-hazards, additive-hazards, proportional-odds and accelerated-failure-time families: S(x) = exp(-H(x)) with H the per-segment accumulation in Hf_tvc() (a cumulative-hazard sum for PH/AH/PO, an accelerated-age sum fed through the baseline for AFT). Along a CovariatePath the same quantities are integrated by quadrature, to a relative error of about 1e-10 on H (see Hf_tvc()). A constant path gives sf(x, Z). An accelerated life model follows cumulative exposure where its life parameter scales time, and raises NotImplementedError where it is a location (see Hf_tvc()). cb_tvc() bounds this survival and mean_tvc() integrates it.

Parameters:

  • x (array_like) – Times at which to evaluate survival.

  • Z (StepSchedule, CovariatePath or array_like) – The covariate path. A StepSchedule (built from change-points, intervals, a cyclic pattern, or a step-valued expression), a CovariatePath (a covariate that changes continuously), or an array of per-segment covariate rows with xl giving the segment start times.

  • xl (array_like, optional) – Segment start times, required only when Z is an array.

  • given (float, optional) – If supplied, return the conditional survival given the item has survived to age given: S(x | given) = exp(-(H(x) - H(given))) for x > given, and 1 for x <= given (survival to those times is certain). Along a CovariatePath the hazard is integrated from given on, so nothing is subtracted. For proportional hazards and odds and additive hazards this depends on the covariate from given on only, so Z need only start by then (#962); for accelerated failure time and life the age reached by given depends on it before too. A nan given gives nan.

Returns:

Survival at each x (conditional on given when supplied).

Return type:

ndarray

Examples

A proportional-odds model whose covariate switches from 0 to 1 at t = 6: before the switch the survival is that of Z = 0, after it the hazard is that of Z = 1.

>>> import numpy as np
>>> from surpyval import Weibull, WeibullPO
>>> from surpyval.univariate.regression import StepSchedule
>>> np.random.seed(1)
>>> Z = np.random.binomial(1, 0.5, 100).reshape(-1, 1)
>>> x = Weibull.random(100, 10, 2) * np.exp(0.5 * Z[:, 0])
>>> model = WeibullPO.fit(x, Z)
>>> sched = StepSchedule.from_changepoints([0, 6], [[0.0], [1.0]])
>>> model.sf_tvc([4, 8, 12], sched).round(4)
array([0.7721, 0.5698, 0.4292])
>>> model.sf([4, 8, 12], [[0]]).round(4)
array([0.7721, 0.4937, 0.2809])

Along a covariate ramped from 0 to 1 over the first 10 time units, and conditional on survival to 4:

>>> from surpyval import CovariatePath
>>> ramp = CovariatePath.from_points([0, 10], [0.0, 1.0])
>>> model.sf_tvc([4, 8, 12], ramp).round(4)
array([0.8195, 0.6331, 0.471 ])
>>> model.sf_tvc([2, 4, 8, 12], ramp, given=4).round(4)
array([1.    , 1.    , 0.7725, 0.5747])
standard_errors() → NDArray

Standard errors of the fitted parameters (square roots of the diagonal of covariance()), ordered to match parameter_names. A fixed parameter’s is 0, as is that of an accelerated life model’s life parameter, whose slot in params holds a placeholder 1 (the life model gives the life at each stress): index the life-model parameters by name, or use summary(), which leaves the placeholder out.

summary(alpha_ci: float = 0.05, robust: bool = False, cluster: npt.ArrayLike | None = None) → pd.DataFrame

The parameter table (#484), in lifelines’ layout: the baseline distribution’s parameters, then the regression coefficients (or, for an accelerated-life model, the life model’s parameters), each with its standard error and a two-sided 1 - alpha_ci Wald interval; for the coefficients also exp(coef) (where the link is log-linear: the hazard ratio for proportional hazards, the acceleration factor for AFT, the survival odds ratio for proportional odds), the Wald statistic z and its two-sided p-value. A coefficient is named by its covariate’s column (a formula, fit_from_df or a DataFrame Z), else coef_j (parameter_names).

The baseline parameters’ intervals are those of param_cb(), which stay in the parameter’s support (a positive scale’s is computed on the log scale). A fixed parameter has no standard error or interval (nan), nor does an aliased coefficient (#476), whose value is nan too.

An accelerated life model’s life-model parameters are not log-linear coefficients: their intervals are param_cb()’s too (a positive constant’s on the log scale, #655), and their exp(coef) columns are nan, as for an additive link. An unbounded one (a power, an activation energy, a column coefficient) has its Wald z and p against 0, no stress effect (p_values, #662). The life parameter the life model replaces has no row; its slot in params holds the placeholder 1 (with standard error 0), which is not a parameter.

Parameters:

  • alpha_ci (float, optional) – The intervals’ total tail probability. Default 0.05.

  • robust (bool, optional) – True gives the table on the robust (sandwich) standard errors of robust_standard_errors() instead of the model-based ones: se(coef), the Wald intervals (those of param_cb(..., robust=True)), z and p (those of robust_p_values()). The estimates are the same. Pass robust=True to cb, quantile_cb and param_cb too for bounds on the same covariance. Default False.

  • cluster (array_like, optional) – With robust=True, a cluster label for each row given to the fit (as for robust_covariance()).

Returns:

Indexed by (part, name), part one of "baseline", "coefficients" or "life model", with the columns of CoxPH’s summary(): coef (the estimate), exp(coef), se(coef), coef lower 95%, coef upper 95%, exp(coef) lower 95%, exp(coef) upper 95%, z and p.

Return type:

pandas.DataFrame

with_params(params: ArrayLike) → ParametricRegressionModel

The same regression with other parameters.

The structure is kept: the distribution (a spline baseline’s knots), the family and covariate link (or life model), the covariate names, formula and its encoding of a DataFrame, the centre a baseline is at, the parameters held fixed and the unit. So sf(x, Z) on the result takes the same raw covariates as the fitted model. Use it to turn a draw from covariance() into a model, and so carry the fit’s parameter uncertainty into anything computed from it.

Parameters:

params (array like) – Every parameter, in the order of covariance_names (that of params): a draw from covariance(), or _estimates() to rebuild the fitted model. The entries of a parameter held fixed in the fit (and of an accelerated life model’s placeholder for its life parameter) are ignored, the fixed value kept; an aliased coefficient stays nan (its effect taken as 0), as the fit had it.

Returns:

A model built from parameters, of the same class: it has no data, covariance or fitted likelihood, since those belong to the fit of the original parameters, so the methods that need them (cb, param_cb, plot, aic, …) refuse, saying so. A fit with weights w gives a model without them: just the distribution at those parameters.

Return type:

ParametricRegressionModel

Raises:

ValueError – For a vector of the wrong length, naming the parameters; or a parameter that is not finite or is outside its support (a negative Weibull scale, say).

Examples

>>> import numpy as np
>>> from surpyval import Weibull, WeibullPH
>>> np.random.seed(1)
>>> Z = np.random.binomial(1, 0.5, 100).reshape(-1, 1)
>>> x = Weibull.random(100, 10, 2) * np.exp(-0.5 * Z[:, 0])
>>> model = WeibullPH.fit(x, Z)
>>> same = model.with_params(model._estimates())
>>> bool(same.sf(5, [1]) == model.sf(5, [1]))
True

...     model._estimates(), model.covariance()
... )
>>> other = model.with_params(draw)
>>> other.params.round(3)
