Censored Quantile Regression

A semi-parametric model of the quantiles of the time to an event. For each level \(\tau\) the \(\tau\) quantile of the log time is linear in the covariates,

\[\log Q_T(\tau \mid Z) = \beta_0(\tau) + \beta(\tau)' Z,\]

with a coefficient vector of its own at every level. A covariate can therefore shorten the early failures (the B10 life, \(\tau = 0.1\)) a great deal and the median hardly at all. Neither proportional hazards nor an accelerated failure time is assumed: an AFT model is the special case where every slope is the same at every level. \(e^{\beta_k(\tau)}\) is the factor by which a unit of covariate \(k\) multiplies the \(\tau\) quantile.

Right-censored data are taken by one of two estimators, chosen with method=, each fitted on a grid of levels (step=0.01 by default) from the bottom up, as R’s quantreg::crq fits them:

  • "peng-huang" (the default): Peng and Huang’s (2008) martingale estimating equations. With no covariates it is the quantile of the Nelson-Aalen (Fleming-Harrington) survival curve.

  • "portnoy": Portnoy’s (2003) recursively reweighted quantile regression, which moves each censored unit’s weight to the right once the quantile has passed it. With no censoring it is ordinary quantile regression; with no covariates it is the Kaplan-Meier quantile.

The process stops at the last level the data determine, model.tau_max: past the last events the censoring leaves nothing to fit. Each unit’s predicted distribution (ff, sf, Hf, qf) is read from its quantiles at the fitted levels, rearranged into order where they cross; ff rises in steps to tau_max and holds it, and qf is nan above it. There is no closed-form standard error: bootstrap_ci, summary(n_boot=...), quantile_cb and cb give percentile bootstrap intervals, resampling the units. Only observed and right-censored data with positive times are accepted.

Usage:

from surpyval import QuantileRegression
model = QuantileRegression.fit(x, Z, c=c)
model.coefficients(0.1)          # intercept and slopes at the B10
model.qf(0.1, Z_new)             # the B10 life of each new unit
model.quantile_cb(0.1, Z_new, alpha_ci=0.1, bound="lower")

See “Semi-Parametric — Censored Quantile Regression” in Regression Modelling with SurPyval for a worked example.

class surpyval.univariate.regression.quantile.quantile_regression.QuantileRegression_

Bases: FitterRepr

Censored quantile regression: the quantiles of the time to an event, \(Q_T(\tau \mid Z) = e^{\beta_0(\tau) + \beta(\tau)' Z}\), with a coefficient vector for every level \(\tau\) and no proportional hazards or accelerated failure time assumption, from right-censored data, by Peng and Huang’s (2008) or Portnoy’s (2003) estimator (R’s quantreg::crq). QuantileRegression is an instance of this class; its fit returns a QuantileRegressionModel.

fit(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, method: str = 'peng-huang', step: float = 0.01, *, unit=None) → QuantileRegressionModel

Fit a censored quantile regression.

The quantile process is fitted on the grid of levels step, 2 step, ..., from the bottom up, and stops at the last level the data determine (QuantileRegressionModel.tau_max): past the last event the censoring leaves nothing to fit. Rows with a missing or infinite covariate are dropped, with a warning. A covariate column that is constant (the intercept already is one), or a linear combination of the others, is aliased: its coefficients are nan, the others those of the fit without it, and one warning names it. The rows are fitted sorted, with identical rows merged, so the fit is the same whatever order they are given in, and a count n = k is the same as k repeated rows.

Parameters:

  • x (array_like) – The (positive, finite) times.

  • Z (array_like) – The covariate matrix, one row per observation.

  • c (array_like, optional) – Censoring flags: 0 observed, 1 right censored. Left and interval censoring are not supported. Defaults to all observed.

  • n (array_like, optional) – Counts per row. Defaults to 1.

  • method (('peng-huang', 'portnoy'), optional) – The estimator: Peng and Huang’s (2008) martingale estimating equations (the default), or Portnoy’s (2003) recursively reweighted quantile regression. With no censoring Portnoy’s is ordinary quantile regression at each level; with no covariates it is the Kaplan-Meier quantile, and Peng and Huang’s the quantile of the Nelson-Aalen survival, each up to the grid’s resolution.

  • step (float, optional) – The spacing of the grid of levels, in (0, 0.5]. Default 0.01, which fits 0.01, 0.02, …, 0.99. A finer grid follows the estimator more closely (both are defined as the grid shrinks) and costs a linear programme per level.

Returns:

The fitted model.

Return type:

QuantileRegressionModel

Examples

The times have a log-normal spread that grows with the covariate, so its effect on the early failures (the B10 life) is weaker than on the median; follow-up ends at 20:

>>> import numpy as np
>>> from surpyval import QuantileRegression
>>> rng = np.random.default_rng(0)
>>> z = rng.uniform(0, 2, 500)
>>> t = np.exp(1.0 + 0.5 * z + (0.2 + 0.2 * z) * rng.normal(size=500))
>>> c = (t > 20).astype(int)
>>> model = QuantileRegression.fit(np.minimum(t, 20), z, c=c)
>>> model.coefficients([0.1, 0.5]).round(2)
array([[0.73, 0.28],
       [1.01, 0.46]])
>>> model.qf(0.1, [[0.0], [2.0]]).round(2)
array([2.07, 3.64])

class surpyval.univariate.regression.quantile.quantile_regression.QuantileRegressionModel(taus: ArrayLike, intercepts: ArrayLike, coefs: ArrayLike, method: str, step: float, data: tuple | None)

Bases: NoLikelihoodMixin, SerialisableMixin

A fitted censored quantile regression: the coefficient process \(\beta_0(\tau), \beta(\tau)\) at the levels of a grid, from QuantileRegression.fit.

taus are the levels fitted, intercepts the intercept at each and coefs the covariate coefficients, one row per level and one column per covariate. coefficients() reads them at any level, and summary() tabulates them with bootstrap intervals. A coefficient is the change in the log of that quantile per unit of the covariate: exp(coef) is the factor by which a unit multiplies the quantile.

Examples

On the Rossi recidivism data (arrest is 1 for an arrest, so the censoring flag is 1 - arrest), the tenth percentile of the time to arrest – the B10 life – by financial aid (fin), age and prior convictions (prio):

>>> from surpyval import QuantileRegression
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> Z = df[["fin", "age", "prio"]].values
>>> model = QuantileRegression.fit(x, Z, c=c)
>>> model.coefficients(0.1).round(3)
array([ 2.834,  0.32 ,  0.018, -0.071])
>>> model.qf(0.1, [[0, 25, 3], [1, 25, 3]]).round(1)
array([21.4, 29.5])

bootstrap_ci(tau: float, alpha_ci: float = 0.05, n_boot: int = 200, random_state: Any = None) → NDArray

Percentile bootstrap confidence intervals for the intercept and the coefficients at level tau.

The units are resampled with replacement (a row with count n is n units), the process refitted on the grid up to tau, and the intervals are the percentiles of the refitted coefficients. A resample whose process stops below tau, or in which a covariate is constant, is left out, with a warning counting them.

Parameters:

  • tau (float) – The level, at most tau_max.

  • alpha_ci (float, optional) – The intervals’ total tail probability: 0.05 (the default) for 95% two-sided intervals, 0.1 for 90%.

  • n_boot (int, optional) – The number of resamples. Default 200.

  • random_state (None, int or numpy.random.Generator, optional) – The seed of the resampling. None (the default) draws from numpy’s global generator, so np.random.seed reproduces it.

Returns:

An (1 + n_covariates, 2) array of [lower, upper], the intercept first.

Return type:

numpy.ndarray

Examples

>>> import numpy as np
>>> from surpyval import QuantileRegression
>>> rng = np.random.default_rng(0)
>>> z = rng.uniform(0, 2, 300)
>>> t = np.exp(1.0 + 0.5 * z + 0.3 * rng.normal(size=300))
>>> c = (t > 20).astype(int)
>>> model = QuantileRegression.fit(np.minimum(t, 20), z, c=c)
>>> ci = model.bootstrap_ci(0.5, 0.1, n_boot=50, random_state=1)
>>> ci.round(2)
array([[0.92, 1.05],
       [0.45, 0.57]])
cb(x: ArrayLike, Z: Any, on: str = 'sf', alpha_ci: float = 0.05, bound: str = 'two-sided', n_boot: int = 200, random_state: Any = None) → NDArray

Percentile bootstrap bounds on sf, ff or Hf at x for covariates Z.

The units are resampled as for bootstrap_ci() and the whole process refitted; the bounds on sf are the percentiles of the refits’ survival, and those on ff and Hf the same bounds transformed. Calls with the same n_boot and integer random_state share one set of refits.

Parameters:

  • x (float or array like) – The times.

  • Z (array like or DataFrame) – The covariates, paired with x as ff() pairs them.

  • on (('sf', 'ff', 'Hf'), optional) – The function to bound ('R' and 'F' are aliases of 'sf' and 'ff'). Default 'sf'.

  • alpha_ci (float, optional) – The total tail probability of a two-sided interval, or the one tail of a one-sided bound. Default 0.05.

  • bound (('two-sided', 'lower', 'upper'), optional) – Two-sided bounds put [lower, upper] on a last axis.

  • n_boot (int, optional) – The number of resamples. Default 200.

  • random_state (None, int or numpy.random.Generator, optional) – The seed of the resampling.

Returns:

The bounds, with the shape of x (and a last axis of 2 for two-sided bounds).

Return type:

numpy.ndarray

Examples

qf(p: ArrayLike, Z: Any) → NDArray

The time by which a share p of units with covariates Z have had the event: qf(0.1, Z) is their B10 life. It is \(e^{\beta_0(p) + \beta(p)' Z}\) where the quantiles at the grid levels are in order, and the rearranged quantile where they cross; nan past tau_max. Z is paired with p as ff() pairs it with x. A probability outside [0, 1] gives nan, with a warning.

quantile_cb(p: ArrayLike, Z: Any, alpha_ci: float = 0.05, bound: str = 'two-sided', n_boot: int = 200, random_state: Any = None) → NDArray

Percentile bootstrap bounds on the quantile qf(p, Z): on the B10 life of units with covariates Z, say, with p = 0.1.

The units are resampled as for bootstrap_ci(), the whole process refitted, and each refit’s quantile read as qf() reads the model’s; a resample whose process stops below a p gives no quantile there and is left out of that bound, with a warning counting them. Calls with the same n_boot and integer random_state share one set of refits.

Parameters:

  • p (float or array like) – The probabilities.

  • Z (array like or DataFrame) – The covariates, paired with p as qf() pairs them.

  • alpha_ci (float, optional) – The total tail probability of a two-sided interval, or the one tail of a one-sided bound. Default 0.05; a one-sided 90% lower bound on a B-life is alpha_ci=0.1, bound="lower".

  • bound (('two-sided', 'lower', 'upper'), optional) – Two-sided bounds put [lower, upper] on a last axis.

  • n_boot (int, optional) – The number of resamples. Default 200.

  • random_state (None, int or numpy.random.Generator, optional) – The seed of the resampling.

Returns:

The bounds, with the shape of p (and a last axis of 2 for two-sided bounds).

Return type:

numpy.ndarray

Examples
