Forest Plots of Coefficients

A forest plot of one or more fitted regression models: each coefficient with its Wald interval, from the model’s summary(). Import it as surpyval.plot_coefficients; worked examples are in Regression Modelling with SurPyval.

surpyval.plot_coefficients(models: Any, on: str | None = None, ax: Axes | None = None, *, alpha_ci: float = 0.05, covariates: Sequence[str] | None = None, labels: Sequence[str] | None = None, colors: Any = None, sort: str | None = None, xlabel: str | None = None, title: str | None = None, legend: bool | None = None) → CoefficientPlot

A forest plot: each coefficient of one or more fitted regression models, as a point with its two-sided Wald confidence interval, one row per covariate, with a reference line at no effect.

The values are those of each model’s summary(alpha_ci), so any model with a coefficient table can be drawn: CoxPH, the parametric PH, AFT, PO and AH families, AdditiveHazards, ProportionalOdds, BuckleyJames, the frailty models and FineGray. Several models are drawn side by side at each covariate, for example the same covariates under a Cox and a Weibull AFT fit, or one fit per subgroup.

Parameters:

  • models (model, list or dict) – One fitted regression model, a list of them, or {label: model}.

  • on (('coef', 'exp'), optional) – The scale: 'coef' the coefficients, with the reference line at 0; 'exp' their exponents exp(coef) (a hazard ratio for Cox and proportional hazards, the acceleration factor for AFT, an odds ratio for proportional odds), on a log axis with the reference line at 1. Defaults to 'exp' when every model has a ratio scale, else 'coef'. An additive model (AH, AdditiveHazards) has none: its coefficients are differences in the hazard, not ratios, so 'exp' is refused for it.

  • ax (matplotlib Axes, optional) – The axes to draw on. Without one a new figure is made.

  • alpha_ci (float, optional) – The significance level of the intervals. Defaults to 0.05.

  • covariates (list of str, optional) – The rows to draw, by name. Defaults to every regression coefficient (the "coefficients" part of a parametric model’s table, which leaves out the baseline’s and a frailty’s parameters). Names can come from any part of the table, e.g. an accelerated life model’s life-model parameters.

  • labels (list of str, optional) – One label per model, in order; the keys of a dict otherwise, and the model’s family name (or “Model 1”, “Model 2”, … when names repeat) for a list.

  • colors (list or dict, optional) – One matplotlib colour per model, or {label: colour}. Without them the models take SurPyval’s palette in order.

  • sort (('estimate', 'name'), optional) – The order of the rows, top to bottom: as in the (first model’s) table (default), by the first model’s estimate, smallest at the top, or by name.

  • xlabel (str, optional) – The x axis label (defaults to the scale drawn) and the title.

  • title (str, optional) – The x axis label (defaults to the scale drawn) and the title.

  • legend (bool, optional) – Whether to draw a legend. Defaults to one when there are two or more models.

Returns:

fig and ax to customise further, the covariates drawn top to bottom, the values drawn and the artists.

Return type:

CoefficientPlot

Examples

>>> import matplotlib
>>> matplotlib.use("Agg")
>>> import matplotlib.pyplot as plt
>>> import surpyval
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static().assign(censored=lambda d: 1 - d.arrest)
>>> kw = dict(x_col="week", c_col="censored", Z_cols=["fin", "age"])
>>> cox = surpyval.CoxPH.fit_from_df(df, **kw)
>>> aft = surpyval.WeibullAFT.fit_from_df(df, **kw)
>>> out = surpyval.plot_coefficients(
...     {"Cox": cox, "Weibull AFT": aft}, on="coef"
... )
>>> out.values["Cox"]["estimate"].round(3).tolist()
[-0.328, -0.071]
>>> out.values["Weibull AFT"]["estimate"].round(3).tolist()
[-0.239, -0.052]
>>> plt.close(out.fig)

The Cox coefficients are log hazard ratios and the AFT’s log acceleration factors (an AFT model ages a unit at exp(coef) times the baseline’s rate), so a negative value means the same in both: financial aid and age both lower the risk of arrest.

Examples

>>> import matplotlib
>>> matplotlib.use("Agg")
>>> import surpyval
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static().assign(censored=lambda d: 1 - d.arrest)
>>> model = surpyval.CoxPH.fit_from_df(
...     df, x_col="week", c_col="censored", Z_cols=["fin", "prio"]
... )
>>> out = surpyval.plot_coefficients(model)
>>> out.on, out.covariates
('exp', ['fin', 'prio'])
>>> out.values["CoxPH"].round(3).values.tolist()
[[0.671, 0.462, 0.974], [1.11, 1.053, 1.169]]
>>> matplotlib.pyplot.close(out.fig)
