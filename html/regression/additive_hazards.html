Semi-Parametric Additive Hazards

The Lin & Ying additive hazards model: covariates add a constant amount to the baseline hazard rather than multiplying it, \(h(x \mid Z) = h_0(x) + \beta' Z\), with the baseline left to the data. AdditiveHazards is an instance of the fitter class below. The fully parametric version, with a Weibull (or other) baseline, is the AH family in Parametric Regression Models. Supports observed and right-censored data.

Nothing keeps the estimated hazard \(h_0(x) + \beta' Z\) positive: the Lin-Ying cumulative hazard falls between the event times, where its baseline drifts down by \(\beta' \bar{Z}(x)\), and for a covariate row the model takes below zero. The model therefore predicts with the running maximum of the estimate from time 0, the smallest non-decreasing cumulative hazard at or above it and 0 (#376): sf stays in \([0, 1]\) and never increases, and hf is 0 wherever Hf is held. Where the estimate is at its running maximum (most of the time for a covariate row inside the data) the prediction is the estimate itself; the fitted baseline H0 is the raw estimate at \(Z = 0\), as R’s timereg reports it.

AdditiveHazards.fit_penalised adds a ridge, lasso or elastic-net penalty: Lin and Ying’s estimating equation is the gradient of a quadratic loss, which takes the place of the negative log-likelihood of the other penalised fits (see the penalised regression section of Regression Modelling with SurPyval). The coefficients are rates, so the penalty is put on them in the unit of the mean follow-up (model.time_scale), and the fit does not depend on the unit of time.

The Lin & Ying semi-parametric additive hazards model: the covariates add a constant risk difference to a baseline hazard that is left to the data,

\[h(x \mid Z) = h_0(x) + \beta' Z.\]

The coefficients have a closed-form estimate (no iteration) with a sandwich variance. AdditiveHazards is an instance of this class; its fit returns an AdditiveHazardsModel. For a parametric baseline see the AH family.

Fit the Lin & Ying additive hazards model.

Parameters:

  • Z (array-like) – The covariate matrix (one row per observation). Rows with a missing or infinite covariate are dropped, with a warning.   • c (array-like, optional) – Censoring flags: 0 observed (event), 1 right-censored. Defaults to all observed.

  • n (array-like, optional) – Multiplicity (counts) for each row. Defaults to 1 each.

>>> from surpyval import AdditiveHazards

fit_penalised(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, penalizer: float | ArrayLike = 0.1, l1_ratio: float = 0.0, standardise: bool = True, tol: float = 1e-10, w: ArrayLike | float | None = None, *, unit=None) → AdditiveHazardsModel

Fit the Lin and Ying model with a ridge, lasso or elastic-net penalty on the coefficients: for many covariates, or correlated ones.

Lin and Ying’s estimating equation, A beta = b, is the gradient of the quadratic loss \(L(\beta) = \tfrac12 \beta' A \beta - b' \beta\), so the penalised fit minimises

\[\frac{1}{N} L(\beta) + \sum_j \lambda_j \left( \frac{1 - a}{2} \tau s_j^2 \beta_j^2 + a s_j |\beta_j| \right),\]

with \(N\) the number of units (the sum of n), \(s_j\) the standard deviation of covariate j (1 with standardise=False), \(\lambda_j\) the penalizer and \(a\) the l1_ratio. This is the penalised fit of Gorst-Rasmussen and Scheike (2012), which R’s ahaz::ahazpen computes for the lasso: the same as the penalised fits of the other models, with the loss in place of the negative log-likelihood. With no penalty it is the fit of fit().

A coefficient here is a rate (an excess hazard per unit of time), so a penalty on its size depends on the unit of time. The lasso part does not: the loss and the L1 penalty both scale with the unit, so a fit in days is the fit in years, its coefficients divided by 365.25. The ridge part would, so it is put on the coefficients in the unit \(\tau\) (model.time_scale), the count-weighted mean of x: a fit in days is then the fit in years for every l1_ratio.

The model predicts as the fit’s does, but has no covariance, standard errors or p-values: penalised estimates are biased towards 0 by design, and intervals from them would not have their stated coverage; those calls raise an error that says so (summary() shows them as nan). There is no likelihood, so no aic or bic either, as for fit().

Parameters:

  • x (array_like) – As for fit().

  • Z (array_like) – As for fit().

  • c (array_like) – As for fit().

  • n (array_like) – As for fit().

  • penalizer (float or array_like, optional) – \(\lambda\): one value, or one per column of Z (0 leaves a coefficient unpenalised). Default 0.1.

  • l1_ratio (float, optional) – \(a\), from 0 (ridge, the default) to 1 (lasso).

  • standardise (bool, optional) – True (the default) penalises the coefficients of the covariates divided by their standard deviations (count- weighted, divisor N), so the penalty does not depend on their units; the coefficients are reported on the covariates’ own scale either way.

  • tol (float, optional) – The optimality tolerance on the gradient of the objective.

  • w (None) – Weights are refused: fit() takes none either.

Returns:

The fitted model, with penalty (the penalizer per column, l1_ratio, standardise, the columns’ scale and the effective degrees of freedom) and time_scale.

Return type:

AdditiveHazardsModel

Examples

>>> from surpyval import AdditiveHazards

>>> Z = rng.normal(size=(300, 4))

...     x, Z, penalizer=0.1, l1_ratio=1
... )

A fitted Lin & Ying additive hazards model, returned by AdditiveHazards.fit().

The covariate effect is additive on the hazard, so the prediction methods use h(t | Z) = h0(t) + beta'Z and the cumulative H(t | Z) = H0(t) + t * beta'Z.

Examples

On the Rossi recidivism data each coefficient is an excess hazard of arrest per week, per unit of the covariate:

>>> from surpyval import AdditiveHazards
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> Z = df[["fin", "age", "prio"]].values
>>> model = AdditiveHazards.fit(x, Z, c=c)
>>> model.beta.round(4)
array([-0.002 , -0.0003,  0.0007])
>>> model.p_values.round(4)
array([0.0725, 0.0004, 0.0083])
>>> model.sf([20, 52], [1, 25, 3]).round(4)
array([0.9269, 0.7725])
Hf(x: npt.ArrayLike, Z: npt.ArrayLike | pd.DataFrame) → npt.NDArray

Cumulative hazard at x for covariates Z (one row, or one row per x): the Lin-Ying estimate H(x | Z) = H0(x) + x * beta'Z, held at its running maximum from time 0. The baseline H0 jumps by d / S0 at each event time and, between the grid times, falls continuously by the covariate-mean drift beta' Zbar(t) (so H0 is not 0 before the first event unless the covariates are centred there). The prediction H(x | Z) is the same however the covariates are centred.

Nothing constrains the additive hazard h0(t) + beta'Z to be positive, so the estimate can fall – between the event times, or for a covariate row whose hazard the model takes below 0 – and exp(-H) would be a survival that rises, and exceeds 1. The prediction is therefore the smallest non-decreasing cumulative hazard at or above the estimate and 0: max(0, max_{0 <= s <= x} H(s | Z)). It is the estimate wherever the estimate is at its running maximum, and flat (a hazard of 0) where it is not; sf stays in [0, 1] and never increases (#376). The estimate is consistent for a non-decreasing truth, and so is its running maximum.

Before time 0, where the covariate effect starts, Hf is 0; past the last observed time there is no risk set to estimate anything from, so Hf holds its value there, as the other semi-parametric estimates do (#400).

concordance(x: ArrayLike | None = None, c: ArrayLike | None = None, Z: Any = None, tie_tol: float = 1e-08, ties: str = 'therneau', *, weighting: str = 'harrell', tau: float | None = None, alpha_ci: float = 0.05, ci_method: str = 'normal') → ConcordanceResult | float

Harrell’s (or Uno’s) concordance index (C) of the model’s risk scores, with its standard error and confidence interval.

The proportion of usable pairs of subjects – the one with the earlier time had the event – in which the model gives that subject the higher risk: 1 ranks every pair correctly, 0.5 is chance. With no arguments it scores the data the model was fitted to (each row counted n times); pass x, c and Z together to score other data, such as a test set. Two events at the same time are not a pair (ties="therneau", as R’s concordance and lifelines) unless ties="harrell"; see surpyval.metrics.concordance_index() for the treatment of tied times and scores.

The risk score, higher meaning an earlier event, is for each family:

  • CoxPH, the frailty models and AdditiveHazards (Lin-Ying): the linear predictor \(\beta'Z\) (the log hazard ratio, or the covariates’ additive hazard), as R’s concordance and lifelines use;

  • the parametric families (PH, AFT, PO, AH and the accelerated life models): the cumulative hazard \(H(t^* \mid Z)\) at \(t^*\), the median of the times scored. For every family whose covariates act through a linear predictor this ranks the rows exactly as the linear predictor does, with the sign that means a higher risk (\(\beta'Z\) for PH, AFT and AH, \(-\beta'Z\) for PO), and \(t^*\) does not matter; it can only matter for an accelerated life model whose life model sets a shape parameter;

  • BuckleyJames: \(-\beta'Z\), since the model is linear in the log time;

  • ProportionalOdds: \(-\beta'Z\), the log of the odds of failure relative to the baseline’s.

Parameters:

  • x (array_like, optional) – Observed times.

  • c (array_like, optional) – Censoring flags, 0 an event and 1 right censored.

  • Z (array_like or DataFrame, optional) – Covariates, one row per time (a DataFrame for a model fitted with fit_from_df).

  • tie_tol (float, optional) – Scores within this of each other are tied. Default 1e-8.

  • ties ({"therneau", "harrell"}, optional) – "therneau" (the default, as R’s survival::concordance and lifelines): two events at the same time are not a usable pair. "harrell" (Harrell’s original definition): they are, counting 1 if their scores are tied, else 0.5.

  • weighting ({"harrell", "uno"}, optional) – "harrell" (default): every usable pair weighs 1. "uno": Uno’s inverse-probability-of-censoring weighted C, each pair weighted by 1 / G(t-)^2 (see surpyval.metrics.concordance_index()).

  • tau (float, optional) – Count only the pairs whose earlier time is at most tau. Default None, every pair.

  • alpha_ci (float, optional) – Keyword only: the significance level of the interval. Default 0.05.

  • ci_method ({"normal", "logit"}, optional) – Keyword only: the scale of the interval. Default "normal".

Returns:

The concordance index, a float that carries its infinitesimal-jackknife standard error se and interval ci (surpyval.metrics.concordance_index()). With no data it scores the data the model was fitted to, each row repeated n times as its own subject (as R does with the rows repeated); the standard error treats the scores as fixed, as R’s does. A plain nan where a covariate is missing.

Return type:

ConcordanceResult

Raises:

ValueError – If only some of x, c and Z are given, or none are and the model does not keep its training data (a model restored with from_dict, or one fitted with time-varying covariates, whose rows are intervals of a subject’s history).

Examples

>>> import surpyval as sp
>>> from surpyval.datasets import load_lung
>>> lung = load_lung().dropna(subset=["ph.ecog"])
>>> lung["censored"] = 1 - lung["status"]  # status 1 is a death
>>> model = sp.CoxPH.fit_from_df(
...     lung, x_col="time", c_col="censored",
...     Z_cols=["age", "sex", "ph.ecog"],
... )
>>> round(model.concordance(), 4)
0.6371
>>> round(model.concordance(ties="harrell"), 4)
0.6369

cs(x: ArrayLike, given: ArrayLike, Z: Any, *args: Any, **kwargs: Any) → Any

Conditional survival: the probability that a unit with covariates Z that has survived to given survives a further x,

\[R(x \mid given, Z) = \frac{R(given + x \mid Z)}{R(given \mid Z)} = e^{-(H(given + x \mid Z) - H(given \mid Z))},\]

the univariate models’ cs(x, given) with the covariates of sf() (#581).

Parameters:

  • x (array like or scalar) – The further durations.

  • given (array like or scalar) – The ages already survived, broadcast against x (one age per unit and one x for all, say).

  • Z (array like or DataFrame) – The covariates, paired with the times as sf() pairs them: one row per element of x / given, or a single row for all of them.

  • *args – Any further arguments of this model’s Hf() (grid=True for every time for every row; a Cox model’s stratum; a frailty model’s group or frailty).

  • **kwargs – Any further arguments of this model’s Hf() (grid=True for every time for every row; a Cox model’s stratum; a frailty model’s group or frailty).

Returns:

cs – The conditional survival probabilities.

Return type:

scalar or numpy array

Notes

The ratio is taken from the model’s cumulative hazard, which keeps it exact where \(R(given)\) underflows (a unit far into the tail). Where \(R(given \mid Z) = 0\) the conditional survival is undefined and nan is returned, as for the univariate models. A fleet’s expected failures over a horizon, built on this, are surpyval.forecast().

Examples

>>> import numpy as np
>>> from surpyval import Weibull, WeibullPH
>>> np.random.seed(1)
>>> Z = np.random.binomial(1, 0.5, 100).reshape(-1, 1)
>>> x = Weibull.random(100, 10, 2) * np.exp(-0.5 * Z[:, 0])
>>> model = WeibullPH.fit(x, Z)

Two units, aged 2 and 8, surviving one more unit of time:

>>> model.cs(1.0, [2.0, 8.0], [[0], [1]]).round(4)
array([0.9362, 0.6843])
>>> s = model.sf([3.0, 9.0], [[0], [1]])
>>> (s / model.sf([2.0, 8.0], [[0], [1]])).round(4)
array([0.9362, 0.6843])

diagnose(alpha: float = 0.05, columns: Sequence[str] | None = None, *, n_boot: int | None = None, random_state: Any = None, **options: Any) → Diagnosis

Check the model’s assumptions, fit and influential points, and say what to do about any that fail.

Runs the checks this kind of model calls for (for a Cox model: proportional hazards, the functional form of each continuous covariate, influence and outliers; see Model Diagnostics) and returns a report: d.table, one row per check with its test, statistic, p-value, verdict ("ok", "warn" or "fail") and covariates; d.advice, plain-English remedies that each name the SurPyval feature that applies them; d.plot(), the visual checks (matplotlib is only imported then); d.ok, True if nothing failed; d.raise_if_failed() for pipelines; and d.to_dict().

A test fails when its p-value is below alpha, and warns when it is below 2 * alpha (borderline) or could not be computed. Each row is judged at alpha on its own, so with many rows some fail by chance even when every assumption holds.

Parameters:

  • alpha (float, optional) – The level each test is judged at. Default 0.05.

  • columns (str or list of str, optional) – The covariates to check, named as summary() names them (the DataFrame or formula columns, else coef_0, …); all of them by default. A joint (GLOBAL) test still covers every covariate.

  • n_boot (int, optional) – For the families whose tests resample (a univariate distribution’s bootstrap goodness-of-fit tests): the number of bootstrap refits; None is the family’s default. Other families ignore it.

  • random_state (optional) – The seed of those resamples (SurPyval’s one seed rule: None draws from numpy’s global generator).

  • **options – Options of the model’s family, named in Model Diagnostics: for an accelerated life model, use_stress, the stress the model is to predict at (a number, or one per stress column), whose distance from the tested stresses the report screens. A family refuses an option it does not take.

Returns:

See surpyval.diagnostics.Diagnosis.

Return type:

Diagnosis

Raises:

  • NotImplementedError – For a model whose family’s diagnostics are not built yet, saying what to check it with meanwhile; for an option of the model the checks do not support yet; and for a kind of model the checks do not cover by design (a discrete distribution, a parametric regression with a custom link, …), saying what to use instead.

  • ValueError – For a model the checks cannot be run on (one restored with from_dict, which has no data), saying what to do.

hf(x: npt.ArrayLike, Z: npt.ArrayLike | pd.DataFrame, bandwidth: float | None = None) → npt.NDArray

Hazard rate h0(t) + beta'Z with a kernel-smoothed baseline, floored at 0, and 0 where the cumulative hazard Hf() is held (see there).

The semiparametric baseline is a step cumulative hazard, so the rate requires smoothing (Epanechnikov kernel over the increments; bandwidth defaults to a normal-reference rule on the event times). Estimates near the boundaries of the observed time range are attenuated by kernel truncation. Past the last observed time the estimate holds (see Hf()), so the hazard there is 0, as it is at and before time 0.

property parameter_bounds: list[tuple[float | None, float | None]]

one (low, high) pair per entry of the vector with_params() takes, in the order of covariance_names (None for an end with no bound).

A parameter set drawn inside these ranges is one with_params does not refuse for being out of range, and one just outside a finite end is refused. Draw a parameter bounded on one side on the log scale of its distance from that end, and one bounded on both on the logit scale between them. Whether an end itself is allowed depends on the parameter (a probability may be 0 where a scale may not), so keep draws strictly inside.

A few models also constrain their parameters jointly, which no per-parameter range can say, and with_params refuses a set that breaks the joint constraint, saying so: a mixture’s weights sum to 1; a Uniform’s a is below its b (as a Beta4’s are); a Royston-Parmar spline does not fall; a Binomial’s n is a whole number. The entry of a parameter with_params ignores (held fixed in the fit, or an accelerated life model’s life parameter) gives the parameter’s range all the same. An accelerated life model’s life-model parameters can have ranges that depend on the stresses fitted to; a model loaded from a dict saved without its data gives them as unbounded.

qf(p: npt.ArrayLike, Z: npt.ArrayLike | pd.DataFrame) → npt.NDArray

The quantile function: the first time at which the predicted failure probability ff(x, Z) reaches p (#662), nan where it never does – the curve is held after the last observed time, above 1 - p where the data end censored. The median life of a unit with covariates Z is qf(0.5, Z).

The cumulative hazard Hf() never decreases, rising both between the event times and in jumps at them, so the quantile is found by bisection to a relative 1e-12, and is an event time where the curve jumps past p there. Z is paired with p as sf() pairs it with x: one row for every p, or one p for every row. A probability outside [0, 1] gives nan, with a warning.

Examples

>>> from surpyval import AdditiveHazards
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> x, c = df["week"].values, 1 - df["arrest"].values
>>> model = AdditiveHazards.fit(x, df[["fin", "prio"]].values, c=c)
>>> b10 = model.qf(0.1, [[0, 0], [1, 0], [0, 10]])
>>> b10.round(2)
array([27.  , 46.  , 10.79])
>>> model.ff(b10, [[0, 0], [1, 0], [0, 10]]).round(3)
array([0.103, 0.103, 0.1  ])
random(size: int, Z: npt.ArrayLike | pd.DataFrame, random_state: Any = None) → tuple[npt.NDArray, npt.NDArray]

Draw size lifetimes for each covariate row of Z, by inverting qf(): a uniform U, the survival the draw is to have, gives qf(1 - U, Z), as every regression’s random draws. The curve is held after the last observed time; a draw it never reaches is inf (the unit outlives the data), as often as sf at the last time says. random_state seeds the draw: None (the default) draws from numpy’s global generator; an int or a numpy.random.Generator gives a stream of its own.

Returns the draws and a 2-D array of the covariate row each was drawn at, row by row.

to_dict() → dict

Serialise this fitted Lin-Ying additive-hazards model to a plain, JSON-serialisable dict.

with_params(params: ArrayLike) → AdditiveHazardsModel

The same model with other coefficients, and the baseline Lin and Ying’s estimator gives at them.

The baseline cumulative hazard is the Breslow-type sum less the covariate-mean drift, H0(t) = Lambda(t) - beta' G(t), linear in the coefficients; the rebuilt model has that baseline at the new beta, so with_params(beta) is what the fit would predict had it estimated beta. The covariate names, formula and its encoding of a DataFrame are kept.

Parameters:

params (array like) – The coefficients, in the order of covariance_names: a draw from covariance(), say. An aliased coefficient stays nan (taken as 0).

Returns:

A model without the data or the covariance: covariance, standard_errors and concordance refuse; its with_params works (it keeps what the baseline needs).

AdditiveHazardsModel

Raises:

ValueError – For a vector of the wrong length; or on a model restored from a dict, which does not keep the risk sets the baseline is re-estimated from.
