Non-Parametric Additive Hazards (Aalen)

Aalen’s additive hazards model: each covariate adds to the hazard an amount that may change freely with time, \(h(x \mid Z) = b_0(x) + b(x)' Z\). The fit estimates the cumulative regression functions \(B_j(x) = \int_0^x b_j\), a least-squares fit at each event time, with their optional-variation variance (R’s timereg::aalen with robust = 0). For effects constant in time see Semi-Parametric Additive Hazards (Lin and Ying). Supports observed and right-censored data, with delayed entry.

As for the Lin-Ying model, nothing keeps the estimated hazard positive, and the model predicts with the running maximum of the estimated cumulative hazard from time 0, so sf stays in \([0, 1]\) and never increases.

class surpyval.univariate.regression.additive_hazards.aalen_additive.AalenAdditive_

Bases: FitterRepr

Aalen’s non-parametric additive hazards model: each covariate adds to the hazard an amount that may change freely with time,

\[h(x \mid Z) = b_0(x) + b(x)' Z.\]

The fit estimates the cumulative regression functions \(B_j(x) = \int_0^x b_j\), a least-squares fit at each event time, with no iteration. AalenAdditive is an instance of this class; its fit returns an AalenAdditiveModel. For effects constant in time, see AdditiveHazards (Lin and Ying), and for a parametric baseline the AH family.

fit(x: ArrayLike, Z: ArrayLike, c: ArrayLike | None = None, n: ArrayLike | None = None, tl: ArrayLike | None = None, penalizer: float = 0.0, w: ArrayLike | None = None, *, unit=None) → AalenAdditiveModel

Fit Aalen’s additive hazards model.

Parameters:

  • x (array like) – The times of the events and censorings, at or above 0.

  • Z (array like) – The covariates, one row per observation. Rows with a missing or infinite covariate are dropped, with a warning. A constant column (which the baseline absorbs) or one that is a linear combination of the others is aliased: its column of B is nan (model.aliased lists it), the others are those of the fit without it, predictions take it as 0, and one warning names it.

  • c (array like, optional) – Censoring flags: 0 observed (an event), 1 right censored. Defaults to all observed. Left and interval censored data are refused.

  • n (array like, optional) – The count of each row. Defaults to 1 each.

  • tl (array like, optional) – Each row’s entry time (left truncation): it is at risk on (tl, x]. Defaults to 0.

  • penalizer (float, optional) – A ridge penalty on the covariates’ increments, dB = (X'YX + P)^{-1} X'dN with P the penalty times each covariate’s variance (so the penalty does not depend on the covariates’ units) and nothing on the baseline. It keeps the fit going where few units are at risk, at the price of shrinking the effects towards 0. Default 0, no penalty. lifelines’ coef_penalizer is the same on standardised covariates, but penalises its intercept too. Named coef_penalty before v0.27 (removed in v0.28). With weights the covariates’ variance is the weighted one, scaled with the weights (see Weighted Data).

  • w (array like, optional) – Sampling, propensity or censoring weights: how many units of the population each row stands for, one positive finite number per row (a scalar for every row). The increments are then weighted least squares, dB = (X'WYX + P)^{-1} X'W dN with W the weights times the counts, and the variance of B is always the robust one (each unit’s martingale residuals, R’s timereg::aalen(..., weights = w, robust = 1)), which does not depend on the weights’ scale. constant_effects_test() refuses a weighted fit. Defaults to no weights.

Returns:

The fitted model.

Return type:

AalenAdditiveModel

Examples

>>> import numpy as np
>>> from surpyval import AalenAdditive
>>> rng = np.random.default_rng(3)
>>> Z = rng.binomial(1, 0.5, (300, 1)).astype(float)
>>> x = rng.exponential(1 / (0.1 + 0.05 * Z[:, 0]))
>>> c = (x > 15).astype(int)  # follow-up ends at 15
>>> x = np.minimum(x, 15)
>>> model = AalenAdditive.fit(x, Z, c=c)
>>> model.cumulative_coefficients([5, 10]).round(3)
      baseline  coef_0
time
5.0      0.562   0.340
10.0     1.099   0.362

The truth is B_0(t) = 0.1 t and B_1(t) = 0.05 t.

class surpyval.univariate.regression.additive_hazards.aalen_additive.AalenAdditiveModel

Bases: DiagnoseMixin, ConditionalSurvivalMixin, NoLikelihoodMixin, ConcordanceMixin, SerialisableMixin

A fitted Aalen additive hazards model, returned by AalenAdditive.fit.

The model is h(t | Z) = b_0(t) + b(t)'Z with every b_j left to the data. B holds the cumulative regression functions \(B_j(t) = \int_0^t b_j(s) ds\) at the event times x, a column per term: the baseline first, then each covariate. A covariate’s B_j(t) is the extra cumulative hazard a unit with one more unit of it has accumulated by t; its slope is the extra hazard at t.

The predictions follow from B: the cumulative hazard of a unit with covariates Z is H(t | Z) = B_0(t) + B(t)'Z (see Hf() for how a falling estimate is handled), its survival exp(-H), and its hazard rate the kernel-smoothed slope (smoothed_coefficients()).

Examples

On the Rossi recidivism data each covariate adds to the weekly hazard of arrest; by week 52 each prior conviction (prio) has added about 0.037 to the cumulative hazard, and financial aid has taken about 0.10 from it:

>>> from surpyval import AalenAdditive
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> df["censored"] = 1 - df["arrest"]
>>> model = AalenAdditive.fit_from_df(
...     df, x_col="week", c_col="censored", Z_cols=["fin", "age", "prio"]
... )
>>> model.summary()[["coef", "se(coef)", "p"]].round(4)
             coef  se(coef)       p
covariate
baseline   0.6315    0.1167  0.0000
fin       -0.1037    0.0584  0.0758
age       -0.0152    0.0041  0.0002
prio       0.0366    0.0140  0.0091
>>> model.sf(52, [[0, 25, 3], [1, 25, 3]]).round(3)
array([0.697, 0.772])
B: npt.NDArray

The cumulative regression functions at x, (len(x), 1 + p): the baseline’s, then each covariate’s (nan for an aliased one).

B_var: npt.NDArray

The variances of B (the optional variation; the robust one for a weighted fit), as B.

Hf(x: ArrayLike, Z: Any) → NDArray

The cumulative hazard at x of a unit with covariates Z (one row for every x, or one row per x): the estimate H(x | Z) = B_0(x) + B(x)'Z, held at its running maximum from time 0.

Nothing keeps the additive hazard b_0(t) + b(t)'Z positive, so the estimate can fall – for a covariate row whose hazard the model takes below 0, or by chance – and exp(-H) would be a survival that rises and exceeds 1. As for the Lin-Ying model (AdditiveHazardsModel.Hf), the prediction is the smallest non-decreasing cumulative hazard at or above both the estimate and 0: max(0, max_{s <= x} H(s | Z)). It is the estimate wherever the estimate is at its running maximum. R’s timereg and lifelines return the estimate itself, which is the same wherever it does not fall.

H is a step function: 0 before the first event time, a step at each event time, and held after the last time B is estimated at (there is no one left at risk to estimate it from).

cb(x: ArrayLike, Z: Any, on: str = 'sf', alpha_ci: float = 0.05, bound: str = 'two-sided', method: str = 'wald') → NDArray

Pointwise confidence bounds on a unit’s predicted sf, ff or Hf. The standard error of H(x | Z) = B_0(x) + B(x)'Z is sqrt(X' C(x) X), X = [1, Z] and C the optional-variation covariance of B (the robust covariance for a fit with weights w); the bound is a Wald bound on log H about the predicted Hf, so that H stays positive and sf in (0, 1], and sf and ff are taken from it. Where the predicted Hf is 0 (before the first event) both bounds are 0.

Only Wald bounds are available: there is no likelihood for a likelihood-ratio bound, and no bootstrap is implemented; for one, refit the model to resampled rows.

Parameters:

  • x (array like or scalar) – The times.

  • Z (array like) – The covariates, paired with x as sf() pairs them.

  • on (('sf', 'ff', 'Hf'), optional) – The function to bound ('R' and 'F' are aliases of 'sf' and 'ff'). Default 'sf'.

  • alpha_ci (float, optional) – The total tail probability. Default 0.05.

  • bound (('two-sided', 'lower', 'upper'), optional) – Two-sided bounds put [lower, upper] on the last axis.

  • method ('wald', optional) – The only method.

Returns:

The bounds, with the shape of x (and a last axis of 2 for two-sided bounds).

Return type:

numpy array

concordance(x: ArrayLike | None = None, c: ArrayLike | None = None, Z: Any = None, tie_tol: float = 1e-08, ties: str = 'therneau', *, weighting: str = 'harrell', tau: float | None = None, alpha_ci: float = 0.05, ci_method: str = 'normal') → ConcordanceResult | float

Harrell’s (or Uno’s) concordance index (C) of the model’s risk scores, with its standard error and confidence interval.

The proportion of usable pairs of subjects – the one with the earlier time had the event – in which the model gives that subject the higher risk: 1 ranks every pair correctly, 0.5 is chance. With no arguments it scores the data the model was fitted to (each row counted n times); pass x, c and Z together to score other data, such as a test set. Two events at the same time are not a pair (ties="therneau", as R’s concordance and lifelines) unless ties="harrell"; see surpyval.metrics.concordance_index() for the treatment of tied times and scores.

The risk score, higher meaning an earlier event, is for each family:

  • CoxPH, the frailty models and AdditiveHazards (Lin-Ying): the linear predictor \(\beta'Z\) (the log hazard ratio, or the covariates’ additive hazard), as R’s concordance and lifelines use;

  • the parametric families (PH, AFT, PO, AH and the accelerated life models): the cumulative hazard \(H(t^* \mid Z)\) at \(t^*\), the median of the times scored. For every family whose covariates act through a linear predictor this ranks the rows exactly as the linear predictor does, with the sign that means a higher risk (\(\beta'Z\) for PH, AFT and AH, \(-\beta'Z\) for PO), and \(t^*\) does not matter; it can only matter for an accelerated life model whose life model sets a shape parameter;

  • BuckleyJames: \(-\beta'Z\), since the model is linear in the log time;

  • ProportionalOdds: \(-\beta'Z\), the log of the odds of failure relative to the baseline’s.

Parameters:

  • x (array_like, optional) – Observed times.

  • c (array_like, optional) – Censoring flags, 0 an event and 1 right censored.

  • Z (array_like or DataFrame, optional) – Covariates, one row per time (a DataFrame for a model fitted with fit_from_df).

  • tie_tol (float, optional) – Scores within this of each other are tied. Default 1e-8.

  • ties ({"therneau", "harrell"}, optional) – "therneau" (the default, as R’s survival::concordance and lifelines): two events at the same time are not a usable pair. "harrell" (Harrell’s original definition): they are, counting 1 if their scores are tied, else 0.5.

  • weighting ({"harrell", "uno"}, optional) – "harrell" (default): every usable pair weighs 1. "uno": Uno’s inverse-probability-of-censoring weighted C, each pair weighted by 1 / G(t-)^2 (see surpyval.metrics.concordance_index()).

  • tau (float, optional) – Count only the pairs whose earlier time is at most tau. Default None, every pair.

  • alpha_ci (float, optional) – Keyword only: the significance level of the interval. Default 0.05.

  • ci_method ({"normal", "logit"}, optional) – Keyword only: the scale of the interval. Default "normal".

Returns:

The concordance index, a float that carries its infinitesimal-jackknife standard error se and interval ci (surpyval.metrics.concordance_index()). With no data it scores the data the model was fitted to, each row repeated n times as its own subject (as R does with the rows repeated); the standard error treats the scores as fixed, as R’s does. A plain nan where a covariate is missing.

Return type:

ConcordanceResult

Raises:

ValueError – If only some of x, c and Z are given, or none are and the model does not keep its training data (a model restored with from_dict, or one fitted with time-varying covariates, whose rows are intervals of a subject’s history).

Examples

>>> import surpyval as sp
>>> from surpyval.datasets import load_lung
>>> lung = load_lung().dropna(subset=["ph.ecog"])
>>> lung["censored"] = 1 - lung["status"]  # status 1 is a death
>>> model = sp.CoxPH.fit_from_df(
...     lung, x_col="time", c_col="censored",
...     Z_cols=["age", "sex", "ph.ecog"],
... )
>>> round(model.concordance(), 4)
0.6371
>>> round(model.concordance(ties="harrell"), 4)
0.6369

constant_effects_test(n_sim: int = 1000, random_state: Any = None) → pd.DataFrame

Tests that each term’s effect is constant in time: that B_j(t) is a straight line through 0, as in the Lin-Ying model (AdditiveHazards). The statistics are R’s timereg::aalen “test for time invariant effects”: the largest distance of B_j from the straight line to its last value,

\[KS_j = \sup_{t \le \tau} \left|B_j(t) - \tfrac{t}{\tau} B_j(\tau)\right|,\]

(Kolmogorov-Smirnov) and its integrated square (Cramér-von Mises, summed over the event times). Their null distributions are simulated by multiplying each event’s contribution to the increments of B by a standard normal draw (the multiplier method of Martinussen and Scheike 2006, section 5.3, on the counting processes): n_sim draws, each a pass over the event times, so the cost grows with units times event times times n_sim. Each draw’s variance is the optional variation B_var. The p-value is the share of draws at least as large as the observed statistic; p-values from different seeds differ by about sqrt(p (1 - p) / n_sim).

The draws multiply the events (dN) rather than the martingale residuals (dN - Y X dB): the residuals are those of a least-squares fit, and where few units are at risk (near the last event time, which anchors the statistic) they are close to 0 and the null is far too narrow. In simulations with a constant effect the residual draws rejected 44% of the time at the 5% level with 100 units, 21% with 300 and 8% with 1000. These draws reject at about the level with 300 units or more, and less often than the level (0.5% to 3.5%) with 100: the test is conservative there.

Parameters:

  • n_sim (int, optional) – The number of simulated draws. Default 1000, as timereg.

  • random_state (None, int or numpy.random.Generator, optional) – The seed of the draws. None draws from numpy’s global generator.

Returns:

One row per term: KS, KS p, CvM and CvM p.

Return type:

pandas.DataFrame

Raises:

WeightedRefusal – For a fit with weights w: the simulated null is that of an unweighted fit.

cs(x: ArrayLike, given: ArrayLike, Z: Any, *args: Any, **kwargs: Any) → Any

Conditional survival: the probability that a unit with covariates Z that has survived to given survives a further x,

\[R(x \mid given, Z) = \frac{R(given + x \mid Z)}{R(given \mid Z)} = e^{-(H(given + x \mid Z) - H(given \mid Z))},\]

the univariate models’ cs(x, given) with the covariates of sf() (#581).

Parameters:

  • x (array like or scalar) – The further durations.

  • given (array like or scalar) – The ages already survived, broadcast against x (one age per unit and one x for all, say).

  • Z (array like or DataFrame) – The covariates, paired with the times as sf() pairs them: one row per element of x / given, or a single row for all of them.

  • *args – Any further arguments of this model’s Hf() (grid=True for every time for every row; a Cox model’s stratum; a frailty model’s group or frailty).

  • **kwargs – Any further arguments of this model’s Hf() (grid=True for every time for every row; a Cox model’s stratum; a frailty model’s group or frailty).

Returns:

cs – The conditional survival probabilities.

Return type:

scalar or numpy array

Notes

The ratio is taken from the model’s cumulative hazard, which keeps it exact where \(R(given)\) underflows (a unit far into the tail). Where \(R(given \mid Z) = 0\) the conditional survival is undefined and nan is returned, as for the univariate models. A fleet’s expected failures over a horizon, built on this, are surpyval.forecast().

Examples

>>> import numpy as np
>>> from surpyval import Weibull, WeibullPH
>>> np.random.seed(1)
>>> Z = np.random.binomial(1, 0.5, 100).reshape(-1, 1)
>>> x = Weibull.random(100, 10, 2) * np.exp(-0.5 * Z[:, 0])
>>> model = WeibullPH.fit(x, Z)

Two units, aged 2 and 8, surviving one more unit of time:

>>> model.cs(1.0, [2.0, 8.0], [[0], [1]]).round(4)
array([0.9362, 0.6843])
>>> s = model.sf([3.0, 9.0], [[0], [1]])
>>> (s / model.sf([2.0, 8.0], [[0], [1]])).round(4)
array([0.9362, 0.6843])

diagnose(alpha: float = 0.05, columns: Sequence[str] | None = None, *, n_boot: int | None = None, random_state: Any = None, **options: Any) → Diagnosis

Check the model’s assumptions, fit and influential points, and say what to do about any that fail.

Runs the checks this kind of model calls for (for a Cox model: proportional hazards, the functional form of each continuous covariate, influence and outliers; see Model Diagnostics) and returns a report: d.table, one row per check with its test, statistic, p-value, verdict ("ok", "warn" or "fail") and covariates; d.advice, plain-English remedies that each name the SurPyval feature that applies them; d.plot(), the visual checks (matplotlib is only imported then); d.ok, True if nothing failed; d.raise_if_failed() for pipelines; and d.to_dict().

A test fails when its p-value is below alpha, and warns when it is below 2 * alpha (borderline) or could not be computed. Each row is judged at alpha on its own, so with many rows some fail by chance even when every assumption holds.

Parameters:

  • alpha (float, optional) – The level each test is judged at. Default 0.05.

  • columns (str or list of str, optional) – The covariates to check, named as summary() names them (the DataFrame or formula columns, else coef_0, …); all of them by default. A joint (GLOBAL) test still covers every covariate.

  • n_boot (int, optional) – For the families whose tests resample (a univariate distribution’s bootstrap goodness-of-fit tests): the number of bootstrap refits; None is the family’s default. Other families ignore it.

  • random_state (optional) – The seed of those resamples (SurPyval’s one seed rule: None draws from numpy’s global generator).

  • **options – Options of the model’s family, named in Model Diagnostics: for an accelerated life model, use_stress, the stress the model is to predict at (a number, or one per stress column), whose distance from the tested stresses the report screens. A family refuses an option it does not take.

Returns:

See surpyval.diagnostics.Diagnosis.

Return type:

Diagnosis

Raises:

  • NotImplementedError – For a model whose family’s diagnostics are not built yet, saying what to check it with meanwhile; for an option of the model the checks do not support yet; and for a kind of model the checks do not cover by design (a discrete distribution, a parametric regression with a custom link, …), saying what to use instead.

  • ValueError – For a model the checks cannot be run on (one restored with from_dict, which has no data), saying what to do.

Examples

>>> from surpyval import CoxPH
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> df["censored"] = 1 - df["arrest"]
>>> model = CoxPH.fit_from_df(
...     df, x_col="week", c_col="censored", Z_cols=["fin", "age"]
... )
>>> d = model.diagnose()
>>> d.ok
False
>>> d.table[["check", "transform", "covariates", "verdict"]].head(3)
                  check transform covariates verdict
0  proportional_hazards        km     (fin,)      ok
1  proportional_hazards        km     (age,)    fail
2  proportional_hazards        km (fin, age)    fail

qf(p: ArrayLike, Z: Any) → NDArray

The quantile function: the first event time at which the predicted failure probability ff(x, Z) reaches p, nan where it never does (the curve is held after the last event time, above 1 - p where the data end censored). Z is paired with p as sf() pairs it with x. A probability outside [0, 1] gives nan, with a warning.

random(size: int, Z: Any, random_state: Any = None) → tuple[NDArray, NDArray]

Draw size lifetimes for each covariate row of Z from the fitted model, by inverse transform on its step survival curve: a draw U of the survival is the first event time at which the predicted cumulative hazard Hf() (the estimate held at its running maximum, so non-decreasing) reaches -log(U).

The estimate stops at the last event time, where the curve is above 0 when the data end censored; a draw beyond it is inf (the unit outlives the data), as often as sf at the last time says. A missing covariate gives nan draws. random_state seeds the draw: None (the default) draws from numpy’s global generator, so np.random.seed reproduces it; an int or a numpy.random.Generator gives a stream of its own.

Returns the draws and a 2-D array of the covariate row each was drawn at, row by row, as the other regressions’ random.

Examples

>>> import numpy as np
>>> from surpyval import AalenAdditive
>>> from surpyval.datasets import load_rossi_static
>>> df = load_rossi_static()
>>> df["censored"] = 1 - df["arrest"]
>>> model = AalenAdditive.fit_from_df(
...     df, x_col="week", c_col="censored", Z_cols=["fin", "prio"]
... )
>>> draws, rows = model.random(5, [[0, 10]], random_state=1)
>>> draws
array([inf, 10., inf, 10., inf])
>>> model.sf(52, [0, 10]).round(3)
np.float64(0.526)
>>> draws, _ = model.random(10000, [[0, 10]], random_state=1)
>>> float(np.isinf(draws).mean())
0.523

smoothed_coefficients(x: npt.ArrayLike, bandwidth: float | None = None, terms: Any = None) → pd.DataFrame

The regression functions b_j(t) themselves, the slopes of B_j: each covariate’s excess hazard per unit at time t. They are estimated by smoothing the increments of B with an Epanechnikov kernel (Ramlau-Hansen),

\[\hat b_j(t) = \frac{1}{w} \sum_k K\left(\frac{t - t_k}{w} \right) \Delta B_j(t_k), \quad K(u) = \tfrac34 (1 - u^2),\]

which is lifelines’ smoothed_hazards_(bandwidth) divided by the bandwidth w (lifelines leaves the division out, so the two agree at w = 1). Within a bandwidth of either end of the event times the kernel runs out of data and the estimate is pulled towards 0.

Parameters:

  • x (array like) – The times.

  • bandwidth (float, optional) – The kernel’s half-width w, in the units of time. Defaults to the normal-reference rule 1.06 sd m^(-1/5) on the m event times. A wider bandwidth gives a smoother, more biased estimate.

  • terms (str, int or list, optional) – The terms, as cumulative_coefficients() takes them.

Returns:

Indexed by time, a column per term.

Return type:

pandas.DataFrame

summary(alpha_ci: float = 0.05, at: float | None = None) → pd.DataFrame

The cumulative effects at one time, in the layout of the other regression models’ summary(): for each term (the baseline, then each covariate) B_j(at), its optional-variation standard error (robust for a fit with weights w), a two-sided 1 - alpha_ci Wald interval, and the Wald statistic z and its p-value, a test that the covariate has added nothing to the cumulative hazard by at. exp(coef) is nan: an additive effect is not a ratio. For how the effects change over time see cumulative_coefficients() and plot(), and for a test that an effect is constant, constant_effects_test().

Parameters:
