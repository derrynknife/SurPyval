Recurrent Event Models

Models for items that can have the same event many times – repairable systems that fail and are repaired, patients with repeated hospitalisations. The data are each item’s event times, measured from the start of its life, with a right-censored (c=1) row marking the end of its observation. Import everything on these pages from surpyval.recurrent. The theory is in Recurrent Event Analysis and Recurrent Event Regression Analysis; worked examples are in Recurrent Event Modelling with SurPyval and Recurrent Event Regression Modelling with SurPyval.

Each fitter below returns one of three fitted-model classes: a ParametricRecurrenceModel (the Poisson processes), a RenewalModel (the renewal and imperfect-repair models) or a ProportionalIntensityModel (the regression models; the semi-parametric ones return a RecurrentCoxModel). The non-parametric and cause-specific fitters return a fitted instance of their own class.

Recurrent Event (Poisson Process) Models

Processes whose events arrive at a rate that depends only on the system’s age (or not at all, for the HPP), so a repair leaves the system as it was just before the failure (“as bad as old”).

  • Parametric Recurrence Model
  • HPP
  • Duane
  • Cox-Lewis
  • Crow-AMSAA

Software Reliability Growth Models

Poisson processes for faults found and removed during testing: the intensity falls as the testing goes on. Fitted to failure times or to the failures counted in each period of testing.

  • Goel-Okumoto
  • Yamada Delayed S-Shaped
  • Inflection S-Shaped
  • Musa-Okumoto
  • Rayleigh Defects
  • Testing Effort and Change Points

Models of the Times Between Failures

Models of one test campaign’s times between failures that are not Poisson processes: a whole number of faults (Jelinski-Moranda), or a rate that is itself uncertain (Littlewood-Verrall).

  • Jelinski-Moranda
  • Littlewood-Verrall

Non-Parametric Models

The mean cumulative function estimated without assuming a process, and the comparison of two groups’ MCFs.

  • Non-Parametric Counting (MCF)
  • Comparing Two MCFs

Panel Counts

Events counted at inspections, with no event times: the mean cumulative function and a proportional means regression.

  • Panel Counts (Events Counted at Inspections)

Renewal Models

Processes in which a repair restores the system part of the way to new (or all the way, for an ordinary renewal process).

  • Renewal Model
  • Generalized Renewal Process
  • Generalized One Renewal Process
  • Arithmetic Reduction of Age (ARA)
  • Arithmetic Reduction of Intensity (ARI)

Competing Risks (Marked) Models

Recurrent processes with several kinds of event, each with its own intensity (and, for the last, its own covariate effects).

  • Cause-Specific MCF
  • Cause-Specific NHPP
  • Cause-Specific Proportional Intensity

Recurrent Event Regression Models

Intensities that depend on covariates.

  • Proportional Intensity Regression Model
  • HPP Regression
  • NHPP Regression
  • Semi-Parametric Recurrent-Event Regression
  • Joint Frailty Model (Recurrent and Terminal Events)
  • Shared Frailty (Poisson Processes Whose Units Differ)

Trend Tests and Diagnostics

Tests of whether the event rate is changing, and the result classes of the tests and of the models’ goodness-of-fit methods.

  • Trend Tests and Diagnostics

Interventions

Whether the rate of failures changed at an intervention (a design change, a corrective action), with the evidence to say so.

  • Intervention Test
